週次ファイルの投入フォルダ
==============================================================

TARGET から出した週次CSVは全部ここ(data/_inbox/)に放り込むだけ。

  ★ weekly_nicegui.ps1 が Phase A / Phase C の冒頭(Step 0)で place_weekly.py を
     自動実行して振り分ける。手動で place_weekly.py を先に走らせる必要はもう無い。
         .\weekly_nicegui.ps1           # 土曜: 振り分け → 出走表/AI予想 → HF
         .\weekly_nicegui.ps1 -Post     # 日曜: 振り分け → 結果集計 → HF

  ● 振り分けだけ単体でやりたい / 確認したい時:
         PYTHONUTF8=1 ./venv311/Scripts/python.exe place_weekly.py         # 振り分け実行
         PYTHONUTF8=1 ./venv311/Scripts/python.exe place_weekly.py --dry   # 先に振り分け先だけ確認

中身とファイル名を見て、data/ の正しい場所へ自動で振り分ける。

ファイル名ルール（これだけ守れば全自動）
--------------------------------------------------------------
  出走表             先頭に S    例) S20260704.csv      → data/weekly/{日付}.csv
  過去5走            先頭に K    例) K20260704.csv      → data/kako5/{日付}.csv
  着度数             先頭に T    例) T20260704.csv      → data/tyaku/{日付}.csv
  結果(通常・15列)    そのまま     例) 20260704.csv       → data/kekka/{日付}.csv
  土曜結果(174列払戻) そのまま     例) bias20260704.csv   → data/bias/{日付}.csv
                                                          ＋ 実現バイアス自動生成
  調教               H-*/W-* のまま                      → data/training/
  オッズ             OD* のまま                          → data/odds/

  ★ 実は S/K/T を付け忘れても大丈夫 (2026-07-03〜):
     出走表/過去5走/着度数 はヘッダ同型だが馬行の列数が違う
     (出走表=46 / 着度数=53〜 / 過去5走=72) ので中身から自動判別する。
     判別できなかった時だけ「S/K/T を付けて」と言われるので付け直せばOK。

着度数(T)について
--------------------------------------------------------------
  着度数は AI予想の horse_fuku_* 特徴(馬の複勝率系)の供給源。
  出走表・過去5走と同じく毎週必要（無いとその週の特徴が欠損する）。

土曜結果(bias)について
--------------------------------------------------------------
  土曜の払戻成績(174列)を入れると build_realized_bias.py が走り、
  翌日(日曜)の出走表タブに「実現バイアス」カードが出る用の
  data/realized_bias.json を更新する。サイト反映は build_site.py /
  sync-hf-umami.ps1（週次フロー）で。

置かなくていいもの
--------------------------------------------------------------
  補正タイム(hosei) … make_weekly_hosei.py が自動生成するので投入不要。
