# 次研究(オッズ価格形成)の開始条件 と 当面の運用規律 (2026-09-21)

## 1. オッズ価格形成研究の開始条件（全て満たすまで開始しない）

### 1.1 事前固定した最低race数（経験則ではなく検出力計算から算出）

**手順**（EXP05-Fの`POWER_ANALYSIS.md`と同一の方法論、
`n_races = (z_{α/2} + z_{power})^2 · σ^2 / effect^2`）:

1. 目的変数を明確化する（例: T-10→close間の価格ドリフト、あるいは
   model確率とT-10/close市場確率の残差、いずれもレース単位・馬単位で
   集約した値）。
2. その目的変数のレース単位(または馬単位)分散σ²を、**pilotデータ**から
   実測する。
3. 検出したい効果量を、楽観的な値ではなく保守的な値で固定する
   （EXP05-Fの規則を踏襲: 観測された効果の50%と、利用可能な下位期間別
   最小絶対値の**小さい方**を採用）。
4. 両側有意水準1%(z=2.576)・検出力80%(z=0.842)を既定とする
   （EXP05-Fと同一の基準、プロジェクト内で統一）。

**現時点のpilot実測値**（本監査`ODDS_TIMESERIES_INVENTORY_20260921.md`
で取得、**結果データは一切使っていない**——de-vig正規化した市場確率
そのものの時点間ドリフトのみ）:

```
対象: T-10→close間の単勝de-vig正規化確率drift(馬単位)
n = 3,166頭(239レース)
mean drift ≈ 0(正規化の定義上、レース内で相殺されるため当然)
sd drift(馬単位) = 0.02140
```

**この値は239レース・9日分のみのpilot推定であり、確定的な必要標本数の
算出には使えない**（σ自体の標準誤差が大きい）。本格的な検出力計算は、
最低でも数百レース規模のpilotが蓄積されてから再計算すること。参考として、
EXP05-Fと同一の保守的アプローチ（σ=0.0214、効果量をEXP05-Fと同オーダー
0.0007程度と仮置き）で試算すると:

```
n_races ≈ (2.576+0.842)^2 × 0.0214^2 / 0.0007^2 ≈ 3,090レース(暫定・要再計算)
```

**この暫定値は最終的な必要標本数ではない**。目的変数・効果量の定義が
確定し、pilotデータが十分蓄積された時点で必ず再計算すること。「とりあえず
1,000件」のような経験則での決定は行わない。

### 1.2 T-35/T-20/T-10/closeの十分な重複

`ODDS_TIMESERIES_INVENTORY_20260921.md`の通り、現状4時点が同時に安定して
揃う期間はごく短い（2026-09-19以降のみ）。**4時点が揃ったレースが、
上記1.1で算出される必要race数に達するまで**は開始しない。

### 1.3 timestamp窓の安定

T-10のminutes-to-postに検出された外れ値（-5228分）のような異常が、
新規蓄積データで再発しないことを継続的に確認する（下記§2のcanary運用）。

### 1.4 append-only保存

`data/forward_prices/`は既にappend-only設計（`docs/forward_price_protocol.md`
§「latest viewだけを残し、観測履歴を上書きすること」を禁止事項に明記）。
T-35(`reports/exp05fs_odds/`)・T-20(`reports/site_odds/`)も同様に
過去ファイルを上書きしない運用を維持する。

### 1.5 収集失敗率の上限

現状のok=true率: T-10/close≈本番運用水準(数値は本監査未算出、別途
`forward_price_eval`参照)、T-35=79.6%、T-20=100%。**T-35の収集失敗率
20.4%は高すぎる**——`EXP05F_OBSERVATION_STATUS_20260921.md`で報告した
進行中の障害を解消し、**収集失敗率を10%未満に安定させてから**価格形成
研究のpilotデータとして採用する。

### 1.6 結果データと分離したdry-run

価格形成研究のパイプライン(特徴生成・集計ロジック)は、結果データ
(着順・払戻)を一切参照しないdry-runで動作検証すること
（`docs/forward_price_protocol.md`の「close価格や結果をdecision特徴へ
逆流させること」禁止と同じ精神を、研究パイプラインにも適用する）。

### 1.7 development期間と完全未開封期間の確保

EXP07-12で確立した規律をそのまま適用する: 目的変数の定義・効果量の
再計算・前処理の選択は developmentデータのみで固定し、それ以降に蓄積
される期間は完全未開封のまま、必要標本数に達した時点で一度だけ評価する。
2024・2025年の表データとは独立の、新規収集期間で完結させる（表データの
使い回しではない）。

### 許可する作業

- 収集障害の修正（例: `EXP05F_OBSERVATION_STATUS_20260921.md`で報告した
  2026-09-21のbundle不一致問題）

  不変条件の維持）

  による定期報告）
- 既存本番バグの修正

- **EXP番号を増やす**（EXP13以降を開始しない）
- **2024・2025年の再利用による追加探索**（表データを使った新しい仮説
  探索は行わない、本ドキュメント群が定める停止線の対象）
- **失敗した仮説の条件変更**（EXP01-12で不合格になった仮説の閾値・
  統制変数・placebo設計等を変えて再検定しない）
- **前向き期間途中のROI最適化**（EXP05-F・T-10自動馬券ラインとも、
  目標標本数到達前に性能を覗いてパラメータを調整しない）
- **T-35データが少ない段階でのモデル学習**（T-35を含む新しい特徴・
  モデルの学習は、上記§1の開始条件を満たすまで行わない）
