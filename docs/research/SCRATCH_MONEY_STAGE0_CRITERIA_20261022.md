## 0. 仮説と、label-free で測れる範囲

pari-mutuel では投票済みの票を取り消せない。取消馬への票は返還されるが、**残った馬への票は
「取消馬が走る文脈」で入ったまま**締切プールに残る。

最小モデル（金額シェアは線形に混ざる）:

- a = 取消前スナップの確率を残存馬に比例再配分したもの（IIA）。旧文脈の票はこの形で残る。
- q = 取消を知った後の資金が持つ新文脈の見方。
- s = 取消時点で既に入っていた票の比率（既投入比率）。
- 締切確率 c = s·a + (1−s)·q。

新文脈の見方 q を「正しい」とすると、締切価格の歪み（取れる情報の上限）は
**KL(q‖c) ≤ s·KL(q‖a)**（KL の第 2 引数に関する凸性。近似ではない上界）。
したがって必要なのは 2 つの大きさだけである。

1. **K = KL(q‖a)**: 取消が起きたとき市場が比例再配分からどれだけ離れて値付けし直すか（文脈効果の大きさ）。
   取消後に大量の新資金が入る早い区間（前夜→9時、9時→T-27）の取消レースで、締切 c と a の乖離から
   推定できる（s が小さいので c ≈ q）。
2. **s**: 取消時点の既投入比率。

着順・払戻を使わずに上界まで出せる。上界が床に届かなければ、ラベルを開ける Stage 1 は不要。
注意: 遅い資金が旧文脈票を見て逆張りすれば歪みは打ち消される。上の上界はそれを仮定しない（＝甘い側）。

## 1. データと定義（固定）

- 入力: `data/Time _series_odds/TANPUK_20160105-20201227.csv` / `TANPUK_20210105-20251228.csv`（cp932、完全重複行は除去）。
  対象 2016-01-01〜2025-12-31。**master・kekka・着順・払戻は読まない**（障害の判別も master が要るので行わず、全レースを含める）。
- スナップ: E = 前日（区分1、前夜 23 時台）、M = 当日最初の区分1（9 時前後）、P = 当日最後の区分1（発走約 27 分前）、
  F = 区分4（確定）。E が無いレースは M→P と P→F だけを使う。
- 馬の在否: 単勝オッズ > 0 なら在、0.0 または空欄なら不在（取消馬は 0.0 で残ることを構造確認で確認済み）。
- **取消（代理）**: あるスナップで在、次のスナップで不在、以後 F まで不在の馬。最初のスナップから不在の馬は
  「発売前取消」で旧文脈票が無いので件数のみ数える。不在→在の復活がある馬はデータ異常として除外し件数を記録。
- 区間: E→M / M→P / P→F（P→F は締切後の除外も含み、取消時刻は区間内で特定できない）。
- 主解析の取消レース: 取消（代理）が 1 区間にだけあるレース（同区間の複数頭は可）。複数区間にまたがるレースは件数のみ。
- 確率: π = (1/オッズ) / Σ(1/オッズ)（比例 de-vig、正規化 1 回）。
- 既投入比率: s_A = 単勝票数(A) / 単勝票数(F)、s_B = 単勝票数(B) / 単勝票数(F)。A は取消前最後のスナップ、
  B は取消後最初のスナップ。取消時点の真の s は [s_A, s_B] にある（P→F では s_B = 1）。
- 乖離量（取消レース r、区間 A→B）: **D_scr(r) = KL(π_F ‖ IIA(π_A))**。IIA(π_A) は π_A を F の残存馬に制限し再正規化したもの。
- 自然ドリフト（非取消レース、同じ始点 A）: **D_nat = KL(π_F ‖ π_A)**。非取消レース = 発売後取消が 0 頭（発売前取消は可）。
- 層: 始点 A ∈ {E, M, P} × F 時点の残存頭数帯 {5-8, 9-12, 13-15, 16-18} × 年。
  取消レースの比較相手は、同じ層の非取消レースを取消レースの層構成で重み付けしたもの。
- 早い取消 = 区間 E→M または M→P。遅い取消 = P→F。

## 2. 推定量（固定）

- **ρ**（中央値比）: 早い取消レースの D_scr の中央値 ÷ 層重み付けした非取消 D_nat の中央値。
- **K**（文脈効果の大きさ, nats/取消レース）: 早い取消レースで
  K = mean_r [ (D_scr(r) − m_nat(層 r)) / (1 − s_B(r)) ]。m_nat は層内の非取消 D_nat の平均。
  /(1−s_B) は c が q を (1−s) 倍しか反映しないことの補正（KL(c‖a) ≤ (1−s)KL(q‖a) より K を大きめに取る側）。
  **K_hi** = 開催日クラスタ bootstrap（2,000 反復, seed 20261022）の 97.5 パーセンタイル。
- **取消レースあたり歪み上界**: Δ_ub(r) = s_B(r)·K_hi（早い取消）、Δ_ub(r) = K_hi（遅い取消, s = 1 の最悪ケース）。
  Δ̄_ub = 主解析の全取消レースでの平均。全レース平均への換算 Δ̄_all = Δ̄_ub × (取消レース数 / 全レース数) は報告値。
- **必要レース数**: EXP16A の理想局所近似 n_req(Δ) = 15.68 / Δ（α = 0.05 両側、検出力 0.8、SD ≈ √(2Δ)）。
  楽観側の式なので、これで足りないなら実際にはもっと足りない。
- **n_avail**: 2016-2025 の主解析取消レース数（参考: 2016-2023 だけの数も出す。2024-25 は EXP16A で封印中）。

## 3. 閉鎖基準（いずれか 1 つでも成立したら閉鎖）

| ID | 条件 | 意味 |
|---|---|---|
| C1 | ρ < 2.0 | 取消があっても締切価格は比例再配分から自然ドリフトの 2 倍以上離れない＝旧文脈と新文脈の差が小さい |
| C2 | K_hi < 0.005 | 最悪ケース（s = 1）でも取消レース 1 つあたりの歪みが EXP16A 実務床 0.005 nats/race に届かない |
| C3a | n_req(0.005) = 3,136 > n_avail | 床ちょうどの効果を全データでも検出力 0.8 で検出できない |
| C3b | n_req(Δ̄_ub) > n_avail | 上界どおりの効果があっても全データで検出できない |

- どれも成立しなければ「Stage 1（ラベルを使う検定）へ進む価値あり（要レビュー）」。Stage 1 の設計はここでは決めない。
- 床 0.005 は **取消レースあたり**で適用する（取消レースだけで賭ける戦略を想定した、仮説に甘い側の適用）。
  全レース平均で見ると Δ̄_all はさらに 1/10 以下になる。
- 結果を見た後に基準・層・推定量を変えない。感度分析は報告するが判定に使わない。
