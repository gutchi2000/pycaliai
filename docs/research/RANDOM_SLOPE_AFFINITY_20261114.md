# 階層ランダム傾き — 馬ごとの「条件への感度」を血統の事前分布つきで推定（2026-11-14）

結論: **null**。馬ごとの条件感度は IDM（その走の出来）の上下を確かに当てるが、勝ち馬予測では v7 にも市場にも有意な上乗せにならなかった。同じ定式化の再走は禁止（範囲は末尾）。

- 実装: `lab/experiments/random_slope_affinity_exp.py`（事前登録は冒頭の docstring）
- 出力: `reports/random_slope_affinity_exp.json`（集計値のみ）、作業用 `reports/rs_z.parquet`（JRDB 由来、reports/ の外へ出さない）
- 物差し: `lab/experiments/gate_common.py` の 4 ゲート（valid=2023 で重みを fit、test=2024-25 を 1 回だけ評価）

## 1. 理論

同日の分析（`PREDICTABILITY_CEILING_20261114.md`）で、能力 1 次元を完全に知っても v7 に届かないことが分かった。足りないのは「馬 × 条件」の相性だという仮説を、同条件の出走回数のような疎な集計ではなく、連続の条件軸に対する**馬ごとの傾き**として推定する。

各走の出来（JRDB IDM）を次のように置く。

    idm_run = level_h + Σ_k (β_k + s_{sire(h),k} + u_{h,k}) · x_k(run) + 共通曲線(月齢, キャリア) + noise

- β_k: 全馬共通の傾き
- s_{sire,k} ~ N(0, ω_k²): 種牡馬ごとの偏差
- u_{h,k} ~ N(0, τ_k²): 個体ごとの偏差
- noise ~ N(0, σ²)

今日の条件が普段とどれだけ違うか Δx_k = x_k(今日) − その馬の過去走の x_k の平均 に傾きを掛けたものが z（今日の条件による出来の上下の見込み、IDM 点）。

既に死んでいるルート（繰り返さない）: 回り適性を生の特徴として足す（市場に織り込み済み）、血統 SVD 埋め込み、セリ価格、1 次元レーティング。今回の違いは、IDM を目的変数にして傾きを縮小推定する点。

## 2. 定義（事前登録どおり）

**データ**: master_lite の 2013-2025 全走に SED の idm / ijou / td / bw を rid_s+馬番で結合。過去走として使うのは平地・ijou==0・idm あり・条件軸がそろう走（606,576 走）。idm は ≤2022 の 1% / 99% 点（−12 / 67）で丸める。

**条件軸（K=10、≤2022 の過去走で標準化）**

| 軸 | 定義 |
|---|---|
| ld | log(距離/1600) |
| dirt | ダート=1 / 芝=0 |
| wet_t / wet_d | 馬場状態（良0 稍1 重2 不3）× 芝 / × ダート |
| field | 出走頭数 |
| left | 左回り=1（東京・中京・新潟）、新潟芝直線=0.5 |
| hill | 急坂（中山・阪神・中京）=1 |
| hot | 6-9 月=1 |
| kin | 100 × 斤量 / 直近の馬体重（前走馬体重。今日の行は当日体重で代用しない） |
| straight | 最後の直線の長さ（m、場×芝ダ×内外） |

共通曲線は月齢の折れ線（36/48/60 か月）と log(1+それまでの出走数)。馬ごとの傾きは持たせない。

**推定（β・分散成分・種牡馬の事前分布は ≤2022 の走だけ）**

1. β と共通曲線: 馬の固定効果つき OLS（2011 年以降生まれ・過去走 2 以上、41,739 頭 390,676 走）。
2. σ²・τ_k²・ω_k²: 馬の水準を中心化で消した周辺尤度の最尤（馬→種牡馬の 3 階層、十分統計量から閉形式、対角）。
3. 種牡馬の傾きの事後分布: ≤2022 の全産駒から。評価する馬自身の ≤2022 の走は抜く。

**as-of**: 評価日 D の馬の傾きは、その馬の D より前の走だけで閉形式リッジ（事前平均 = 種牡馬の事後平均、事前分散 = 種牡馬の事後分散 + diag(τ²)）。2023 年以降でも「D より前の自分の走」は使うが、β・分散成分・種牡馬の事前分布は ≤2022 で固定。Δx の基準（過去走の平均）も D より前だけ。今日の馬場状態は発走前に発表される当日情報で、市場は知っている。

**変種（3 つ）**

- (a) z_total = Σ_k (β_k + ŝ_k + û_k) Δx_k … 判定の主役
- (b) 軸ごとの 9 列（wet_t と wet_d は合算）
- (c) 種牡馬の事前分布だけ: Σ_k (β_k + ŝ_k) Δx_k（個体の走で傾きを更新しない）

**判定規則**: (a) の P が PASS なら SIGNAL(予測)、(a) の M が PASS なら SIGNAL(市場外)。(b)(c) だけの PASS は要追試どまり。PASS が出たら年別符号と偽薬（傾きの偏差を馬の間で入れ替え）。全部 none なら null。

**カバー率**: valid 86.9% / test 86.8%。過去走が 1 つも無い馬（初出走）と障害戦は z なし（ゲート側でレース平均埋め）。過去走数の中央値は 7。

## 4. 出来（IDM）の上下は当たるか

「その走の残差 − 過去の平均残差」（β と共通曲線を除いたあとの出来の上下）を、傾きの偏差 (ŝ+û)·Δx で予測。過去走 2 以上の馬。

| 期間 | n | 種牡馬+個体 | 種牡馬のみ | 偽薬（傾きを馬の間で入れ替え） |
|---|---|---|---|---|
| valid 2023 | 36,535 | r=+0.239、回帰係数 0.90 | r=+0.084、0.63 | r=+0.007 |
| test 2024-25 | 69,602 | r=+0.224、回帰係数 0.86 | r=+0.078、0.68 | r=−0.006 |

回帰係数がほぼ 1 なので縮小の強さは適切。偽薬は 0。**馬ごとの傾きは、未来の走の出来の上下を実際に当てている**（説明できるのは出来の上下の分散の 3〜4%）。

## 6. なぜ IDM は当たるのに勝ち馬は良くならないか（事後の説明、valid=2023 だけ、判定には不使用）

| 入力 | valid の NLL（in-sample） | z の重み |
|---|---|---|
| 一様 | 2.5903 | |
| z_total だけ | 2.5830 | 0.126 |
| v7 | 2.0460 | |
| v7 + z_total | 2.0449 | 0.059 |
| 確定市場 + v7 | 1.9215 | |
| 確定市場 + v7 + z_total | 1.9209 | 0.045 |

- z は単独でも一様から 0.007 nats しか縮めない。一様から確定市場までの 0.67 nats の 1% ほど。勝ち負けを決めるのは馬どうしの水準の差で、「普段の自分との差」は量として小さい（z のレース内の散らばりは 2.8 IDM 点、走ごとの雑音は 6.9 点）。
- v7 を入れると z の重みは半分強が消える（0.126→0.059）。v7 の同条件成績・コース実績の特徴が、傾きの大半を既に持っている。
- レース内で z の偏差部分は v7 と +0.12、確定市場と +0.13 の相関。市場も同じ方向を見ている。

つまり、天井分析が示した「相性の次元」のうち、**ここで定式化した 10 軸の線形の感度は取り分が小さく、その大半は v7 と市場に入っている**。残りの相性は別のところ（展開・騎手・当日の状態など）にあると読むのが妥当。

## 7. 注意点

- 傾きは線形・事前分散は対角。距離の「最適点」（短くても長くても落ちる）や軸どうしの交互作用（距離×芝ダ）は表せない。
- 血統は種牡馬だけ。母父は入れていない（種牡馬の層が (c) でゼロなので期待は薄い）。
- IDM は JRDB の補正込みの指数。β には芝ダ間の IDM の水準差のような指数側の癖も入る。個体の傾きには「成長しながら距離を延ばした」ような時間の傾向も混ざる。どちらも as-of なので漏れではないが、純粋な適性ではない。
- 今日の馬場状態は当日情報。v7 は当日情報を使わないので、P の wet の重みは「v7 が知らない当日情報」の分を含みうる。それでも none。
- 2011 年より前に生まれた馬はキャリア数が 2013 年起点で切れている（評価対象の 2023-25 にはほぼいない）。
- 変種は事前登録の 3 つだけ。分散成分の最適化が遅かったため数値勾配を自動微分に替えたが、定義は変えていない（test を見る前）。

## 8. 再走禁止の範囲

次は同じ結論になるので再走しない。

- IDM（やそれに類する各走の出来の指数）を目的変数に、馬ごとの線形の傾き（距離・芝ダ・馬場・頭数・回り・急坂・季節・斤量比・直線）を縮小推定し、Δ条件 × 傾きを勝ち馬予測に足す形。
- その小変更: 軸の入れ替え・追加削除、分散成分の推定法の変更、母父の層の追加、非対角の事前分散、過去走の時間減衰。
- 血統の事前分布だけで条件適性を作る形（(c)。血統 SVD と同じ結論）。

範囲外（未検証、ただし z 単独で 0.007 nats しか無いので期待は低い）: 距離の最適点を持つ非線形の形、展開・ペースとの相互作用、当日情報との組み合わせ、z を v7 の学習特徴に入れて再学習する形。
