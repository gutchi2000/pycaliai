## 0. 問い

a95 などの回収率は少数の大きな払戻に依存し、500R の標準誤差が約 17pt ある。
(1) winsorize（払戻の上側打ち切り）や対数回収でこの SE がどれだけ下がり、そのとき推定対象がどれだけずれるか（分散-バイアス frontier）。
(2) そのとき 8 券種の 1 点買いの序列がどれだけ安定するか（Kendall τ と 95% CI）。
(3) a95 の回収が上位何 % の払戻に依存しているかを SE 付きで確定する。

## 1. データ（固定）

- 母集団: `data/_policy/bet_substrate.pkl`（sha256 `36d947b3…8a11d2`、本番 v6 の OOS 確率 × 実払戻、2023-25、10,299R）。`analysis/top1_by_odds_band.py` と同じ除外（5 頭以上、AI1 位の 9 時単勝オッズが有限かつ正）。
- **2026 年のデータは使わない。2026-10 以降の a95 前向き決済（CW-10/CW-11 台帳）は開かない。**
- 単位は開催日（`date`）。SE と CI はすべて開催日ブロック bootstrap（`analysis/deep_bet_search.block_boot` と同じ考え方、日を復元抽出）、B = 2000、seed 固定。

## 2. 券種序列の対象（固定）

AI 順（p_win 降順）上位馬による 8 券種の 1 点買い、各 100 円、全レース：
単勝(AI1)・複勝(AI1)・馬連(AI1-2)・馬単(AI1→2)・ワイド(AI1-2)・枠連(AI1-2 の枠)・三連複(AI1-2-3)・三連単(AI1→2→3)。
枠連は発売のある出走 9 頭以上のレースのみ（`shadow_a95.sellable_kinds` と同じ規則）。他の 7 券種は全レース。

## 3. 推定量（固定）

各券種・各レースの回収 R = 払戻 / 100（外れは 0）。

| 名前 | 定義 |
|---|---|
| `plain` | 通常 ROI = 100 × ΣR / N |
| `win_q99` `win_q95` `win_q90` `win_q75` | 券種ごとに **fit 年の的中払戻（R>0）の q 分位** を打ち切り値 c とし、評価年で 100 × Σmin(R, c) / N |
| `log_f001` `log_f01` | 対数回収（固定比率 f の Kelly 型成長率）。g = mean log(1 + f (R − 1))、確実性等価 ROI = 100 × (1 + (exp(g) − 1)/f)。f = 0.001 と 0.01 を**先験的に固定**（fit しない） |

- 打ち切り分位は **fit 年で決め、別の年で評価する年ローテーション**。一次は **fit=2023 → 評価=2024-25**。副次として fit=2024 → 評価 2023+2025、fit=2025 → 評価 2023-24 も同じ手順で出す（記述のみ）。
- bootstrap では fit 年の日も同時に復元抽出し、打ち切り値をその都度再推定する（打ち切り値の不確実性を SE に含める）。
- 対数回収は ROI とは別の推定対象（分散罰つき）であることを前提に、frontier 上の位置だけを見る。
- バイアスは「同じ評価データでの `plain` との差」（推定対象のずれ）として報告し、差の SE も bootstrap で出す。
- SE の比 = SE(推定量) / SE(plain)、同じ評価データ・同じ bootstrap 複製で比較。500R 換算 SE = SE × √(N_eval / 500)。

## 4. 一次ゲート（これだけ）

- 統計量: 各推定量について、**fit 年（2023）での 8 券種の序列** と **評価年（2024-25）での序列** の Kendall τ_b（年を跨いだ序列の再現性）。
- 95% CI: fit 年と評価年の日を独立に復元抽出した bootstrap のパーセンタイル区間（打ち切り値は fit 側の複製で再推定）。
- **判定: τ の 95% CI が 1 を含むか（上限 = 1 か）だけ。** 含む → 「年を跨いで序列が完全一致と区別できない（安定）」。含まない → 「序列は年で入れ替わっている（不安定）」。
- 推定量ごとに判定する。勝ち負け・採用・方策への反映は無い。

副次（記述のみ、ゲートにしない）:
- τ_boot: 評価年内で、bootstrap 複製の序列と全標本の序列の τ（標本ノイズによる揺れ）。
- τ_target: 各推定量の評価年序列と `plain` の評価年序列の τ（推定対象のずれが序列を変えるか）。
- 副次ローテーション 2 方向の τ。

## 5. a95 の裾依存（記述と SE のみ）

- 凍結表 `data/shadow_policies/a95_equal_v1.json`（sha256 `0119f043…30ff`）の帯×券種・均等配分（1R 1 万円、100 円格子、枠連は 9 頭以上のみ）を **読むだけ**（import した関数でなく同じ規則を再実装、ファイルは変更しない）。帯は substrate の 9 時オッズ（凍結表の作成と同じ）。
- 注意: 凍結表は 2023-25 全期間の表から作られたので、2023-25 での a95 ROI は **in-sample**。ここで確定させるのは水準ではなく SE と裾依存度。
- 指標（全期間 2023-25 と 評価年 2024-25 の両方）:
  - ROI と SE（1 レース回収率 SD、500R 換算 SE）
  - レース単位の払戻（そのレースで当たった券種の合計）で、**上位 1% / 上位 5%（的中レース中の割合）/ 上位 10 本** を除いた ROI
  - 裾シェア = 上位 k の払戻合計 / 全払戻合計
  - ROI を 100 / 95 未満に落とすのに要る上位払戻の本数（元が上回る場合のみ）
  - いずれも開催日ブロック bootstrap で、複製ごとに上位 k を数え直して SE を出す
- 2023 で決めた打ち切り値による a95 の winsorized ROI と対数回収（2024-25 評価）、SE の比。
