   同じレースの先の馬の結果が混入している（21,539 行）。§5 で別枠に数えた。
3. **（今回の計測で判明）除外・中止・失格の行**: 学習側の騎手・調教師・馬の直近集計は、着順欠損の 5,191 行（フラグ 0）を窓に含めて計算した後で
   その行を master から落としている。配信側の履歴にはその行が無い。同じ行集合で学習定義を計算し直せば配信側と完全一致するので（§5-A）、
   差はこの行の有無だけで説明できる。同日先行レースの無い行でも、窓 30 で約 6〜7%、窓 90 で約 16〜18% の行の格納値が、
   配信側では再現できない値になっている（騎手 7.4% / 18.1%、調教師 5.6% / 16.2%）。
4. いずれも再学習・データ差し替えを伴うので別 Gate とする（2026-10-04 決定）。§4-C の基準（配信経路の◎top3 率が学習時特徴より
   1.0pt 以上低く、差の CI が 0 を含まないときだけ差し替えの別 Gate を検討）に照らした結果は §5-C（該当しない）。
