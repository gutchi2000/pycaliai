## 結論

**B\* = 2,000 円**（主母集団で Δ = −0.03pt [−0.10, +0.04]、券種落ち 0 件）。2,000 以上はすべて合格、1,000 と 500 は不合格。

- **券種落ちは B ≥ 500 では 0 件**。plan の最大券種数は 5（5-8倍帯）なので、500 円あれば全券種に 100 円ずつ置ける。400 円以下で初めて落ちる（記述のみ）。
- **Δ の正体は丸めによる非均等配分**。端数を plan の先頭券種へ寄せるので、B が券種数で割り切れないと先頭（2-3倍/3-5倍帯の馬連、8-15倍帯の単勝）が厚くなる。
  2,000 円は 1/2/4/5 券種で割り切れるため、10,000 円と違うのは 3 券種帯（8-15倍: 700/700/600 と 3,400/3,300/3,300）だけになる。非均等なレースの割合は 2,000 と 10,000 がともに 4.7%、1,000・3,000・5,000 は 62〜67%。
- B が 2,000 → 1,000 → 500 と下がると、非均等配分が 2-3倍・3-5倍帯の馬連（その帯で ROI が最も低い券種）に寄るので Δ は負に振れる。

## まとめ（real_money 再開時の規模の正本）

- 1R 予算は **2,000 円の倍数**（100 円単位で 20 口の倍数＝1・2・4・5 券種で割り切れる。2,000 / 4,000 / 10,000 など）にすると、10,000 円の方策とほぼ同じ配分になる。最小は 2,000 円。
- 500・1,000 円は券種は落ちないが、丸めで馬連などに偏り、Δ の CI が 1pt を超える。3,000・5,000 円は合格だが 2,000 円より基準から遠い。
- ここで決めたのは「予算を縮めても方策の中身が変わらない最小値」まで。実弾を出すかどうかの判断（ROI が控除率を超えるか）とは別の話で、そちらの証拠は無い。
