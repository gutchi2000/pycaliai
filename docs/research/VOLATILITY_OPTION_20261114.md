## 1. 理論

1 走の出来 = 能力 + 運。運が正規分布なら(Thurstone)、勝率は平均だけでなく分散にも依存する。

- 平均が下の馬は、分散が大きいほど勝率が上がる(オプション価値)
- 平均が一番上の馬は、分散が大きいほど勝率が下がる。3 着内はもっと下がる

v7 の確率層(1 頭 1 スコアの softmax / Plackett-Luce)は全馬同じ運の形を仮定するので、これを表せない。
馬券を買う人たちも値付けを誤っているかもしれない、というのが検証したこと。

関連する過去の結果: EVT(極値)特徴は弱かった。`kako5_std_pos`(着順の SD)は v7 に入っている。
今回新しいのは、①出来の指数(IDM)から推定した「特性としての分散」、②Thurstone の非対称、③市場側の検定。

## 2. σ_h の作り方(as-of)

- 材料は JRDB SED の IDM。完走かつ IDM あり、芝ダ別、障害は使わない。
- 同じ馬・同じ芝ダの連続 2 走の差 d(間隔 1〜365 日)を取り、`x = min(|d|, 30)² / 2`。
  差を取るので成長や衰えのようなゆっくりした変化は消える。30 点の頭打ちは、流して大敗した 1 走が支配しないため。
- レース日 D の `σ_h² = (k·s0² + Σ_{日付<D} x) / (k + n)`。逆ガンマ事前分布の事後平均と同じ形。
  - `s0`(〜2022 の平均): 芝 5.65 点、ダート 7.04 点
  - `k`(〜2022 で「次の x」を二乗誤差最小に当てる値): **7.4**。差が 7 本あってやっと自分のデータと母集団が半々
  - 差が 0 本の馬は σ_h = s0
- as-of の自己点検: 300 行を「日付 < D の走だけ」から作り直して全て一致(不一致 0)。同じ馬の同日重複も 0。

### 特性かどうか(〜2022、差が 8 本以上の馬 19,120 頭)

| 分け方 | log s の相関 | Spearman–Brown |
|---|---|---|
| 前半 vs 後半(境の 1 本は捨てる) | 0.204 | 0.34 |
| 重ならない差を交互に | 0.162 | 0.28 |
| 前半 vs 後半・芝だけ | 0.144 | 0.25 |

帰無が 0 でないのは「ダートの方が運が大きい」という芝ダの差が残るため。それを引いても相関は残る。

理論はここでは死なない。ただし 1 頭の推定は粗い(レース内の log σ̂ の sd は 0.136 = σ にして約 14% の差)。

## 8. 判定

- 事前登録の規則どおり: A が P・M とも PASS、2024 / 2025 とも同符号で CI が 0 を外し、偽薬は none → **SIGNAL(予測)・SIGNAL(市場外)**。
  13 年分の市場回帰(2013-19、2020-25)も独立に同じ向きで CI が 0 を外す。
- 量は v7(JRDB)の市場上乗せ(−0.00085 nats/レース)と同じ桁の微小さ。◎の当たり方は変わらない。回収率 100% を超えるセルは無い。
- B(非対称)は null。C(Thurstone の厳密計算)は v7 には足しになるが市場の外には無い。IDM の平均が粗く共通 sd が 14 点と大きいため、馬ごとの分散の差が薄まった。
- 三分位表の 12 統計は null。「ムラな人気薄は買われすぎ」「堅実な本命の複勝は買われ足りない」はどちらも出ていない。

## 9. 怪しい点・注意

1. **多重性**: 同じ日に別の理論が 9 本並走している。3 変種 × 4 ゲートのうち A だけが揃って通った。test 2 年だけなら偶然を疑うが、test を含まない 2013-19 と 2020-23 でも同じ向き(z = 2.1、2.7)。
2. **解釈は確定していない**(§7)。走った回数を制御すると半分になる。「分散の特性」ではなく「キャリアの浅い馬が少し過小評価されている」の言い換えである可能性が残る。
3. **非対称が出ていない**。理論の核心(本命は分散で損をする)は未確認で、効いているのは全馬共通の主効果だけ。本命帯の単勝は 2013-19 と 2020-25 で符号が逆。
4. 事前分布の定数(s0²、k)と s_c は 〜2022 で推定。2013-22 の市場検定ではこの 4 つの数だけが同期間由来(個々のレース結果は使っていない)。
5. 三分位の境は期間 × オッズ帯の全体で切った(結果は使わないが、厳密な as-of ではない)。回帰版とゲートはこの境を使わない。
6. σ_h は JRDB の IDM から作るので、値そのものは公開できない(サイト・根拠表示に出さない)。
7. C の M ゲートは形式上 PASS だが ΔNLL −0.00001、重み 0.0005。PASS として数えない。

## 10. 再走禁止の範囲と、残るもの

再走禁止(同じ設計で繰り返さない):
- `log σ_h × 人気薄度` の交互作用(B)と、IDM 平均を土台にした不等分散 Thurstone(C)を市場ゲートにかけること
- σ 三分位 × オッズ帯の単勝・複勝の均等買い(回収率は 73〜88%、差は全て CI が 0 を跨ぐ)
- 「ムラな人気薄の買われすぎ」「堅実な本命の複勝の買われ足りなさ」を馬券ルールにすること
