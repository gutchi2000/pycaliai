## 1. 依頼内容

下記「未着手 8 手法」のそれぞれについて、次の 3 点だけを答えてほしい。

- (a) **v6 の 120 特徴 + 締切市場オッズに含まれていない情報**を、具体的にどのデータ列から取るのか。関数形や推定量の違いだけなら「情報は同じ」と明記すること。

## 3. 死亡ルート（提案禁止）

以下は全て本番 v6 土俵で敵対的に検定済み。名前を変えて再提案しないこと。

**予測層（特徴・アーキテクチャ）**
- 特徴追加全般（物理・EVT・統計力学・クラス変動・回り適性・セリ価格・ラップ・馬体重・調教・不利代理・トラックバイアス・当日馬場状態・カードカウンティング）→ priced または無効
- 対戦相手ネットワーク（1-hop / 2-hop / Hodge 射影 / PageRank 前段）→ placebo で FAIL
- 階層ベイズ（低頻度ペア）→ 母集団選択バイアスで仮説撤回
- レジーム分離（夏専用 / 手動条件分割 / 不変特徴選別）→ 3 件独立に否定
- Race-as-a-Set / Set Transformer / Transformer-PL → ΔBrier 非有意
- 直接着順学習 / 欠損頑健 LambdaRank / near-tie collapse → FAIL
- 低重要度特徴の剪定 → 有意悪化
- 動的能力 / 潜在状態分離 / 陣営選択の逸脱 → 市場込みで固有価値なし

**市場層**
- オッズ軌跡 / CLV / money-flow 特徴 → 死亡（pari-mutuel で CLV は換金不能）
- 市場内部裁定（複勝/単勝の整合）→ 非効率実在も控除超えず
- クロスプール（馬連→枠連、ワイド↔馬連、三連複トモグラフィ）→ signal は床の 1/6〜58%、経済価値 1e-4/R 以下
- 市場デジタルツイン + EV 分位選抜 → 停止
- オッズ帯別 ROI（Favorite-Longshot）→ 大穴 1 帯の崖のみ、他は平坦

**馬券層**
- EV 閾値 / EV 帯選抜 / UMAMI 駆動選抜 → 有害または印と同等
- Kelly / 分数 Kelly / 対数成長最適化 → 期待値の符号を変えない
- 三連複フォーメーション各種 / ワイド専用 AI 210 config / 枠連 / WIN5（繰越含む）/ 三連単 → 全て控除壁内
- 「トリガミ床」→ 配線済み、ROI 中立（当たりの形だけ改善）
- 「消しモデル × 合成印」→ 全否定

## 5. 評価プロトコル（この土俵で通らない提案は採用しない）

1. **市場条件付き**: 比較対象は常に「v6 較正確率 + 締切市場」。v6 単独に勝っても無価値。
2. **実務床**: Δlogloss ≥ 0.0117（レース単位、開催日ブロック bootstrap CI が床を除外）。
3. **placebo**: 同じ構造のランダム / シャッフル特徴で同じ改善が出ないこと。
4. **as-of**: 母集団定義・集計は全てレース日より前の情報のみ。full-period count 禁止。
5. **早期棄却**: 2023 年内 meeting-day forward-chaining CV で FAIL なら 2024/25 を開封しない。
6. **救済禁止**: FAIL 後に統制変数を減らす、閾値を動かす、部分集合で再検定する、は不可。
7. **経済評価は最後**: 上記を通過して初めて ROI を見る。ROI は prob-first 均等額を基準に paired bootstrap。
