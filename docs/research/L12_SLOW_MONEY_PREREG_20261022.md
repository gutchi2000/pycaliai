| 項目 | 定義 |

| オッズ | `data/Time _series_odds/TANPUK_*.csv`（区分 1 / 4、各馬 `{n}単`） |
| 勝ち馬 | `data/master_v2_20130105-20251228.csv` の `着順 == 1`（同着 = 勝ち馬 2 頭以上のレースは除外） |

## 2. スナップの定義

| 名前 | 定義 |
|---|---|
| `eve` | 前日の区分 1 のうち最も遅いもの（22〜23 時台） |
| `am` | 当日の区分 1 のうち最も早いもの（8〜9 時台） |
| `pre` | 当日の区分 1 のうち、確定時刻より 15 分以上前で最も遅いもの。ただし `am` と同一行なら欠損扱い（= 当日 2 本目が無いレースは pre 比較から外す）。memory `project_market_provenance_audit_20260922` の `historical_pre_snapshot`（発走 26〜30 分前）に相当 |
| `final` | 区分 4（確定）。発走の 6〜9 分後に記録される |

**de-vig**: スナップのオッズを starters だけに絞り、`1/odds` を比例正規化する（後で取り消された馬はスナップから落として正規化し直す）。

## 3. 量の定義

- レースごとの logloss: `LL_s = −log π_s(勝ち馬)`
- **吸収ギャップ**: `G_s = mean_race(LL_s − LL_final)`（nat/レース）。スナップ s の後から確定までに市場が取り込んだ情報量。**主たる量は `G_pre`**（発走約 27 分前 → 確定、狭義の「遅い資金」）
- 吸収の割合: `R_s = G_s / G_eve`（前夜から確定までの情報のうち、s 以降に入った割合）
- 遅い資金の量: `V_pre = 1 − 単勝票数(pre) / 単勝票数(final)`（レース平均）
- 本命-大穴勾配: 年ごと・スナップごとに条件付きロジット `P(i 勝) ∝ π_i^β` を最尤推定した β（β > 1 = 本命が過小評価 = 大穴過大評価）

## 4. 年次系列（記述のみ）

- 2013〜2025 の全年について `G_eve / G_am / G_pre`、`R_am / R_pre`、`V_pre`、`β_s`、スナップ時刻（確定までの分の中央値）、レース数を出す。
- EXP16A §3 に年別 PRE − Q0（2019〜2023）が既にあるので、**年次系列は H1 として検定しない（記述扱い）**。
- **2024〜2025 の方針**: 年次系列の表には載せるが**記述のみ**。断点検定・トレンドの当てはめ・placebo には使わない。モデル評価ではない市場だけの記述統計なので、EXP16A が 2024/25 に掛けた封印（モデル残差 Gate 用）とは目的が違うが、将来の確認用ホールドアウトとして断点検定からは外しておく。

## 6. 断点の検定（1 本だけ）

**統計量**:

```
D_T = G_pre(T 年, 窓 W) − Ĝ_pre(T 年, 窓 W)
Ĝ_pre(T, W) = 適格年 E∖{T} の G_pre(Y, W) に年の 1 次式を OLS で当てはめ、T で予測した値
E = {2013, …, 2019, 2022, 2023}   （2020・2021・2024・2025 は入れない）
```

- 処置年は T = 2020。
- **placebo**: 断点位置を他の年の同じ窓にずらす。E の各年 Y（9 年）について、同じ式で D_Y を出す（Y 自身はトレンドの当てはめから外す。2020 は常に外す）。
- **p 値**: `p = (1 + #{Y ∈ E : |D_Y| ≥ |D_2020|}) / (1 + 9)`（両側）。最小値は 0.10。
- **不確実性**: 開催日単位のブートストラップ（各年の窓の中で開催日を復元抽出、2,000 回、seed 20261022）で D_2020 の 95% 区間を出す。トレンド側の年もそれぞれ再抽出する。
- **判定規則（事前固定）**:
  - `BREAK`: placebo p = 0.10（= |D_2020| が 9 個の placebo すべてを上回る）**かつ** ブートストラップ 95% 区間が 0 を含まない
  - `NO_BREAK_DETECTED`: それ以外
  - placebo が 9 年しかないので、p は 0.10 より小さくなれない。「BREAK」でも強い証拠ではなく、「方向と大きさが他の年の揺らぎの外にある」以上のことは言わない。
- β・`G_eve`・`G_am`・`V_pre`・`R_pre` の 2020 窓の値は**記述だけ**で、検定しない（多重比較を作らない）。
