# 複勝専用モデル（「3 着以内」を直接学習）は、今の変換値より当たるか — 探索

作成: 2026-11-19 / 分析のみ（本番コード・本番設定は変更していない）
**位置づけ: 探索**。後半（08-16〜11-15）は過去の分析で何度も使った期間。
再現: `python -m analysis.place_model_check train --out reports/objective_check`（約 3 分）→ `python -m analysis.place_model_check eval --work reports/objective_check --out-json docs/research/PLACE_MODEL_CHECK_20261119.json`（前提: `analysis.objective_check_replay` の再生結果）
数値の正本: `docs/research/PLACE_MODEL_CHECK_20261119.json`

## 結論（先に）

1. **専用モデルは今の変換値より当たらない**。後半（8 頭以上の 751R）の複勝 LogLoss は専用 0.45859・現行 0.44533 で、差 +0.0133 [+0.0099, +0.0167]（CI 全体が 0 より上＝現行の方が良い）。Brier も同じ向き。
2. オフライン（test 2024-25、6,909R、配信の特徴の欠けが無い条件）でも専用モデルの方が悪い（LogLoss +0.0084 [+0.0075, +0.0092]）。勝敗を 2 値で学習した M1（`OBJECTIVE_CHECK_20261119.md`）と同じく、1 頭ずつ独立に当てる学習は、同じレースの他の馬との比較を使う現行（ランク学習 → PL）より不利。
3. 2026 では専用モデルがすべての確率帯で高すぎる（ECE 0.046、現行 0.013）。配信の特徴の欠け（serve skew）に、配信用の較正器を通す現行より弱い。ただしオフラインでも負けているので、較正だけの問題ではない。
4. EV ルール（複勝率 × T-10 の複勝オッズ下限）: 専用モデルは 74.9〜79.0%、現行は 83.4〜89.7% で、どちらも 100% に届かない（CI の上限は現行の最上位 1 頭で 119〜120%）。後半の全馬均等は 73.7% [70, 78]（10,400 頭）。現行の点推定は全馬均等より高いが、上位 10 払戻を除くと 48〜66% に落ちる。また前回の券種別の探索（`BET_TYPE_TERRAIN_20261118.md`）では、同じ形のルール（凍結版の複勝率 × T-10 下限の最上位 1 頭）が前半 64〜66%・後半 89〜92% と期間で大きく割れていた（今回は後半だけを評価）。

## 1. 設計（後半を見る前に固定）

| 項目 | 内容 |
|---|---|
| 専用モデル | v6 と同じ 120 特徴・エンコード・master（〜2022 で学習、2023 で早期停止）。目的関数 = 2 値 log-loss、目的変数 = 着順 1〜3（同着含む）。ハイパラは v6 から lambdarank 固有のものを除いてそのまま、標本重みなし、早期停止 100 回（上限 5,000、結果 660 回）。確率は生の出力 |
| 現行 | v6 スコア → PL の 3 着以内確率 → 配信用 isotonic（pl_calibrators_v6_serve の複勝）。2026 は凍結 bundle の開催日を現在の配信経路で再生した値（`OBJECTIVE_CHECK_20261119.md` と同じ X）。参考に公開時の凍結版 |
| 採点対象 | 中止等でない・再生 X あり・T-10 の複勝オッズありの馬（1 頭でも欠けるレースは外す: 342R）。**出走 7 頭以下のレースは外す**（複勝は 2 着までの払いで、どちらの確率も 3 着以内の確率なので合わない。41R） |
| 分割 | 前半 〜08-15 / 後半 08-16〜。専用モデルは 2026 のデータで何も fit しないので、前半は参考値。後半を 1 回だけ評価 |
| 主指標 | 3 着以内の 2 値 LogLoss の差（専用 − 現行）。確率は [0.001, 0.999] に制限。CI はレース単位の対応付きブートストラップ 4,000 回 |
| 副次 | EV = 複勝率 × **T-10 の複勝オッズ下限**、閾値 1.0 / 1.1、全該当と最上位 1 頭、払戻は確定複勝配当 |

**「最終複勝払戻」を EV の材料に使わなかった理由**: kekka には 3 着以内に入った馬の確定配当しか無く、入らなかった馬の最終複勝オッズは手元に無い。買う馬を選ぶ材料にはできないので、購入時点に近い T-10 の複勝オッズ（下限）で選び、払戻は確定配当で数えた。

**前半の扱い**: 指示の「前半 fit」に当たる調整は、この比較には無い（専用モデルは 2013〜2023 だけで作り、2026 では何も合わせていない）。前半の値は参考として並べた。

## 6. 判断

- 「3 着以内」を直接学習しても、今の「ランク学習 → PL → 較正」より複勝率は当たらない（オフラインでも 2026 でも）。複勝専用モデルを本番に入れる根拠は無い。
- EV ルールはどちらの確率でも 100% に届かない。現行の値の点推定が全馬均等より高いことは、確定させる根拠にはならない（探索・高配当頼み）。

## 7. 限界

1. **探索扱い**: 後半は過去の分析で何度も使った期間。
2. **世代混合**: 公開時の本番は v6-C0・C1・v7。比較自体は、どちらも現在の配信経路で再生した v6 の X で行った。
3. **v8 は含まれていない**（本番は 11/21 から v8）。
4. 専用モデルは較正器を通していない（現行は配信用の isotonic を通す）。専用モデルに同じ種類の較正をかければ 2026 の差は縮む可能性があるが、オフライン（配信の欠けが無い条件）でも負けているので、逆転は見込みにくい。今回はこの組み合わせを事前に定めていないので試していない。
5. ハイパラは v6 のもの（3 着以内用の再探索はしていない）。
6. EV は T-10 の複勝オッズ下限で選んでいる。実際の複勝配当は締切までに動き、下限と上限の間のどこになるかは他の馬の着順で決まる。
7. 出走 7 頭以下のレース（41R）は主評価から外した。
