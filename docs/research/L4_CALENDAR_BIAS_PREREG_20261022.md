**固定日時**: 2026-10-22（勝ち馬・logloss・層ごとの Δ を一度も計算していない時点で書いた）

**出力先**: `analysis/calendar_bias/`、`docs/research/` の新規ファイルのみ。本番ファイルには触れない。git commit / push はしない。

**needs_user（データからは作れない）**:
- **真の祝日カレンダー**: 土日に重なる祝日（例: 土曜の祝日）と、平日の代替競馬日を祝日から分けるには国民の祝日表が要る。
  `jpholiday` / `holidays` はこの環境に無く、master・TANPUK に祝日列も無い。L4b は「平日開催」proxy で検定し、
  真の祝日層は needs_user として残す（後から差し替えて再検定することはしない＝救済禁止）。
- JG1（障害 G1）併催日は障害を母集団から外しているので対象外（定義の追加はしない）。

## 4. モデルと Δ

- 条件付きロジット（レース内 softmax、切片なし）: `P(i 勝) ∝ exp(a·logπ_i + c·z_i)`
- **null N**: 評価年 Y について、2016〜Y−1 の**全レース**で (a, c) を最尤推定
- **alternative A_h**: 同じ形を、2016〜Y−1 の**層 h のレースだけ**で推定（= 全レースで `I_h·logπ`・`I_h·z` の交差項 2 本を足したモデルと同値）
- **Δ_r = LL_A(r) − LL_N(r)**、`LL = −log q(勝ち馬)`。評価年 Y の**層 h のレースだけ**で計算。**負が改善**
- 層の歪みの向き（a_h − a: 正なら層内で本命がより過小評価＝人気薄の買われすぎ）は**記述のみ**で判定に使わない

## 5. 推論

- **bootstrap**: 年層化・**暦日（全場まとめた開催日）クラスター**、B = 10,000、seed = 20261022。同じ重み行列を全層で使う
- 片側 p = (1 + #{boot 平均 ≥ 0}) / (B + 1)
- **Holm**: 片側 family α = 0.025。家族は検出力監査では 4 層全部、本検定では POWERED の層だけ
- 年別点（7 年）と leave-one-year-out 点（7 通り）

## 6. 判定（EXP25 の等級規則を 7 評価年に置き換えたもの）

| 等級 | 条件 |
|---|---|
| **ABOVE_SCREEN** | Holm 調整 p < 0.025 ∧ CI95 上限 < **−0.005** ∧ 年別点が 7 年中 **5 年以上で負** ∧ LOO 7 通りすべて負 ∧ 実値 < placebo の q0.025 |
| **SIGNAL_SUBSCREEN** | 上と同じで、CI95 上限が [−0.005, 0) |
| **FAIL** | それ以外 |

- 実務床 **0.005 nats/race**（EXP16A / EXP25 の既定値）。結果で変更しない。点推定は等級に使わない。
- **生存** = 少なくとも 1 層が ABOVE_SCREEN。生存しても ROI・買い目・本番接続には自動で進まない（別の事前固定が要る）。
- SIGNAL_SUBSCREEN は「床未満の信号」として記録のみ。実務上は閉鎖側に数える。
- **閉鎖** = 検定した層がすべて FAIL / SIGNAL_SUBSCREEN。UNPOWERED の層と合わせて**暦・番組位置の軸を一括で閉じる**。

## 7. placebo（本検定のみ、各層 200 draw、ラベルを付ける単位で並べ替える）

| 層 | 並べ替え |
|---|---|
| L4a_R12 | 各 (日付, 場) の正式レースから 1 R を一様に選んでラベル（R12 の構造＝1 日 1 場 1 R を保つ） |
| L4b_WEEKDAY | 年の中で暦日を並べ替え、ラベル付き暦日の数を保つ |
| L4c_KAI_LAST | 年の中で (日付, 場) を並べ替え、ラベル付き (日付, 場) の数を保つ |
| L4d_G1DAY_OTHER | 年の中で (日付, 場) を並べ替え、数を保つ（選ばれた日・場の全正式レース。G1 レースは本物の層定義でだけ除く） |

条件: 実値の pooled Δ < placebo pooled Δ の 2.5 パーセンタイル。

## 8. 検出力監査（先に実行、勝ち馬を読まない）

- 合成真値: `log p = logπ + b · I_h · w`（層 h の race だけ傾ける。他は市場どおり）。
  方向 w は **2 本**: `logπ`（層内の本命-大穴勾配の変化＝仮説の向き）と `z`（層内で v6 の重みが変わる）
- b は、2017〜2023 の層 h のレースでの真の期待改善 `mean KL(p ‖ N*)` が目標値になるよう二分探索で較正
  （N* は 2017〜2023 全レースでの期待対数尤度最良の (a, c)）
- 各反復で全レースの勝ち馬を合成 → **§4〜§6 と同じ手順**（rolling fit・bootstrap・Holm 4 層・年・LOO）。placebo は通過扱い
- 反復数: 零効果 1,000、床 0.005 は層×方向ごとに 400、power curve（方向 logπ、目標 0.0025 / 0.0075 / 0.01 / 0.015 / 0.02 / 0.03）は各 100
- **POWERED** = 床 0.005 で P(SIGNAL_SUBSCREEN ∪ ABOVE_SCREEN) ≥ **0.80** を**両方向とも**満たす層。それ以外は UNPOWERED で、勝ち馬を開けない
- 零効果で「どれか 1 層でも SIGNAL」の割合の Wilson 95% 上限が 0.05 を超えたら停止（本検定に進まない）
- 層ごとのレース数（全期間・評価年）、MDE（power 0.8 の補間、記述）を報告
