## 4. 結論と扱い

- 2016〜2023（OOF がある期間すべて）では、どの暦層でも実務床 0.005 nats/race の層固有の歪みを 0.8 の確率で検出できない。
  検出できるのは、層あたり **0.010（開催最終日）〜0.014（12R・G1 併催日）nats/race 以上**の大きな歪みだけ（平日開催は 0.03 でも届かない）。
  これは「歪みが無い」という証明ではない。**この軸はこのデータ量では検定できない**、という結論。
- 事前固定の §8・§9 に従い、**暦・番組位置の軸を検出不能（CLOSED-UNPOWERED）で一括閉鎖**する。
  層の統合、期間の延長、2024/25 の開封、閾値の変更、層の追加で救済はしない。
- 再開できる条件は「新しい観測量」だけ（EXP25 以後の 3 点ゲート）。暦ラベルはすべて既存列からの派生なので、この軸で新しい番号は立てない。
