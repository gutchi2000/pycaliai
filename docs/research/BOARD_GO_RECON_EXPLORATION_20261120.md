1. **推定人気モデルの学習期間**: `speed_index.py cmd_market_train` は 2013〜2022 年で学習（`x["year"].between(2013, 2022)`）。予測指数モデルも 2013〜2022、場の癖の補正（course_offsets）と 100 の中心合わせも 2014〜2022、騎手成績は前年分。**対象レース（2026 年）より後のデータで学習したものはない**。今回のレースの確定単勝オッズは学習の正解に使うだけで、入力には入っていない（入力は 1〜3 走前の人気・オッズ、騎手の前年成績、枠、斤量、過去走の指数）。→ 人気ゲージに未来情報は見つからなかった。
2. **ゲージのコードの変更履歴**: どのゲージも、対象期間（2026-06-13〜11-15）中には存在しなかった。値はすべて期間後に計算したもの。
   - 速度・推定人気: `speed_index.py`（d557331d 11/15 22:09、e1f1de3a 11/15 22:33、5bd292cd 11/20 21:24 = build の調教 JOIN を省くだけ）。2026 年の過去日の `reports/speed_index/day_*.json` 97 本は **11/15 22:29 の 1 回の score-days でまとめて作ったもの**で、全日同じコード版。
   - PW: `power_rating.py`（最終変更 11/12）。`history.csv` の「R前」（レース前のレーティング）を使う。100 点の物差しは 11/20 時点の現役最上位で決まるが、芝・ダート別の線形変換なので、レース内の 1 位は変わらない。
   - ボード集計: `build_board_stats.py` / `board.js`（5bf13ef6 11/16 以降、一致数の定義は不変。11/18 の変更は混戦度の表示だけ）。

3. **確定値を使っている入力**: 速度ゲージ（予測指数）と人気ゲージ（推定人気）は、どちらも **そのレースの確定馬場状態**（`going_n`）と確定斤量を入力に使う（`score_days` が実走の行から `going` / `weight` を上書き）。朝の公開時点では発表済みの馬場状態だった。結果そのもの（着順・タイム・確定オッズ）は入っていない。PW は着順だけから作るので該当なし。GO・難しさ・印・◎のオッズは凍結版 bundle の値で該当なし。
