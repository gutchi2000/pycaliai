## 結論（先に）

1. **馬（確定オッズ）= リバーサル**。過去に「オッズの割に 3 着内に来た」馬は単勝が買われ過ぎ、「オッズの割に来なかった」馬は買われなさ過ぎ。
   実勝/市場の Q5/Q1 は **0.90 [0.87,0.93] / 0.89 [0.86,0.93]**（2013-19 / 2020-25）。ゲートも M0・M とも PASS（ΔNLL −0.0012 / −0.0015）。
   ただし中身の半分ほどは既知の「前走 2-3 着は買われ過ぎ・凡走明けは買われなさ過ぎ」（市場の癖の地図）の言い換え。
2. **馬（10 時オッズ）= モメンタム**（1.14 / 1.15）。朝の市場は前走の結果を織り込み切れておらず、締切までの資金が直す。確定では少し行き過ぎる。
   カルマン直近重みの検定（朝は直近軽視・確定は中立）と同じ絵で、「着順（馬券圏内）」という物差しにすると確定の行き過ぎが見える。
3. **種牡馬×芝ダ = モメンタム**（1.13 / 1.09、確定・10 時とも）。**調教師・生産者 = 弱いモメンタム**（1.05〜1.07）。**騎手・騎手×調教師 = none**。
   ただし状態を 1 年前・2 年前のものに差し替えても同じだけ効く（事後点検 E4）＝「遅れて学習している」のではなく
   **市場が何年も直さない小さな固定の癖**。理論の言う動学（遅い更新 → 追いつく）ではない。ゲートは種牡馬 top3 だけ PASS、他は none か WORSE でまちまち。
4. **市場の学習率（馬の前走 1 走）は最適の ±10% 以内**: 朝は最適の 0.93〜0.97 倍（少し遅い）、確定は 0.99〜1.09 倍（3 着内サプライズにだけ少し速すぎ）。
5. **馬券にはならない**。どの五分位も単勝均等買い 61〜84%（控除率 20% の内側）。良い側の群でも種牡馬 Q5 79〜81%、馬 Q1 78.5〜83.5%。

## 1. 理論

金融市場では価格がサプライズに遅れて反応し（決算後ドリフト）、後で行き過ぎる。パリミュチュエルの群衆も学習者で、
各レースは「その馬・厩舎・種牡馬についてオッズがどれだけ外れたか」を 1 回ずつ見せる。更新が遅ければ「オッズより走ってきた」主体は
買われなさ過ぎのまま残る（モメンタム、実勝/市場 > 1）。行き過ぎなら逆（リバーサル）。どちらでも両期で安定なら、定義上 市場の外の情報。

既存結果との関係（繰り返さず引用）: 市場の癖の地図（`MARKET_BIAS_ATLAS_20261107.md`: 前走 2-3 着は買われ過ぎ、凡走明けは 5〜9.9 倍で買われなさ過ぎ、
100% 超のセルなし）、カルマン直近重み（`KALMAN_RECENCY_20261114.md`: 確定 none、朝は直近軽視）、顕示選好（`REVEALED_PREFERENCE_20261114.md`: none）。
v7 は `kako5_pos_vs_ninki`（近 5 走の着順−人気）を持っているので「最近人気より走った」こと自体はモデルが知っている。ここで問うのは市場の反応。

## 2. 事前登録（スクリプト docstring に、確認期間の結果を見る前に固定）

- 出走馬 = 確定単勝オッズ >0 かつ取消・除外でない馬。市場勝率 p = (1/単勝オッズ) のレース内正規化。10 時市場 p10 も同じ（全頭に 10 時オッズがあるレース）。
  中止・失格は 1 着=0・3 着内=0・着順=頭数。障害は履歴からも除外。
- **走ごとのサプライズ**（履歴は常に確定オッズ基準）
  - (a) `s_win` = 1着 − p
  - (b) `s_top3` = 3着内 − q3。q3 は p から Harville の 3 着内確率を出し、2011-12 の全走でロジスティック再較正（2013-25 の 実 3 着内/Σq3 = 1.001）
  - (c) `s_rank` = (人気順位 − 着順) / 頭数
- **主体ごとの as-of 状態** = サプライズの指数減衰平均を 0 へ縮小。レース日 D の状態は日付 < D の走だけ（同日の他レースは不使用）。
  1 開催日ぶん（n_d 走、合計 s_d）をまとめて S ← λ^{n_d}·S + s_d、N ← λ^{n_d}·N + n_d、λ = 0.5^(1/半減期)。状態 = S/(N+k)、適格 = N ≥ N_min。
- **変種（主体あたり 3 本、計 18 本。全部報告）**。半減期・k・N_min は事前に固定した値でデータに合わせていない。

| 主体 | 変種 | 半減期 | k | N_min | 履歴の開始 |
|---|---|---|---|---|---|
| 馬 | top3 / top3 / rank | 3 走 / 10 走 / 3 走 | 2 | 1 | 2011 |
| 調教師・騎手・種牡馬×芝ダ・生産者 | win / top3 / rank | 200 走 | 50 | 30 | 2013 |
| 騎手×調教師 | win / top3 / rank | 50 走 | 20 | 10 | 2013 |

- 検定期間: 馬は 2013-19 / 2020-25。他の主体は master が 2013 開始なので 2013 年を助走にして 2014-19 / 2020-25。
- 検定母集団: 適格馬が 4 頭以上いるレース。z = 適格馬内のレース内標準化、検定期間プールの五分位（Q5 = 過去に市場を上回ってきた側）。
- 主指標: 実勝/市場 = Σ1着/Σp、**C = Q5/Q1**、開催日クラスタ bootstrap（B=2000）。C補正 = 期待勝に本命-大穴補正（オッズ帯別の実勝/市場）を掛けた版。
  γ = 条件付きロジット 1着 ~ log p + (log p)² + γ·z（開催日クラスタ頑健 SE）。
- **判定**: C・C補正の CI95 が両期で 1 を除外し同じ向き、かつ γ も両期で同符号かつ 0 を除外 →「実在」。C>1 モメンタム、C<1 リバーサル、他は none。
  18 本を見るので帰無仮説の下で 1 本が偶然通る確率は約 2%。主体の判定 = 3 変種のうち 1 本でも実在ならその向き。
- ゲート: 18 変種を 1 本ずつ + 6 主体の top3 状態を同時に入れた 1 本。本丸は M0（確定市場 → +z）と M（確定市場+v7 → +z）。

カバレッジ（検定対象の馬/全出走馬）: 馬 89.9%、調教師 99.1%、騎手 98.7%、種牡馬×芝ダ 94.4%、生産者 95.0%、騎手×調教師 70.9%。
レース数は各期 約 2.0〜2.1 万（馬 21,271 / 18,173、他 約 19,950 / 19,980）。

## 9. 注意・怪しい点

- **種牡馬の偏りは「学習速度」の名に値しない**。E4 のとおり静的。人気種牡馬の買われ過ぎ・地味な種牡馬の買われなさ過ぎのような別の属性の代理である可能性が高く、
  市場の癖の地図（属性 25 次元）に種牡馬×芝ダの as-of 実勝/市場を 1 次元足した、と読むのが正確。原因の切り分けはしていない。
- **ゲートの結果が変種で割れる**（種牡馬 win WORSE / top3 PASS、騎手 rank PASS / win・top3 WORSE）。valid 1 年の重み推定が効果より粗い。
  主体の状態については「両期の A/E では通るが、1 年 fit の前向き合成では再現が不安定」が正直な状態。PASS の変種だけを拾って主張しない。
- **馬の top3 状態はオッズと強く相関**（Q5 の中央オッズ 7 倍、Q3 は 55 倍、z と log p の相関 +0.29）。C補正・(log p)²・オッズ帯別（E2）で点検し、どれでも残る。
- 馬の rank 変種は none（2013-19 は 1.005）。リバーサルは「人気より上に来た」一般ではなく「3 着内」という閾値に結びついている。着順そのものへの反応。
- 調教師コードは master の値をそのまま使った。転厩馬で「最新の厩舎」に上書きされている可能性は未確認（馬主列と同じ種類の問題があり得る）。
  調教師の結果は元々弱いので結論には響かないが、調教師を使う後続研究は確認が要る。種牡馬・生産者は不変なので影響なし。
- 騎手・調教師・種牡馬・生産者の履歴は 2013 年開始で、2014 年初めの状態は 1 年ぶんしかない（N_min=30 と縮小 k=50 で抑えている）。
- 10 時市場の検定でも履歴は確定オッズ基準。10 時オッズ基準のサプライズは作っていない。
- 学習率の κ\* は市場を条件にしない結果モデルの係数で、上に書いたとおり目安。
- 事後追加 E1〜E5 は結果を見てから足した。E5（馬 win 状態）は馬の 4 本目の変種にあたるので判定に入れていない。
- 回収率は文脈として載せただけで、セル探索はしていない。最大は馬 top3 Q1（確定、2013-19）の 83.5%、2020-25 は馬 rank Q1 の 81.7%（種牡馬 top3 Q5 は 80.5%）。控除率の線（80%）の前後。

## 10. 再走禁止の範囲と、残した問い

再走しない:
- 馬・調教師・騎手・種牡馬×芝ダ・生産者・騎手×調教師の「市場誤差の指数減衰記憶」（win / top3 / rank サプライズ、半減期 3〜200 走）を、
