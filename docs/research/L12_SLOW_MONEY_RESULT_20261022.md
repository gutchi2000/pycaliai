`G_s` = スナップ s と確定の logloss の差、`R_s = G_s / G_eve`、`V_pre` = 確定票数のうち pre 以降に入った割合、β = 条件付きロジット `π^β` の指数（β > 1 なら本命が過小評価）。各年の `G_pre` の標準誤差は約 0.0045、β の標準誤差は最大 0.027。

読めること（すべて記述）:

1. **遅い資金が運ぶ情報は増えている**。`G_pre` は 0.03 → 0.05〜0.06、`R_pre` は 0.20 → 0.35〜0.40。確定オッズの精度（LL_final）も 2.01 → 1.89〜1.93 に上がったが、平均頭数が 14.5 → 13.7 に減っているので、その分は機械的に下がる部分を含む。
2. **前夜オッズの情報不足 `G_eve`** は 2013〜2020 年に 0.15 → 0.10 と縮み、2021 年以降は 0.13〜0.15 に戻っている。当日朝 → 確定の `G_am` は 0.05 → 0.08 に増えた。前夜の段階で付く価格の比重が下がり、当日に価格が決まる比重が上がっている、と読める。
3. **票の量で見ると、確定票数の約 81% が発走 27 分前より後に入る**。この割合は 2013〜2021 年はほぼ一定で、2022 年以降に 84〜85% へ上がった。プールの総量は 2.3 倍になっている。
4. **本命-大穴勾配**: 確定時点の β は 1.00〜1.06 で、比例 de-vig 後はほぼ勾配なし。27 分前の β は 1.09〜1.16 で、本命が過小評価されている。遅い資金が本命側に寄って勾配を消している、という形がどの年にも出ている。
5. スナップ時刻は安定している（pre は発走 27〜28 分前、確定の 34〜35 分前）。am スナップは 2023 年以降 9 時台の比率が増えたが、確定までの中央値は 255〜257 分で変わらない。

## 4. 日付の裏付け（記述）

- 2020 年の開催日ごとの `V_pre`（`out/daily_2020.csv`）には、2/29 の前後でも 10/10 の前後でも、はっきりした段差は無い。目立つのは 4 月中旬〜5 月（緊急事態宣言の時期と重なる）に 0.84〜0.85 へ上がったことで、6 月以降は元の水準に戻っている。
- したがって、**無観客期間の日付をデータから決めることはできなかった**。暫定日付（2020-02-29〜10-04）のまま **needs_user**。もし公式の日付がずれていても、窓 W はほぼ 7 か月あるので、数日の違いで結論が変わる可能性は低い。ただしウインズの再開時期が窓の途中だった場合は、「ネット投票 100%」の期間が W より短くなる。

## 5. 解釈の限界

- **検出力**: placebo が 9 年分しかなく、p は 0.10 より小さくなれない。年ごとの窓 `G_pre` のばらつき（placebo D の SD は約 0.005）と、ブートストラップの SD 0.0065 から考えると、約 0.012 より小さい断点は原理的に検出できない。今回の D = −0.009 はその下にある。
- **交絡**: 2020 年はコロナ禍そのもの（在宅需要で確定票数が前年比 +14%）、番組の変更、新規のネット投票者の流入が無観客と同時に起きている。仮に断点が出ていても、それを観客の不在に帰属させることはできない。
- **スナップの解像度**: 当日の途中スナップは朝と発走約 27 分前の 2 点しかない。「場内の締切直前の資金」と「ネットの締切直前の資金」を分けられない。確定オッズは発走の 6〜9 分後に記録されるので、締切までのすべての資金を含む。
- **logloss の尺度**: 平均頭数が年ごとに変わる（14.5 → 13.7）。`G` は差なので影響は小さいが、0 にはならない。
- **トレンド**: 線形トレンドを事前に固定した。2013〜2016 年が上下に揺れているので、トレンドの当てはめそのものが不安定（2015 の placebo が大きいのもこのため）。
- 2021 年（部分制限・無観客の再発）と 2024〜2025 年は記述だけで、検定には使っていない。
- **ROI への含意は書かない**。遅い資金の情報量が増えていることは、締切前の価格で判断する本番ライン（T-10・T-20）から見て確定オッズとのずれが年々大きくなる、ということを示唆するが、これは構造の記述であって、レバーではない（CLV は換金不能 — memory `project_odds_trajectory_clv_dead`）。
