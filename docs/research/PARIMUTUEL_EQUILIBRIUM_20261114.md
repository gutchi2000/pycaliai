# パリミュチュエル均衡と本命-大穴バイアス: どの理論が JRA の単勝市場に合うか (2026-11-14)

スクリプト: `lab/experiments/parimutuel_equilibrium_exp.py`（実行 `python -m lab.experiments.parimutuel_equilibrium_exp`、約 4 分）
出力: `reports/parimutuel_equilibrium_exp.json`
データ: `data/_joint/tanpuk_all_drift.parquet`（全馬の 朝 9 時 / 発走約 28〜35 分前 (T-28) / 確定 単勝オッズ）、`data/_joint/tanpuk_fav.parquet`（T-28 と確定の単勝票数）、
`data/kekka_20130105-20251228.csv`（単勝払戻）、`data/master_v2_*.csv`（クラス・障害判定）。平地 8 頭以上・同着なし、**40,685 R / 578,636 頭**（2013-2025）。

## 0. 結論

- **確定オッズの FLB はほぼ消えている。** 条件付きロジットの傾き β（β>1 = 本命が売れ不足）は確定で **1.012 [1.000, 1.025]（2013-19）/ 1.034 [1.020, 1.050]（2020-25）**。
  T-28 時点では **1.113 [1.100, 1.128] / 1.130 [1.116, 1.147]**。締切前の約 30 分に入る資金（確定票数の約 82%）が、傾きで見た FLB の約 9 割を消している。13 年すべての年で β_pre > β_fin（差 0.07〜0.11）。
- **確定オッズの β は、どのレジームでも両期で再現する差が出なかった。** 票数規模・遅い資金の厚さ・遅い資金の情報量・朝の書き換え量・G1・G1 の日・新馬・頭数の 8 軸すべてで、「両期で同符号かつ CI が 0 を跨がない」を満たすものは 0。
- **3 理論のどれも、確定市場については予測どおりの差を作っていない。** 素人参加（危険愛好）が予測する「G1・G1 の日・大きい票数で FLB が強い」は出ない。O–S の「参加者が多いほど強い」も出ない。Shin の「遅い資金が多いほど強い」はむしろ逆向き（2013-19 で −0.045 [−0.075, −0.012]、2020-25 は有意でない）。
- 両期で再現したのは **T-28 の市場**についてだけ: (a) 票数が大きいほど β_pre が小さい（−0.039 / −0.065、両期 CI 0 外）、(b) その後の遅い資金が厚いレースほど β_pre が大きい（+0.104 / +0.105）。
  → **FLB は「早い時間帯の薄い市場」の性質で、締切直前の資金（情報を持った資金）が本命側へ買い直して消す**、という絵が一番合う。O–S の「遅い情報付き賭け」(timing) の話、あるいは単純に効率的な最終価格の話であって、確定オッズに残る FLB の強さを説明する理論の判別にはならない。
- **実用: 1 番人気の単勝・複勝が予測可能に 100% を超えるレジームは無い。** 両期の悪い方の回収率で最上位は「遅い資金の情報量 上位 3 分位 × 確定 1.0〜1.4 倍の複勝」101.9 / 100.1 だが、n = 74 / 83（年 11 点）、CI 下限 95 前後、確定オッズを使う（買う時点では分からない）レジームで、約 60 セルの中の最大値なので偶然の範囲。発走前に分かるレジームでは 100.2 / 98.7 が最大。既知の 1.0〜1.4 倍複勝 97〜98% から動かない。

## 1. 3 つの理論と予測（事前登録、スクリプト docstring に固定）

| 理論 | 仕組み | 票数規模 POOL | 遅い資金 LATE / LINFO | G1・G1 の日 | 新馬（情報非対称） |
|---|---|---|---|---|---|
| Ottaviani–Sørensen（私的情報を持つ多数の同時参加者の均衡） | 私的情報が価格に入りきらず、本命の事後確率が過小評価 | + | (+) / + | +（参加者が多い） | + |
| Shin 型インサイダー | 情報を持つ資金の比率が高いほど FLB | − （素人資金で薄まる） | + / + | − | + |
| 危険愛好・素人参加 | 素人が小さい確率を過大評価して大穴を買う | + | 0 / 0 | + | −（素人が少ない） |

POOL と G1 の符号で Shin と（O–S・素人）が分かれ、新馬と LATE で O–S と素人が分かれる設計。

## 2. 代理変数と FLB の測り方

| 名前 | 定義 | 分かる時点 |
|---|---|---|
| POOL | log(確定単勝票数) − 直前 365 日（当日除く）の中央値。2013 年は参照が無いので除外 | 締切（結果前） |
| LATE | log(確定票数 / T-28 票数) を T-28 の分数で 2013-16 に回帰した残差 | 締切 |
| LINFO | log KL(確定の確率 ‖ T-28 の確率) = 最後の約 30 分の書き換え量 | 締切 |
| EINFO | log KL(T-28 ‖ 朝 9 時) | 発走前 |
| GRADE | G1 / 重賞 / OP（3勝含む）/ 条件 / 未勝利 / 新馬 | 発走前 |
| G1DAY | G1 開催日の非重賞レース vs それ以外の日の非重賞 | 発走前 |
| FIELD | 8-11 / 12-15 / 16-18 頭 | 発走前 |

- 連続量の 3 分位境界は 2013-16 で固定（POOL −0.133 / 0.239、LATE −0.097 / 0.178、LINFO −3.67 / −3.07、EINFO −4.18 / −3.46）。
- 相関（2013-16、Spearman）: POOL–LATE −0.45、POOL–LINFO −0.44、LATE–LINFO 0.63。票数の大きいレースほど遅い資金の比率は小さい。
- FLB 主指標: 条件付きロジット P(i 勝ち) = p_i^β / Σ p_j^β（p = 単勝オッズの逆数を正規化）。β_fin = 確定、β_pre = T-28。副指標: 単勝回収率（確定 <5 倍）−（≥50 倍）、1 番人気（確定）≤1.9 倍の単勝・複勝、1.0〜1.4 倍の複勝。
- CI は開催日クラスタ bootstrap 400 回。判定は両期（2013-19 / 2020-25）で同符号かつ両期とも CI が 0 を跨がないこと。

## 4. どの理論が支持されるか

1. **確定市場の FLB の強さを規定する変数は見つからなかった。** 傾きで見た確定市場の FLB は β ≈ 1.01〜1.03 と小さく、3 理論が予測する方向の差（素人: G1・票数で +、O–S: 票数で +・新馬で +、Shin: 遅い資金で +）はどれも両期で出ない。この意味で 3 理論とも**判別に足る証拠が無い（全理論 null）**。
2. 唯一頑健なのは「T-28 の FLB が大きく、締切直前の資金がそれを消す」こと。票数の薄いレースほど T-28 の FLB が強く（β_pre の POOL 差 −）、遅い資金の比率が高いレースほど T-28 の FLB が強い（LATE 差 +）のに、確定ではその差が消える。
   - これは「早い時間の少額資金が大穴寄りに散らばり、締切直前の大口資金が本命へ寄せて直す」構図。O–S（2006）の「情報を持つ参加者は遅く賭ける」とは整合し、**素人・危険愛好モデル単独では説明しにくい**（素人の偏りが残るなら確定にも残るはず）。
   - Shin の予測（遅い資金が多い → 確定の FLB が強い）とは逆向き（2013-19 で有意に負、2020-25 は 0）。パリミュチュエルでは「インサイダーの資金」が値段を正しい方向へ動かすので、ブックメーカー型の Shin 予測はそのまま当てはまらない、と読むのが自然。
3. FLB は傾きの問題というより**裾（≥50 倍）の問題**。β が 1 に近いのに <5 倍と ≥50 倍の回収率差が 20pt あるのは、大穴の末端だけが過剰に買われているため。末端の偏りの強さもレジームで再現的には変わらない。

## 5. 実用の答え

- **1 番人気の単勝・複勝が予測可能に 100% 以上になるレジームは無い。** 唯一の 100 超（LINFO 上位 × 1.0〜1.4 倍複勝）は、(i) 確定オッズと確定票数でしか判定できない（買う時点で未知）、(ii) 年 11 点、(iii) 約 60 セル（7 軸 × 水準 × 3 券種）の最大値、(iv) 両期とも CI 下限 95 前後、で採用不可。発走前に判定できる軸では最大 98〜100 で、既知の「1.0〜1.4 倍複勝 97.8%」「票数比 ≥2.19 で 96%」の帯から出ない。
- T-28 の価格には大きな FLB があるが、払戻は確定オッズなので取れない（`PINNED_FLOOR_SEARCH_20261112` の「確定の市場は発走前より遥かに賢い」と同じ現象を、傾きの言葉で言い直したもの）。オッズ推移での選別は死亡ルートであり、本結果もそこへ戻る根拠にはならない。

## 6. 注意点

- β は 1 パラメータの冪較正で、中位帯に支配される。裾の FLB は別指標（3.3）で見たが CI が広い。
- POOL・LATE・LINFO は締切時点の値（着順情報は含まないが、T-28 の判断では使えない）。実用評価は EINFO・GRADE・G1DAY・FIELD に限るべき。
- T-28 スナップは確定の 29〜58 分前（中央値 35 分）。LATE は分数で補正したが、残る時刻差が β_pre に混ざる可能性がある。
- 理論の代理変数は粗い（参加者数 ≒ 票数、情報の質 ≒ 価格の書き換え量、素人 ≒ G1）。票数は JRA 全体の売上トレンドを直前 365 日中央値で除いている。G1 は各期 140〜160R しかなく G1 単独の β は CI ±0.15〜0.2。
- 多数の比較（7 軸 × 2 市場 × 2 期 + 同時モデル）をしている。片期だけ有意な係数（2020-25 の 重賞 −0.12、新馬 −0.07 など）は偶然として扱った。
- 2013 年は POOL の参照期間が無いため POOL 分析から外れる（他の軸には入る）。
