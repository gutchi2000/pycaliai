# 協調フィルタリング相性 (「この馬に似た馬は、この条件で走った」) — 2026-11-14

結論: **none (null)**。事前登録した 3 変種とも、P・M・M0・A10 の 4 ゲートすべてで CI が 0 をまたぐ。
レース内シャッフルのプラセボと同じ大きさの揺れしか出ていない。

- スクリプト: `lab/experiments/cf_affinity_exp.py`（事前登録は docstring）
- 出力: `reports/cf_affinity_exp.json`（集計値のみ）、`reports/cf_affinity_inner.json`（〜2022 の内側検証）
- 作業用: `reports/cf_affinity_z.parquet`（馬別 z。JRDB の IDM 由来なので reports/ の外へ出さない）
- 物差し: `lab/experiments/gate_common.py` の `gate()`（valid=2023 で重み fit、test=2024-25 を 1 回評価、6,632 レース）

## 1. 理論

強さ（1 次元）を完全に知っても v7 に届かない（`PREDICTABILITY_CEILING_20261114.md`）。足りないのは
「馬 × レース条件」の相性だが、同じ条件の出走は 1 頭あたり数走しかなく、明示的な同条件成績は疎。
協調フィルタリングは全馬の「条件別の出来・不出来」から条件セルの潜在因子を学び、各馬の数走から
その馬の潜在ベクトルを推定して、**走ったことのないセル**の出来まで予測する。v7 の同条件系の特徴
（hist_same_cond_* / kako5_same_*_ratio / course_win_rate）は走ったセルの数え上げなので、ここは v7 が
直接は作れない。

## 2. 定義（test を見る前に固定）

| 項目 | 内容 |
|---|---|
| 走 | JRDB SED、平地（td∈{1,2}）、履歴に使うのは ijou==0 かつ idm 非欠損 |
| 目的変数 | y = idm（その走の出来。走った後の値なので履歴としてだけ使う） |
| セル | 場 × 芝ダ × 距離（m そのまま）。学習期間の有効走 800 以上の 84 セルが因子を持つ |
| モデル | y = a_馬 + g(月齢 3 か月刻み) + b_セル + u_馬·v_セル + ε |
| 学習 | 〜2022-12-31 の 565,202 走 / 62,366 頭。a・g・b は後退代入、u・V は ALS（u に ridge λ、V は全体ノルム固定） |
| (K, λ) | K∈{3,5,8} × λ∈{10,30,100,300} を「〜2019 学習 → 2020-22 を as-of 予測」で選択。規則は corr(z, 今日の上振れ) 最大 → **K=8, λ=10** |
| fold-in | レース日 D の各馬について、ymd < D の有効走だけで [a, u] を ridge 回帰（V・g・b は 〜2022 で固定）。z = u·v_{今日のセル} |

変種（3 つ）と基準:

| 名前 | 定義 |
|---|---|
| V1 z_cf（主検定） | 上の z |
| V2 z_cf_rel | z × 信頼度（1 − 事後分散/事前分散、0〜1。test 平均 0.30） |
| V3 z_cfg | セル因子に馬場状態の因子を足す（q = v_セル + w_{芝ダ×稍 / 重・不}）。馬場状態は master_lite、学習 2013-2022 |
| 基準 z0（変種に数えない） | 今日とまったく同じセルの過去平均 − 過去全体の平均、n/(n+3) で縮小。未経験は 0 |

判定規則: SIGNAL(市場外) = V1 の M が PASS かつ 2024・2025 とも負 かつ プラセボが PASS しない。
SIGNAL(予測) = V1 の P で同じ条件。V2/V3 だけの PASS は多重比較のため要追試扱い。

## 3. as-of の扱い

- 因子 V・月齢曲線 g・セル切片 b・馬場因子 W は 〜2022 の走だけで学習。valid/test には触れていない。
- valid/test 馬の u は ALS の学習値を使わず、毎回 D より前の走から fold-in で作り直す。
- 累積和は「同じ馬の、その行より前の行」だけ。SED に同一馬・同日 2 走は無い（assert）。
- fold-in の値を、300 行について「ymd < D の走だけを取り出して素直に解いた値」と突き合わせ、
  差は 1e-11 以下（V1・V3、z・z0 とも）。この点検は内側期間（2020-22）でやり、test は使っていない。
- 今日のセル（場・芝ダ・距離）と馬場状態は発走前に分かる。今日の idm・着順は使っていない。
- v8 affinity が死んだ原因（in-sample の漏れ）に当たる経路は無い。別セルに差し替えたプラセボは
  IDM の上振れとの相関が −0.011、ゲートも none で、漏れがあれば出るはずの「セルに依らない当たり」は出ていない。

### 4.2 被覆

- z がある馬（過去有効走 ≥1 かつ今日のセルが因子を持つ）: test の 86.2%。平均の過去有効走 8.3。
- 履歴がある馬のうち、今日とまったく同じセルを走ったことがない馬: 56.5%（ここが CF でしか埋まらない部分）。
- レース内相関: z_cf と v7 +0.06、確定市場 +0.07、z0 +0.69、z_cfg +0.84、別セルプラセボ −0.02。

### 4.3 z は「今日の出来」を当てるか（記述、判定には使わない）

今日の上振れ t = (今日の idm − 月齢・セルの補正) − 過去平均、過去有効走 ≥3 の有効走。

| | n | corr(z, t) | corr(z0, t) | 同セル未経験だけの corr(z, t) |
|---|---|---|---|---|
| 内側 2020-22（〜2019 学習、K=8 λ=10） | 96,540 | +0.116 | +0.143 | +0.019 |
| valid 2023 | 32,220 | +0.095 | +0.119 | +0.018 |
| test 2024-25 | 62,951 | +0.096 | +0.123 | +0.018 |
| 別セルプラセボ test | 62,951 | −0.011 | — | +0.002 |

- z は今日の出来を外挿で当ててはいる（test corr +0.096、プラセボ −0.011）。as-of の予測として本物。
- しかし**疎なはずの明示版 z0 のほうが強い**（+0.123）。t を z と z0 に同時回帰すると z の係数は 0.07、z0 は 0.75 で、
  z の当たりのほとんどは「同じセルをまた走る馬の実績」＝ z0 と同じ情報。
- CF 固有の部分（同セル未経験の走）は corr +0.018 とほぼゼロ。
- 学習した 84 セル因子の特異値の比率は 0.155〜0.087 とほぼ平ら、主成分と芝ダ・距離の相関も小さい
  （最大で第 2 主成分と芝ダ −0.26）。K=8・λ=10 では因子は構造でなく雑音に寄っている。

## 5. 判定

- SIGNAL(市場外): **該当なし**（V1 の M は none）。
- SIGNAL(予測): **該当なし**（V1 の P は none）。
- V2・V3 も全ゲート none。WORSE も無い。

なぜ効かないか（解釈）:
1. 条件相性は IDM の上振れを corr 0.10〜0.12 でしか当てない（上振れの分散の 1〜1.5%）。勝ち馬の NLL に届く量でない。
2. その小さい当たりの大半は「同じ条件をまた走る馬の実績」で、v7（同条件系の特徴 + 直近 1-3 走の IDM）と
   市場がすでに持っている。明示版 z0 も P で +0.00001。
3. CF でしか得られない「未経験セルへの転移」は IDM 上で corr 0.02〜0.05。芝ダ・距離の大きな適性は
   血統・調教師の番組選択・市場に既に入っていると読むのが自然。

## 6. 注意点

- IDM は JRDB の人手補正が入った指数。相性の一部は IDM の付け方に吸収されている可能性がある。
- 月齢曲線は全馬共通。個体の成長・衰えの違いは残差に残り、「最近走ったセルで好走」と相性が混ざりうる
  （この混入は z を大きく見せる向きに働くが、それでも none）。
- セルは場×芝ダ×距離のみ。内/外回り・右左（回り適性は別途「織り込み済み」で死亡）・頭数・ペースは入れていない。
- 事前登録の (K, λ) 選択規則は、結果的に CF らしくない設定（同セル実績の記憶寄り）を選んだ。規則は変えず、
  事後追加として CF らしい設定も報告した（§4.4）。どちらも none。
- test は 2 年・6,632 レース。M ゲートの CI 半幅は約 0.0006 nats/レースで、v7 の市場上乗せ（−0.00085）より
  小さい効果は検出できない。

## 7. 再走禁止の範囲

次は同じ結論になるので再走しない:
- IDM 残差の「馬 × (場・芝ダ・距離) セル」行列を低ランク分解（ALS / SVD、rank 3〜8、ridge fold-in）して作る相性 z。
- それに馬場状態（良 / 稍 / 重・不）の因子を足したもの、信頼度で縮めたもの。
- 明示版（同セル過去平均 − 全体平均）を縮小したもの。
- 同じ行列で K・λ・最小セル数を振り直すこと（内側検証で格子全体が corr 0.10〜0.12 に収まり、平ら）。

対象外（この実験では否定していない）:
- 目的変数を IDM 以外（走破タイム・通過順・上がり等の生値、着差）にした相性。
- セルでなく連続の条件ベクトル（コース形状・直線長・坂・ペース）を使う相性、馬側に血統を入れる冷スタート型。
  ただし §5 の 1〜3 から、同じ壁（上振れの予測力が小さい・市場が織り込み済み）に当たる見込みが高い。

関連する死亡ルート（繰り返していない）: 回り適性（織り込み済み）、v8 affinity（in-sample 漏れ）、1 次元レーティング / Elo。
