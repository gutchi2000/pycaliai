## 結論（先に）

1. **単独で確定市場に上乗せするブロックは見つからなかった。** JRDB の 14 ブロックはどれも、市場に足したとき（単独）も JRDB 以外の全特徴に足したとき（対比）も、改善が多重比較の補正（Holm・Bonferroni、族 39 行）を通らない。未補正で 95%CI が 0 未満になるのは、単独では「前日の適性・状態の区分」（−0.24×10⁻⁴、きわめて小さい）、対比では「過去走のペース・区間の評価」（−1.52×10⁻⁴）と「外厩」（−0.74×10⁻⁴、ほぼ 2024 年だけ）。
2. **前日の評価指数はほぼゼロ**だった。能力・騎手・陣営情報・合成・穴馬の評価は、市場に足しても改善量が単独で ±0.2×10⁻⁴、JRDB 以外の全特徴との対比でも ±0.3×10⁻⁴ 以内に収まる。残差モデルの多くは数本の木で止まった（＝学習期間でも市場の外の情報を見つけられなかった）。これらは**確定市場がほぼ全部織り込んでいる**。v8 の市場ゲート none、パドック系 none と同じ向き。
3. **点推定が大きいのは「ペース・位置」系**だった。過去走のペース・区間の評価と、前日の展開予想は、単独でも対比でも −0.9〜−1.5×10⁻⁴ で、2024・2025 年とも同じ向き。ただし補正後はどちらも 0 をまたぐ（未補正でも 0 未満になるのは対比の過去走ペースだけ）。11/15 の展開の検証（CW-20）の気配と整合するが、仮説の域を出ない。
4. **補正後も残ったのは 1 行だけ: JRDB 全体を「確定市場＋JRDB 以外の全特徴」に足した場合。** LogLoss −2.99×10⁻⁴ [−4.80, −1.24]（Bonferroni 区間 [−6.07, −0.13]、Holm p=0.031）、勝ち馬 NLL −0.0032 nats/レース、2024・2025 年とも −3.0×10⁻⁴。**情報は特定のブロックに集まっておらず、多くのブロックに薄く散っている**、と読むのが自然。
5. **JRDB 以外の全特徴（v6 の 120 特徴）も、同じ作り方なら市場に上乗せを示す**（−4.01×10⁻⁴ [−6.88, −1.12]、未補正のみ）。JRDB 全体の上乗せはこの約 4 分の 3 にあたり、両者はほぼ足し算で効く（「市場」→「＋JRDB 以外」→「＋JRDB」で −4.0 → さらに −3.0）。以前の線形の合成（v6 のスコアを市場と混ぜる）では v6 の上乗せは検出されなかった。違いは、今回は**市場を土台にして残差だけを学習した**こと（どの特徴のときに市場が値を付け違えるか、を直接学ぶ）。
6. **量は非常に小さい。** 最も大きい −3.0×10⁻⁴ でも、市場単独の LogLoss 0.2037 に対して 0.15%。目的関数の検証で測ったモデルと市場の差（LogLoss で約 +0.017＝170×10⁻⁴、勝ち馬 NLL で 0.17〜0.22 nats/レース）の 2% 程度で、控除を越える大きさではない。**馬券の戦略を変える根拠にはならない。**
7. **探索扱い。** 多重比較の族は 39 行。採否の判断には使わず、有望な候補（4 の JRDB 全体、3 のペース・位置系）は **v8 の前向きデータでの再確認が必要**。ただし必要な標本は JRDB 全体で約 4,800R（約 1.4 年）、ペース・位置系の単独では 1.2〜1.7 万 R（4〜5 年）と見積もった（§6）。

## 1. 設計（test を見る前に固定）

設計はスクリプト `analysis/jrdb_block_audit.py` の冒頭に書き、**test を評価する前に commit した**（`6aee418e`）。test（2024-25）の評価は 1 回だけ実行した。

| 項目 | 内容 |
|---|---|
| 問い | JRDB のどの情報ブロックが、確定単勝オッズの市場に対して勝ち馬の追加情報を持つか |
| 土台（市場） | 確定単勝オッズの逆数をレース内で正規化した勝率（`kekka_1986_2025_enhanced.csv`、読み取りのみ） |
| 残差モデル | LightGBM 2 値（1 着か）。**市場の勝率の logit を初期値（init_score）に入れ、市場で説明できない部分だけを学習**。特徴 = ブロックの列＋数値列のレース内 z＋出走頭数。ハイパラは固定（学習率 0.03、葉 31、葉の最小 500、L2 10、列 70%・行 80% の抽出、seed 42、早期停止 100 回） |
| 期間 | 学習 2016-01〜2022-12（外厩データが 2016 から、24,129R）／ 早期停止とゲートの重み 2023（3,453R）／ **評価 2024-25（6,632R・90,284 頭、1 回だけ）** |
| ゲート（条件付きロジット、重みは 2023 で fit） | **単独**: [log 市場] → [log 市場, z_ブロック] ／ **対比**: [log 市場, z_N] → [log 市場, z_N, z_(N+ブロック)]（N = JRDB 以外の全特徴。N にブロックを足して学習し直した残差を加える）／ **参照**: [log 市場] → [log 市場, z_N] |
| 指標 | 主: 1 頭ごとの 2 値 LogLoss（勝率を [0.001, 0.999] に制限、全馬平均）。副: 勝ち馬の負の対数尤度（nats/レース、過去のゲートと同じ物差し）。差 = 足した側 − 土台（**負 = 改善**） |
| 区間 | 開催日単位の bootstrap 10,000 回。95%CI と、族全体（39 行）の Bonferroni 区間（両側 0.128%〜99.872% 点）。p 値は bootstrap 分布から両側、Holm で補正 |
| 判定の言葉 | 「改善(補正後も)」= Bonferroni 区間の上端 < 0 ／「改善(未補正のみ)」= 95%CI の上端 < 0 ／「悪化」= 95%CI の下端 > 0 ／ それ以外は「差なし」 |
| 対照・偽薬 | 出走頭数だけの残差（CTX）、乱数、JRDB 全体の残差をレース内でシャッフル |
| 対象 | master_v2 の完走扱いの馬で、全頭の確定オッズがあり、1 着がちょうど 1 頭、5 頭以上のレース（2016-25 で 34,548R → 34,214R） |

**配線の確認**: test を開く前に、2023 年の中だけ（前半で重み、後半で評価）で同じ集計を走らせ、乱数が差なし・シャッフルが悪化になることを確かめた（数値は判定に使っていない）。

## 4. 読み方

**(1) 前日の評価指数は市場が持っている。** 能力・騎手・陣営情報・合成・穴馬の評価は、どれも予想の精度を大きく上げる材料だった（v8 は ◎3着内 +1.5pt、gain の 7 割が前日データ）。それでも確定市場に対しては、単独でも対比でも ±0.3×10⁻⁴ 以内に収まる。前日に配られる評価は、締切までに買い手がほぼ使い切っている。予想の精度に効くことと、市場の外にあることは別物で、前日系は前者だけにあたる。

**(2) 上乗せがあるとすれば「ペース・位置」の周辺。** 点推定が大きいのは、過去走のペース・区間の評価（対比 −1.52、単独 −0.87）と前日の展開予想（単独 −1.41、対比 −1.20）で、どちらも 2 年とも同じ向きだった。市場は能力の評価はよく織り込む一方、レースの流れと位置の噛み合わせは値付けが粗い、という仮説と矛盾しない（11/15 の展開の検証で残った CW-20 の気配とも同じ方向）。ただし補正後はどちらも 0 をまたぎ、効果の大きさはせいぜい 1〜2×10⁻⁴ なので、**現時点では仮説どまり**。

**(3) 情報は散っている。** 単独のブロックは補正を通らないのに、まとめると通る。14 ブロックの対比の差を単純に足すと −3.2×10⁻⁴ で、まとめて学習した G_ALL の −3.0×10⁻⁴ とほぼ同じ。1 つ 1 つは雑音に埋もれる大きさの上乗せが、多くのブロックに少しずつある形になっている。「このブロックが効く」とは言えず、「JRDB 全体として、JRDB 以外の特徴が持たない市場の外の情報をわずかに持つ」とだけ言える。11/14 の v7 の結果（v7＋市場 − v6＋市場 −0.00079 nats/レース）と同じ向きで、作り方の違い（市場の残差を直接学ぶ）の分だけ量は大きい（−0.0032 nats/レース）。

**(4) JRDB 以外の特徴も、市場の残差としてなら少し効く。** 市場＋JRDB 以外は −4.01×10⁻⁴（未補正のみ）。11/14 までの「v6 は市場に何も足さない」は、市場を見ずに学んだスコアを後から混ぜた場合の結果だった。市場を土台に残差を学ばせると、たとえば「この条件の馬は市場が買いすぎる」といった癖まで拾える。ただし N には先の値で上書きされた列（馬主）が含まれており（`project_owner_column_future_overwrite`）、この行の量は少し割り引いて読む。対比の行（3.3）は N を土台にしているので、N が水増しされていればむしろ控えめに出る。

**(5) 血統・騎手・調教は、JRDB 以外の側でもほぼ市場の中。** 参照ブロックは、血統 −0.41（未補正のみ、量はごく小さい）、騎手・調教師 −0.29、調教タイム +0.74 で、どれも補正を通らない。JRDB 側の騎手評価・調教評価・厩舎評価も同じく差なしか、わずかに悪化（学習期間に合わせすぎ）だった。

**(6) 大きさの感覚。** 最大の −3.0×10⁻⁴ は、市場単独の LogLoss の 0.15%、モデルと市場の差（目的関数の検証で +170×10⁻⁴ 前後）の 2% 程度。勝ち馬 NLL の 0.003 nats/レースは、単勝で控除 20%（log 0.8 ≈ −0.22）を越える大きさから 2 桁離れている。**馬券・本線・買い目のロジックは変えない。**

## 5. 限界

- **後から直されたデータの可能性。** 成績（`sed.parquet`）と前日データ（`kyi.parquet`）は現在のアーカイブで、当時の値から改訂されていれば、その分だけ上乗せが水増しされる（台帳 CW-12・CW-16 と同じ懸念）。発走前に保存した前日データは 2026-11-14 以降しか無い。
- **確定オッズが土台。** 購入時点（T-10）の市場は確定より情報が少ない（目的関数の検証で LogLoss が約 0.003 悪い）。購入時点に対する上乗せは今回の数字より大きい可能性があるが、2024-25 の T-10 オッズが無いので測っていない。
- **学習器は 1 つ・ハイパラ固定。** 「差なし」は「この学習器で見つからなかった」であって、情報が無い証明ではない。特に木が数本で止まったブロックは、もっと弱い正則化なら何か拾う可能性がある（ただし 2023 で悪化したので止まっている）。
- **2023 は早期停止とゲートの重みの両方に使った。** 残差は 2023 にやや合っている（2023 の中での配線確認では、test より改善が大きく出た）。test の数字はこの影響を受けない。
- **test 2024-25 は過去の実験でも何度も使った期間**。今回の比較は 1 回だけだが、期間そのものへの合わせ込みは否定できない。
- **多重比較**。族は 39 行（参照 4・単独 18・対比 17）。未補正で 95%CI が 0 未満になった 9 行のうち、補正後に残ったのは 1 行だけ。
