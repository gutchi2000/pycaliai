## 結論（先に）

1. **この検証では、モデルの追加情報は見つからなかった**。fit 側で選んだブレンド（幾何平均・モデルの重み 0.25）は、検証側で市場のみより LogLoss が +0.0018 [+0.0006, +0.0031]、Brier が +0.00032 [+0.00006, +0.00060] 悪い（どちらも 95%CI が 0 より上＝市場の方が当たっている）。勝ち馬の対数尤度で見ても 1 レースあたり +0.021 [+0.007, +0.036] nats 市場が良い。
2. **事前の取り決めどおり、EV ルールは計算していない**（条件は「検証でブレンドの LogLoss が市場より小さいこと」）。
3. **fit 側の時点で、市場のみが 6 つのブレンドすべてより良かった**（市場 0.20322、最良のブレンド 0.20626）。モデルの重みを 0.25 → 0.5 → 0.75 と上げるほど単調に悪くなる。幾何平均と算術平均の差は小さい。
4. 読み方: 「モデルは市場の外の情報を全く持っていない」とまでは言えない。言えるのは「**重み 0.25 以上で混ぜると、モデルが持ち込む誤差の方が上乗せの情報より大きい**」こと。11/14 の検証（`docs/research/V7_MARKET_GATE_20261114.md`、2024-25 年 6,632R）では、合成の重みを連続値で fit すると最適なモデルの重みは約 0.06 で、v6＋市場は市場単独と区別できず（ΔNLL −0.00007、CI が 0 をまたぐ）、v7＋市場だけが −0.00085 [−0.00168, −0.00005] とわずかに上回った。今回の格子（0.25 / 0.5 / 0.75）はこの領域を含んでいない（§6 限界 4）。
5. 参考（探索）: クラス・芝ダ・頭数・CHAOS 帯・世代のどこで分けても、モデル単独は市場より悪い。ブレンドが市場を有意に上回る区分は無い（1 レースだけの障害重賞を除く）。最も市場に近いのは v7 の 69R（モデル − 市場 +0.008 [−0.002, +0.018]、ブレンド − 市場 −0.0004 [−0.0027, +0.0020]）だが、標本が小さく何も言えない。

## 5. 判断

- 「勝率が市場より平らなのを直せば EV ルールが生き返るか」という流れの 3 本目として、**市場に固定の重みで混ぜても、市場単独を越えない**。EV は検証側で計算されず、前 2 回の結論（EV 閾値ルールは全滅、再較正でも生き返らない）は変わらない。
- 市場を確率の土台にした時点で、EV = 確率 × オッズ は市場の控除（約 80%）に近づく。今回のように市場単独が最良なら、ブレンドの EV ルールは「控除どおりの回収率」以上を期待する根拠が無い。

## 6. 限界

1. **モデル世代が混ざっている**（v5・v6-C0・v6-C1・v7）。fit 側と検証側で世代構成が違う（前半 v5＋C0、後半 C0＋C1＋v7）。
2. **v8 は含まれていない**（本番は 11/21 から v8）。v8 の確率に市場の外の情報があるかは未確認。
3. **最終オッズを使っているので、市場に有利な条件**。最終オッズは締切までの全情報（購入時点より後の売れ行きを含む）を織り込んだ、最も強い比較相手になっている。実際に買える T-10 や朝の時点の市場はこれより弱く、そちらと比べればモデルを混ぜる価値が出る可能性はある（既存の結果: 朝 9 時オッズとの合成印は test 2024-25 で ◎3着内が朝の市場単独 64.40% に対し 65.24%。CLAUDE.md の「朝の補正印」、`analysis/fit_am9_blend.py`。今回は未検証）。
4. **重みの格子が粗い**。指示どおり 0.25 / 0.5 / 0.75 だけを比べた。fit 側の LogLoss は重みを下げるほど良くなっており、0.25 未満（11/14 の連続 fit では約 0.06）の領域は今回試していない。そこで市場を上回るかは、この検証では分からない。
5. 採点から外した馬（最終オッズ無し・中止等の 64 頭）の分だけ、レース内正規化の母集団が実際の出走馬と違う。
6. 前半・後半の分割は 1 通りだけ。
