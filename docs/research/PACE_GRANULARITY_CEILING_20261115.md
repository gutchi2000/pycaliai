# 展開を細かく学習したときの上限 — 2026-11-15

**結論: 細かくしても取り出せる分は無い。** 展開の情報のうち効くのは「今日その馬が前半どこにいたか」だけで、
完全に分かれば大きく効く（◎3着内 +2.7pt 相当）。しかし発走前の情報で再現できるのはその 3 割で、
再現できる部分は v7 と市場がすでに持っている。ペースを連続量で知っても上乗せはほぼ 0。

- スクリプト: `lab/experiments/pace_granularity_ceiling.py`（読み方は docstring で事前に決めた）
- 出力: `reports/pace_granularity_ceiling.json`（集計値のみ、git 管理外）
- 物差し: `lab/experiments/gate_common.py`（valid=2023 で重み、test=2024-25 を 1 回、6,632 レース）
- 前提: `PACE_FORWARD_PROBLEM_20261114.md`（3 区分ペース × 脚質は null）。今回は同文書 §7 の未検証分を測った

## やったこと

JRDB SED（平地、2013〜）から 1 着の LightGBM を作り（2013-20 学習、2021-22 で早期終了）、2023-25 の log-odds を z としてゲートに入れた。

- **pre**: 発走前の脚質量（テン指数・最初のコーナー位置・逃げ率・ペース指数・IDM の直近平均、距離増減、枠、
  さらに細かい脚質として 出遅れ率・4 角コース取り平均・1 角→4 角の上げ幅・上がり指数）
- **R**: pre + 今日のレースの実際のペース（S/M/H、レースペース指数、テン指数のレース平均、前に行った頭数）
- **P**: pre + 今日その馬が実際に前半どこにいたか（最初のコーナー相対位置、先頭か、普段との差、出遅れ）
- **T**: pre + 道中（4 角コース取り、不利 前/中/後/計）

R・P・T は今日のレースの事後情報（オラクル）で、予想には使えない。「完全に分かったらいくら効くか」の上限として読む。

## 結果（test 2024-25、ΔNLL nats/レース、負 = 改善）

| z | P（v7 → +z） | M（確定市場+v7 → +z） | ◎3着内（P） |
|---|---|---|---|
| pre（発走前） | −0.0028 [−0.0049, −0.0006] PASS | −0.0001 [−0.0007, +0.0005] none | 62.18 → 62.65% |
| R ペースの実際（連続量） | −0.0036 PASS | −0.0002 none | 62.52% |
| P 前半の位置の実際 | −0.0706 PASS | **−0.0447 PASS** | **64.93%** |
| T 道中の実際 | −0.0126 PASS | −0.0055 PASS | 63.01% |
| R+P+T | −0.0889 PASS | −0.0590 PASS | 64.91% |
| **P を発走前の予測で置き換え** | −0.0026 PASS | −0.0000 none | 62.55% |
| **T を発走前の予測で置き換え** | −0.0024 PASS | −0.0001 none | 62.44% |

発走前の情報での再現度（test 2024-25 の R²）: 前半の位置 0.30、先頭か 0.13、普段との差 0.20、出遅れ 0.13、
4 角コース取り 0.18、不利 ≈ 0。

## 読み方

1. **ペースは細かくしても効かない。** 実際のペースを連続量で入れても M の上乗せは −0.0002（pre との差 −0.0001）。
   事前に決めた基準（pre より 0.002 以上）に遠く届かない。「ペースの定義が粗かった」は理由ではなかった。
2. **効くのは馬ごとの前半の位置。** 完全に分かれば M −0.045 で、v7 の市場上乗せ（−0.00085）の 50 倍。
   ただしこの上限には「今日調子の良い馬が前に行ける」という結果の漏れが混ざるので過大側。
3. **その位置は発走前にはほとんど決まっていない。** 再現度は R² 0.30。予測値で置き換えると M は 0 に戻り、
   P ゲートの上乗せも pre（−0.0028）と同じ（−0.0026）。予測できる分は「普段の脚質」そのもので、v7 と市場が既に持つ。
   残り 7 割はスタート・騎手の判断・隣の馬の出方で、レースが始まってから決まる。
4. **道中の不利は予測不能**（R² ≈ 0）。4 角コース取りは 0.18 だが、予測値では効かない。
5. pre 単独が P ゲートを通った（◎3着内 +0.47pt）のは、v7 と別の小さいモデルを足した平均化の効果の可能性があり、
   展開の情報とは言えない。M は none なので馬券には関係しない。年別・偽薬は見ていない（記録のみ）。

## 再走禁止の範囲

- ペースの定義を細かくする（連続量・レースペース指数・前半の速さ）
- 過去走から作る細かい脚質（出遅れ率・コース取り・まくり幅・上がり）を足す
- 前半の位置・コース取り・不利を発走前に予測して足す（R² 0.30 / 0.18 / 0 で、予測値はゲートを通らない）

再開してよいのは、発走後の位置が入る使い方（ライブ・レース中の予測）か、
発走前に前半の位置を決める新しい情報（騎手の戦法コメント、ゲートの出方の当日情報）が入ったときだけ。
いずれも現在のデータには無い。
