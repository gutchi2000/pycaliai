# O-1 最小運用予算 B* — 判定基準の事前固定（2026-10-22）

> 計算前に書く。結果は別ファイル `MIN_BUDGET_BSTAR_RESULT_20261022.md` に出し、本ファイルは後から書き換えない。
> 出典: `docs/research/NEW_EXPERIMENT_CANDIDATES_20261013.md` O-1。

## 問い

本線方策 a95_equal_v1（凍結、`data/shadow_policies/a95_equal_v1.json`、sha256 `8cccbed13f55…`）を
1R 予算 B で運用したとき、100 円格子の丸めと券種の脱落で回収率がどれだけ変わるか。

## 対象と固定事項

- 方策: 凍結表どおり。帯 = AI1位（生 p_win 降順）の 9 時単勝オッズ、券種 = `plan[帯]`。
  配分は本番と同じ関数を使う: `shadow_a95.sellable_kinds`（8 頭以下は枠連なし）→
  `a95_engine.build` と同じ脱落規則（`B // 券種数 < 100` の間、plan の後ろから落とす）→ `shadow_a95.equal_stakes(kinds, B, 100)`。
- B ∈ {500, 1000, 2000, 3000, 5000, 10000}。基準は B = 10000（本番の cap）。
  集合外の B（100〜400 など）を出す場合は記述のみで、判定に使わない。
- データ: `data/_policy/bet_substrate.pkl` 2023-01-01〜2025-12-31（alloc_95_design / a95_chaos_gate_check と同じ substrate と決済）。
  2026 年 10 月以降の a95 前向き台帳・cowork_output 決済は開かない。
- 母集団:
  - **主（判定用）**: 参戦ガード通過近似 = `analysis/a95_chaos_gate_check.py` と同じ定義
    （混戦度 = 正規化エントロピーの 2023-25 分位 0.667 未満、かつ 8 頭以上、かつ AI1位 p_win ≥ 0.05）。
  - 副（感度）: 全レース。主と結論が食い違えば併記するが B* は主で決める。

## 分解

ROI_cont = 各 B で残った券種へ連続（丸めなし）均等配分したときの ROI。連続配分は B に対してスケール不変なので、
券種が落ちない限り ROI_cont(B) = ROI_cont(10000)。

Δ(B) = ROI(B) − ROI(10000) = (a) + (b)

- (a) 丸め由来 = [ROI(B) − ROI_cont(B)] − [ROI(10000) − ROI_cont(10000)]
  （B での格子歪みのうち、基準 10000 自身の格子歪みを差し引いた分）
- (b) 券種落ち由来 = ROI_cont(B) − ROI_cont(10000)（B で落ちた券種がある時だけ非 0）

ROI はすべて「総払戻 / 総投資」(%)。

## 推定と CI

- 開催日ブロック bootstrap（日付単位で復元抽出、3,000 回、seed 固定）。同じ抽出で ROI(B) と ROI(10000) を計算する対の差なので、Δ の CI はペア差の分位点（2.5%, 97.5%）。
- 年別（2023 / 2024 / 2025）も同じ方法で出す（記述のみ）。

## 採用基準（固定）

- B が合格 ⇔ 主母集団で **Δ(B) の 95% CI [lo, hi] が [−1, +1]pt に収まる**（= |Δ| の CI 上限 ≤ 1pt）
  **かつ** 全レースで券種落ち 0 件（落ちの判定は本番の脱落規則による）。
- **B\* = 合格する最小の B。ただしそれ以上の B もすべて合格していること**（非単調なら、上がすべて合格する最小値を採る）。
- 集合内にどれも合格しなければ B\* = 10000（現状維持）。
- 年別・副母集団で 1pt を超える年が出ても B\* は変えず、結果に明記する。

## 記述（判定に使わない）

- 各 B の年間期待収支（円）= 年間参戦 R × B × (ROI(B)/100 − 1)。
  年間 R = 3,400R × ガード通過率。通過率は既存値（a95_chaos_gate_check の 6,658/10,261 ≈ 64.9%、本計算で再現した値を併記）。
  点推定（in-sample ROI）と、悲観側（上位 10 払戻除外 ROI）の 2 本を出す。
- 年間収支の 5% / 50% / 95% 点: 主母集団の開催日集計を 1 年分の開催日数（substrate の年平均 ≈ 107 日）だけ復元抽出、3,000 回。
- 注意: ROI 水準は凍結表を作ったのと同じ 2023-25 で決済する in-sample。Δ（B による差）は方策を固定した対比較なので in-sample の影響は受けにくいが、ROI 水準と年間収支は楽観側に偏る。OOS 参考値は 102.6%（4 方向平均、最悪 97.6%）、控除率超えの証拠は無い。
