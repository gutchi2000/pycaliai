# 顕示選好理論 — 騎手・厩舎の「選択」は市場の外の情報か（2026-11-14）

きっかけ: ユーザー「常人じゃ考えられない、生成AIだから思いつく理論」。

## 理論

市場の外にある情報の多くは、厩舎や騎手の頭の中にある。それは言葉にはならないが、「選ぶ」という行動には漏れる。市場は騎手の名前や乗り替わりを見ている。ただし「同じレースで何を捨てて何を選んだか」という構造まで値段に入れていなければ、そこに歪みが残るはず、という仮説。

- **T1 騎手の選択**: 前走で馬 A に乗った騎手 J が、同じレースで別の馬 B に乗る場合、B を「選ばれた馬」、A を「捨てられた馬」とする。両方の馬の感触を知っているのは J しかいない。
- **T2 厩舎の二頭出し**: 同じ調教師の馬が 2 頭以上出るレースで、as-of 勝率の高い騎手が乗る方と、そうでない方に分ける。
- **T3 騎手の格上げ・格下げ**: 前走の騎手と比べて、同じ日の as-of 勝率で ±5pt 以上の差がある騎手に替わった馬。

## 方法

- 実装は `lab/experiments/revealed_preference_exp.py`、出力は `reports/revealed_preference_exp.json`。モデルは使わず、市場と結果だけで測る。
- 対象は 2013-25 年の 44,561R。確定単勝オッズは `kekka_1986_2025_enhanced.csv` から取った。
- 指標は「実際の勝ち数 ÷ 市場勝率の和」。1 なら市場が正しく値付けしている。あわせて、単勝・複勝の均等買い回収率と、同じオッズ帯の全馬との差（帯残差）を出した。
- 期間は 2013-19 年と 2020-25 年に分けた（コロナ前後）。CI は開催日単位の bootstrap。
- 判定は事前に固定した。2 期間とも CI が 1 をまたがず、向きもそろえば SIGNAL とする。

## 結果

| 群 | 2013-19 実勝/市場 | 2020-25 実勝/市場 |
|---|---|---|
| 選ばれた馬（約 4.2 万 / 3.1 万頭） | 1.003 [0.976, 1.030] | 1.011 [0.981, 1.042] |
| 捨てられた馬 | 1.000 [0.966, 1.033] | 1.011 [0.972, 1.050] |
| 厩舎の本命側 | 0.966 [0.905, 1.026] | 1.023 [0.958, 1.085] |
| 厩舎のもう一頭 | 1.035 [0.956, 1.116] | 0.991 [0.908, 1.082] |
| 騎手の格上げ | 1.008 [0.960, 1.058] | 1.008 [0.953, 1.065] |
| 騎手の格下げ | 0.910 [0.857, 0.966] | 0.983 [0.920, 1.052] |

**判定: 全群で SIGNAL なし。** 市場は、騎手が何を捨てて何を選んだかまで、ほぼ正確に値段に入れている。

- 格下げは 2013-19 年だけ市場より勝てていなかった（過大評価）が、2020-25 年には消えている。
- 帯残差で CI が 0 をまたがなかったのは 2 つだけで、どちらも片方の期間に限られる。
  - 格上げの単勝: 2013-19 年 −7.6pt（2020-25 年は CI が 0 をまたぐ）
  - 捨てられた馬の複勝: 2020-25 年 +3.3pt
- どの群でも、回収率は 68〜80% の範囲にとどまった。

## 結論

顕示選好（騎手・厩舎の選択）は、市場の外の情報ではない。日本の市場は乗り替わりの構造まで読み込んでいる。

再走は禁止する。同じ選択構造の別定義（騎手の前々走、調教師と騎手の組み合わせなど）も対象に含める。これらを特徴としてモデルに足す案も、市場の外に出ないので優先度は低い。
