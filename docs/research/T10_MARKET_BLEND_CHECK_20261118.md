# 購入時点（T-10）の市場にモデルを混ぜると当たりが良くなるか（前半 fit / 後半検証）

## 結論（先に）

1. **購入時点（T-10）の市場に対しても、モデルを混ぜた効果は検出できない**。fit 側で選ばれたのは最小の重み 0.05 で、検証側の LogLoss は T-10 市場のみと実質同じ（差 +0.00004 [−0.00030, +0.00045]）。Brier（+0.000004 [−0.00005, +0.00006]）・勝ち馬の対数尤度（+0.0006 [−0.0036, +0.0056] nats/レース）でも同じ。点推定はわずかに市場の方が良い。
2. **事前の取り決めどおり、EV ルールは計算していない**（条件は「検証でブレンドの LogLoss の点推定が T-10 市場より小さいこと」）。
3. **fit 側でも T-10 市場のみが 4 つの重みすべてより良く**（市場 0.21331、w=0.05 が 0.21353）、重みを増やすほど単調に悪化した。最適な重みは 0.05 以下、データ上は 0 と区別できない。
4. 最終オッズとの差の大きさ（参考）: 検証側で、最終オッズの市場は T-10 の市場より LogLoss で −0.0033 [−0.0049, −0.0018]、勝ち馬の対数尤度で −0.039 [−0.057, −0.022] nats/レース良い。**締切前の 10 分で市場に入る情報の方が、モデルが市場に上乗せしうる量（11/14 の推定で約 0.001 nats/レース）よりずっと大きい**。T-10 の市場は最終より弱い比較相手だが、それでもモデルは上乗せできていない。

## 2. 設計（検証を見る前に固定）

| 項目 | 内容 |
|---|---|
| 採点対象 | 前回と同じ（最終単勝オッズあり・中止等でない・p_win あり）かつ §1 で T-10 単勝オッズのあるレース |
| 分割 | 前回と同じ境界: fit = 〜08-15、検証 = 08-16〜。検証は 1 回だけ |
| 市場 q | T-10 単勝オッズの逆数をレース内（採点対象の馬）で正規化 |
| モデル m | bundle の p_win を同じ馬の集合でレース内正規化 |
| ブレンド | 幾何 p ∝ q^(1−w)·m^w、**w = 0.05 / 0.10 / 0.15 / 0.25**。格子の根拠は 11/14 の検証（`V7_MARKET_GATE_20261114.md`、2024-25 年）で、合成の重みを連続値で fit した最適が約 0.06 だったこと |
| 重みの選択 | fit 側の LogLoss（馬ごと 2 値、確率は [0.001, 0.999] に制限）最小の 1 個 |
| 検証の比較 | 選んだブレンド・T-10 市場のみ・モデルのみ。主 = LogLoss、副 = Brier・勝ち馬の対数尤度。参考に最終オッズの市場。CI はレース単位の対応付きブートストラップ（4,000 回） |
| EV ルールの条件 | 検証でブレンドの LogLoss の点推定が T-10 市場より小さいときだけ。EV = ブレンド確率 × **T-10 単勝オッズ**、閾値 1.0 / 1.1 / 1.15、単勝の全該当と上位 1 頭。払戻は確定配当 |

実行の経緯: 1 回目は、週次 CSV の発走時刻の読み込み（列ずれのある行で日時の変換に失敗）で、どの数値も出る前に止まった。その行を読み飛ばすよう直して再実行した。設定の変更はしていない。

## 5. 判断

- 最終オッズ（前回）でも購入時点のオッズ（今回）でも、bundle の勝率を市場に混ぜて市場単独より当たりが良くなる証拠は無い。今回の比較相手は最終より明確に弱い T-10 の市場だが、それでも fit・検証ともに差は出なかった。
- このため「購入時点の市場 × モデル」で EV ルールを作る根拠は、この期間・この世代（主に v6）では得られない。11/14 の検証で v7 にだけ見えた微小な上乗せ（約 0.001 nats/レース）は、検証側の v7 が 69R しかないため、今回の検証では確かめられない（前向き確認は台帳 CW-16）。
- 既存の「朝の補正印」（朝 9 時オッズ × モデル）が ◎3着内を朝の市場単独よりわずかに上げたのは、朝の市場が T-10 よりさらに弱いからだと考えるのが自然で、今回の結果と矛盾しない（今回は朝 9 時では検証していない）。

## 6. 限界

1. **検証期間の再利用**。検証側（08-16〜11-15）は、EV 閾値・再較正・最終オッズのブレンドの過去 3 回の分析と同じ期間で、すでに何度も見ている。今回の設計（重みの格子・EV の条件）を決める前にこの期間の結果を知っていたので、厳密な意味での未使用の検証ではない。
2. **モデル世代が混ざっている**。fit は v6-C0 のみ、検証は v6-C0・v6-C1・v7。前回までの fit 側にあった v5 は、T-10 オッズの保存開始前なので今回は入っていない。
3. **v8 は含まれていない**（本番は 11/21 から v8）。
4. **実際の購入オッズは T-10 の値から動く**。T-10 の後も締切まで票が入り、確定オッズは T-10 と違う（勝ち馬の確定オッズは T-10 より平均で低い: `compute_bets.py` のコメントでは −7.8%）。EV は T-10 のオッズで選び、払戻は確定配当で数えるので、EV ルールを計算していたとしても、選んだ時の EV と実際の受け取りはずれる（今回は EV を計算していない）。また市場の「当たり具合」も、T-10 と実際に買える最後の時点（T-1 など）とでは違う。
5. **fit 側が小さい**（606R・18 開催日、凍結 bundle のある fit 期間の 64%）。05-02〜06-07 は T-10 の保存が無い。
6. T-10 の取得時刻は 5〜15 分前の窓で選んだ（中央値 9.98 分）。live_odds（06-13〜08-16）は上書き式で、その時点の最新版。窓に入らない取得は使っていない。
7. 前半・後半の分割は 1 通りだけ。
