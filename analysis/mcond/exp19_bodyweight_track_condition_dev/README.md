# EXP19 — 当日馬体重 × 公式馬場物理値

**状態**: v0.2修正済み・Fable差分再レビュー待ち（Stage 0未着手）
**次に渡す相手**: **Fable（仕様レビュー）**
**実装担当**: Fable承認後に Opus

## 目的

当日発表された馬体重を、単純な「増減が大きい／小さい」ではなく、その馬自身の過去体重からの偏差として表現し、JRA公式のクッション値・含水率との相互作用が判断時点市場および締切市場に残差情報を加えるかを検証する。

これは朝9時の現行v6へ当日馬体重を混ぜる研究ではない。馬体重が公開された後だけ動く `late_decision` 系の独立候補であり、現行production、朝の印、買い目、予算には接続しない。

## 既に確認した事実

- `fetch_baba_today.py` はJRA公式ページからクッション値、芝・ダートのゴール前/4角含水率、測定時刻を取得し、`data/baba_today.json`へ保存している。
- `build_baba_feats.py` がJRA PDFから `data/baba_feats.parquet` を構築済み。2018-07-27〜2025-12-28、3,164 venue-days。含水率の充足は99.7%以上、クッション値は制度開始前を含むため71.9%。
- 2026-09-26の実収集も、中山・阪神についてクッション値と4種類の含水率を測定時刻付きで取得できている。
- 公式馬場値だけを足した既存 `baba_eval.py` は、testで ΔAUC=-0.000304、Δlogloss=+0.000278（悪化）。公式馬場値単独は既に「priced」と判定済み。
- 歴史の今走馬体重は `data/torch_20130105-20251228.csv` にあり、2019〜2023平地で231,068 horse-race rows / 16,645 races。200〜800kgの有効値は99.807%、血統登録番号欠損は0。
- forwardのWH収集は `analysis/bodyweight_forward/` で開始済み。append-only、T−90〜T−5、未計測・取消・異常値を0埋めしない。

## 新規性の範囲

既検証の「公式馬場値だけ」「馬場適性×馬場値」「当日先行レース結果から推定するオンライン馬場状態」は再実施しない。EXP19が問うのは次の二点だけ。

1. 当日馬体重の**その馬自身に対する異常度**に残差情報があるか。
2. その異常度の意味が、公式のクッション値・含水率によって変わるか。

TM/DMなどJRA-VAN独自指数は使用しない。使用する外部情報は、JRA公式の生の物理測定値とJV-Dataの当日馬体重だけである。

## 実験の順序

1. Stage 0: provenance、時点、forward/historical parity、母集団、被覆、検出力を結果開封前に固定。
2. Gate A1/A2: T−28前後の判断時点市場で、馬体重単独と馬体重×馬場を独立検定（Holm補正）。
3. Gate B1/B2: A1/A2でSUBFLOOR以上の経路だけ、締切市場に残るかを検定。
4. terminalでPRACTICALを通った経路だけ、別番号で同一ハイパーパラメータのvNext比較を提案できる。

2024/2025、ROI、候補生成、賭金配分、production接続は本番号では行わない。
