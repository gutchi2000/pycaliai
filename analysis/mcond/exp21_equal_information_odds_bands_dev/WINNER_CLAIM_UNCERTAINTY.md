# 優勝者三連単表の +10pt — 公表値だけによる不確実性の格付け

**入力（公表値）**: 2025〜2026 年 4,365 race。三連単確定オッズ 600〜1,200 倍の ROI 0.831、1,200〜2,500 倍の ROI 0.820（SPEC §0）。
帯別の**組合せ数**は優勝者資料の**付録 A3** に全 9 帯が掲載されている（資料記載の「組合せ数」であり、票数ではない）。
控除率基準 0.725。手元の結果データは開いていない。計算は `winner_claim.py` → `out/winner_claim_uncertainty.json`。

> 訂正（2026-09-27）: 初版は「原表の帯別組合せ数が手元に無い」として n̄ をパラメータで振っていた。付録 A3 に掲載があるため、公表値で n̄ を確定した。

## 前提（規律）

- 独立単位は **race（4,365）**。**同じ race 内の組合せを独立標本として扱わない**。組合せ数は race あたりの n̄ に換算して使うだけで、標本数には数えない。
- 帯内の的中は race あたり高々 1（排反）。代表倍率 ō は帯の幾何中央（849 / 1,732）。
  `SE(ROI) ≈ sqrt(deff · ROI · ō / (n̄ · 4,365))`（市場が較正に近いと仮定）。
  暦日 cluster と払戻の裾の追加分散は design effect（deff）1.0 / 1.5 / 2.0 で感度を見る。
- 帯は結果を見た後に選ばれている（付録 A3 の 9 帯のうち最良の山）。Bonferroni 片側閾値は k = 9 で z = 2.54（感度: k = 10 で 2.58、k = 15 で 2.71）。

## 結果（公表 n̄ を使用）

| 帯 | 基準との差 | n̄ | z（deff 1.0 / 1.5 / 2.0） | 必要 n̄（k = 9、deff 1.0 / 1.5 / 2.0） | 必要 n̄（k = 15、同） |
|---|---|---:|---|---|---|
| 600〜1,200 倍 | +10.6 pt | 127.6 | **2.98** / 2.43 / 2.11 | 92.7 / 139.0 / 185.4 | 105.8 / 158.7 / 211.6 |
| 1,200〜2,500 倍 | +9.5 pt | 194.4 | 2.32 / 1.90 / 1.64 | 232.5 / 348.7 / 464.9 | 265.4 / 398.1 / 530.7 |

- **600〜1,200 倍**: design effect 1.0 なら必要量（k = 9 で 92.7、k = 15 で 105.8）を超え、最良帯選択後も基準超過と言える水準。
  ただし **design effect 1.5〜2.0 では未達**（必要 139〜212 に対し 127.6）。暦日内の相関や払戻の裾が無視できないなら、選択の偶然と区別できない。
- **1,200〜2,500 倍**: **design effect 1.0 の必要量（232.5〜265.4）にも未達**（194.4）。最良帯選択後の基準超過は支持されない。
- **損益分岐**: 両帯とも点推定 < 1.0 で、公表 n̄ ではどの design effect でも CI95 上限 < 1.0。「黒字の帯」という証拠にはならない。

## 格付け

**「単年・terminal 価格・事後の帯選択による点推定。600〜1,200 倍の基準超過は design effect 1.0 の仮定の下でだけ有意、1,200〜2,500 倍は有意でない」**。
あわせて次の制約がある:

1. 2025〜2026 の単一期間で、発見と評価の分離がない（EXP21 の 2024/2025 封印とも別期間）。
2. terminal（確定）オッズで帯を決めており、購入時点で帯を知ることはできない（実行可能条件ではない）。
3. 帯境界が固定幅で、13 倍未満が主表に無い。
4. **EXP21 は三連単の全組価格源が無く（G0 FAIL）、この主張を再現も否定もできない。**
