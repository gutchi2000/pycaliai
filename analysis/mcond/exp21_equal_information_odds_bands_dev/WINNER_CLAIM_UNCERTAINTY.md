# 優勝者三連単表の +10pt — 公表値だけによる不確実性の格付け

**入力（公表値、SPEC §0）**: 2025〜2026 年 4,365 race、三連単確定オッズ 600〜1,200 倍の ROI 0.831、1,200〜2,500 倍の ROI 0.820。
控除率基準 0.725。手元の結果データは開いていない。計算は `winner_claim.py` → `out/winner_claim_uncertainty.json`。

## 前提

- 独立単位は **race（4,365）**。同じ race 内の数百〜数千 ticket を独立標本と数えない。
- 帯内の的中は race あたり高々 1（排反）。帯の race 平均 ticket 数を n̄、代表倍率を ō（帯の幾何中央: 849 / 1,732）として
  `SE(ROI) ≈ sqrt(ROI · ō / (n̄ · 4,365))`（市場が較正に近いと仮定）。暦日 cluster と払戻の裾の追加分散は design effect 1.0 / 1.5 / 2.0 で感度を見る。
- **原表の帯別組合せ数が手元に無いので n̄ はパラメータとして振った**（25〜800）。原表があれば確定できる。
- 帯は結果を見た後に選ばれている（主表の固定帯のうち最良の山）。主表の帯数 k を 10〜15 とし、Bonferroni 片側閾値 z = 2.58（k=10）/ 2.71（k=15）を使う。

## 結果

| 帯 | 基準との差 | 基準との差の z（design effect 1.0）: n̄ = 25 / 50 / 100 / 200 / 400 / 800 | 最良帯選択後も有意になる n̄（k=15） |
|---|---|---|---|
| 600〜1,200 倍 | +10.6 pt | 1.32 / 1.86 / 2.64 / 3.73 / 5.27 / 7.46 | **n̄ ≥ 106**（design effect 2 なら ≥ 212） |
| 1,200〜2,500 倍 | +9.5 pt | 0.83 / 1.18 / 1.67 / 2.36 / 3.33 / 4.71 | **n̄ ≥ 265**（design effect 2 なら ≥ 531） |

- **損益分岐**: どちらの帯も点推定 < 1.0。CI95 上限が 1.0 を超えるのは n̄ が数十と小さく design effect が大きい場合だけ（例: n̄ = 25・design effect 2 で上限 1.05 / 1.14）。
  「黒字の帯」という証拠にはならない。
- **控除率基準を上回る形状**: 帯あたり数百 ticket/race なら、単年でも race 単位の標本誤差に対して大きい。ただし次の理由で、EXP21 の格付けは
  **「単年・terminal 価格・事後の帯選択による未再現の点推定」**にとどまる:
  1. 2025〜2026 の単一期間で、発見と評価の分離がない（EXP21 の 2024/2025 封印とも別期間）。
  2. terminal（確定）オッズで帯を決めており、購入時点で帯を知ることはできない（実行可能条件ではない）。
  3. 13 倍未満が主表に無く、帯境界が固定幅で、同じ race 内の ticket を独立に扱った集計である。
  4. **EXP21 は三連単の全組価格源が無く（G0 FAIL）、この主張を再現も否定もできない。**
- 多重比較上の位置づけ: 主表の最良 2 帯を事後に選んだ比較なので、単独帯の z ではなく k = 10〜15 の Bonferroni 閾値と比べる必要がある。
  上表の必要 n̄ 未満なら、+10pt は選択の偶然と区別できない。
