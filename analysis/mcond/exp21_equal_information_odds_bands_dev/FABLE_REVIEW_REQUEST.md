# Fable宛て — EXP21 v0.1-draft レビュー依頼

AI競馬予想マスターズ2026優勝者資料の「三連単600〜2,500倍は控除率基準より約10pt高い」
という診断を出発点に、全8券種でオッズ帯構造を監査する仕様です。

今回の中心的な変更は、固定幅だけでなく次の三表を事前固定した点です。

1. 市場implied expected-hit massを10等分する主表
2. ticket数を10等分する副表
3. 1〜5倍、5.1〜15倍等の固定説明表

以下を重点レビューしてください。

1. raw ticket数ではなくexpected-hit mass等分をprimaryに置くことは妥当か。
2. `q_j` のrace内de-vig定義で券種間の比較精度を十分に揃えられるか。
3. ticket-weighted ROIを対象にしつつ、暦日cluster bootstrapで同一race内相関を保持する設計は妥当か。
4. 複勝・ワイドLo/Hiについて、結果非依存の代表価格を凍結できない場合に券種停止とする線は十分か。
5. G1の形状再現（同方向 + Spearman 0.70）とG2の50%保持は、結果前Gateとして強すぎる／弱すぎるか。
6. terminal診断とdecision-time実行可能表の分離に漏れがないか。
7. 2023全券種91列、2026の227列、既存馬連substrateについて、Stage 0で追加すべきprovenance検査はあるか。
8. 固定帯 `wide 5.1-15.0` を事前注目としつつGate上は特別扱いしない判断は妥当か。
9. 2024/2025を開けず、価格時点が不足する券種はforward待ちへ送る停止規律でよいか。
10. 本監査が既存の券種横断ROI探索を不当に再開する設計になっていないか。

まだ集計・パーサ拡張・結果列の読み込みは行っていません。レビュー後にspecを凍結し、
最初にG0データ契約だけをOpusへ渡す予定です。
