# EXP21 — 全券種・等情報量オッズ帯監査 仕様書 v0.3-frozen（§13 で v0.2 を部分改訂）

## 0. 目的と研究境界

AI競馬予想マスターズ2026優勝者資料は、2025〜2026年4,365レースの三連単で、
確定オッズ600〜1,200倍の払戻率0.831、1,200〜2,500倍の0.820という広い山を報告した。
しかし、13倍未満が主表に無く、固定帯、同一race内ticketの独立扱い、terminal価格による
帯選択という問題がある。

EXP21はモデル非依存の市場構造監査であり、黒字条件探索ではない。出力は
(a) favorite-longshot bias曲線、(b) 優勝者主張の再現可否、(c) 最も負けにくい帯の記述
に限定する。予測仮説を追加しないため研究停止線の「新規観測量なし」による開始禁止の対象外だが、
PASSしても買い目・配分・productionへ接続しない。

事前期待は、単勝・複勝・馬連で本命帯ROIが穴帯を上回るFLB曲線が出る一方、
控除率基準を上回る帯は少数で、損益分岐には届かない、である。三連単+10ptは現資産では
再現不能な単年・terminal・多重比較下の点推定として残る可能性が高い。

単一レースで完結する8券種を監査する。WIN5は対象外。

| 券種 | 歴史全組価格 | pre価格 | 本番号で到達可能 |
|---|---|---|---|
| 単勝・複勝 | TANPUK 2011〜2025 | historical_pre_snapshot（約T−28） | D0/D1/G1/G2 |
| 馬連 | UMAREN 2011〜2025 | historical_pre_snapshot（約T−28） | D0/D1/G1/G2 |
| 枠連・ワイド・馬単・三連複・三連単 | 2023単年91列（時点要同定）+ 2026 OD 227列（T−10、約49日） | 2026のみ | D0記述 + D1記述。G1/G2不可 |

## 2. 券種別控除率基準

全ticketへ同額を賭け、市場が較正されている場合の理論ROI (1-takeout) を固定する。

| 券種 | 基準ROI |
|---|---:|
| 単勝・複勝 | 0.800 |
| 枠連・馬連・ワイド | 0.775 |
| 馬単・三連複 | 0.750 |
| 三連単 | 0.725 |

帯ごとの差は損益分岐ではなくfavorite-longshot biasの測定値である。

## 3. 三種類の帯

### 3.1 Primary: equal expected-hit-mass 10帯

各ticketの q_j を価格だけから作り、累積 sum(q_j) が10等分になる境界を各券種・各期間で作る。
境界は結果を使わないため、発見期間と評価期間で別々に算出してよい。比較対象は価格幅ではなく
帯順位1〜10の形状である。

- 単勝・枠連・馬連・馬単・三連複・三連単: race内 1/odds を券種内で正規化。
- 複勝・ワイド: sqrt(Lo*Hi) を帯割当キーとしてのみ使う。ROIは公式払戻で決済する。
- 20帯感度は単勝・複勝・馬連だけ。その他は10帯のみ。
- outcome列を読んで境界を動かすことを禁止する。

### 3.2 Secondary: equal ticket-count 10帯

券種・期間ごとにticket数が等しくなる価格分位。ユーザー案の「1〜5倍帯と
1,000〜3,000倍帯の標本数を近づける」に対応する説明表で、主検定には使わない。

### 3.3 Descriptive fixed bands

[1,2], (2,3], (3,5], (5,10], (10,15], (15,25], (25,50], (50,100],
(100,300], (300,600], (600,1200], (1200,2500], (2500,5000],
(5000,15000], (15000,inf)

ワイド5.1〜15.0倍は事前注目帯だがGateで特別扱いしない。

## 4. 推論単位と報告値

- estimandは各eligible ticketへ100円を賭けたticket-weighted ROI。
- 同一race内の数千ticketを独立標本と数えない。
- 暦日meeting-day cluster bootstrap 10,000回、seedは実装前に固定。
- ticket数、race数、暦日数、期待的中mass、的中数、投資、払戻、ROI、CI95、
  控除率基準との差、損益分岐との差を報告。
- 払戻上位1/3/10 ticket除外、上位1/3日除外を必須。
- race数・日数・期待的中massが不足する帯は insufficient。閾値は結果前にpower監査で固定。

## 5. 価格時点

### D0 terminal diagnostic

### D1 decision-time descriptive/actionability audit

- 2026 OD: 真のT−10で帯を決めterminal決済。
- decision-time帯からterminal帯への遷移行列を出す。
- T−28とT−10を混ぜない。

## 6. G0 データ契約

結果集計前に券種別に実施する。

1. source path、sha256、期間、記録区分、価格/払戻単位をmanifest化。
2. ticket key一意性、対称/順序付き構造、self ticket=0、頭数別ticket数を検証。
3. 的中ticketと公式払戻をrace_id+ticket keyで突合。馬名join禁止。
4. 取消・除外・同着・返還・不成立を分け、黙って払戻0へ変換しない。
5. 2023 91列の単勝をTANPUK区分4、馬連18slotをUMAREN o_umfin と同raceで突合。
   99%以上一致ならterminal相当。9時側に99%以上ならpre相当。どちらでもなければ使用禁止。
6. 枠連・ワイド・馬単・三連系の列割当は構造推測だけで採用しない。kekkaの公式払戻と
   wide_payoutsを使い、的中ticketから列位置を逆引きして固定する。
7. terminal/pre区分不明ファイルはD1禁止。proxy・推測オッズによる補完禁止。

## 8. Gate

### G0 — Data contract

券種ごとに§6を全てPASS。FAIL券種は以後計算しない。

### G1 — Shape replication（単勝・複勝・馬連のみ）

Primary 10帯で次を全て満たす。

1. 控除率基準からの差の符号が発見・評価で一致する帯が10帯中8帯以上。
2. 帯順位ROIのSpearman相関が0.70以上。
3. 単一帯の黒字だけではPASSしない。

### G2 — Decision-time persistence（G1 PASS券種のみ）

発見期間D0で事前選択されたprimary帯順位だけを、評価期間D1で一度検定する。
同じ期間でD0帯を選びD1を検定しない。評価期間D1で、控除率基準からのupliftが
発見期間D0 upliftの50%以上残り、CI95下限が控除率基準を上回ればPASS。
ROI 1.0超は別に報告し、控除率超過と混同しない。

G1/G2 PASSでも「帯Xを買えば勝てる」と表現しない。次番号のforward shadow事前登録へ送るだけ。

## 13. v0.3-frozen（2026-09-27、Stage 1 の結果開封前に凍結）

Fable レビューで、単勝・複勝・馬連だけ Stage 1 へ進むことが承認された。本節は v0.2 の矛盾する規則を置き換える（v0.2 の記述は履歴として残す）。

- **基準**: 単勝・馬連は、各帯の label-free 較正 null（帯内 ticket の race の 1/overround を terminal 価格だけから作り、ticket 重みで平均）と比べる。
  法定控除率は参考値。馬連・枠連・ワイドの控除率が 2014-06-07 に変わったことを manifest に記録する（較正 null は race ごとに吸収する）。
- **複勝**: Lo/Hi の幾何平均は帯割当キーとしてだけ使い、払戻値にしない。Stage 1 の基準は同じ期間・価格層の全 ticket プール ROI。
  G1 は帯順位の Spearman ≥ 0.70 が主、プール ROI との差の符号一致は副。Stage 0 の power で使った合成 null は `synthetic_pay = baseline / q_null`。
  EXP18 で固定した JRA 複勝式が表示 Lo/Hi を再現できなかった（往復 Gate FAIL）ので、Lo/Hi を票シェアや確率へ逆算しない。
- **価格層**: 2026 OD を T−10 と呼ばない。terminal 5 日は D0 記述専用。前夜・未明の 36 日は時点未定義の価格層として保留。
  歴史 D1 は historical_pre_snapshot（約 T−28）だけ。T−10 は取得 0 日。
- **対象券種**: Stage 1 は単勝・複勝・馬連だけ。枠連・ワイド・馬単は D0 診断だけ。三連複は insufficient。三連単は G0 FAIL。
  優勝者の三連単高倍率帯主張は、EXP21 では再現も否定もできない先行主張とする。
- **G1**（単勝・馬連）: discovery D0 と evaluation D0 の primary 10 帯で、較正 null との差の符号一致 ≥ 8/10 かつ帯 ROI の Spearman ≥ 0.70。
  20 帯は感度（等級に使わない）。
- **G2**（G1 PASS 券種だけ）: discovery D0 で「uplift > 0 かつ bootstrap CI95 下限 > 0」の帯順位を**一度だけ**選び、その和集合を
  evaluation D1 で**一度だけ**検定する。evaluation D1 の uplift が discovery D0 の 50% 以上残り、CI95 下限 > 0 なら PASS。選択が空なら NOT_APPLICABLE。
  discovery D0 表を正式評価に再利用しない。等 ticket-count 帯と固定可読帯は副解析で、救済判定に使わない。ROI > 1.0 は別に報告する。
- **同着**: 券種ごとに除外して件数を報告（単勝: 1 着同着、馬連: 1・2 着の同着、複勝: 払戻対象数 ≠ places(n)）。取消馬の ticket は返還で eligible 外。
- **推論**: 年層化・暦日 cluster bootstrap、B = 10,000、seed 20260928。同じ期間の全券種・両価格層で同じ再標本を使う。
- **検出力の位置づけ**: Stage 0 の power は帯間独立の正規近似で、同じ race が複数帯へ寄与する相関を無視しているため楽観的な可能性がある。
  power は設計判断専用で、Stage 1 の有意性に使わない。
- **事前期待**（結果開封前に固定）: 単勝・馬連は本命帯 ROI > 穴帯 ROI の FLB 形状が再現する。複勝は同方向だが低倍率帯で頭打ち。
  較正 null を上回るとしても本命側 1〜2 帯に限られ、損益分岐 1.0 には届かない。D1 では pre → terminal の移動で勾配が縮む。
  G1 PASS を利益 edge と解釈しない。
- **provenance**: `PROVENANCE.md`（Stage 0 commit `aec789bb` に無関係 28 ファイルが混入した事実。過去 commit は修正しない）。
- ROI 最適化、モデル選択、賭け方・資金配分、production 変更は行わない。2024/2025 は封印を維持する。
