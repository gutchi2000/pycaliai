# EXP21 — 全券種・等情報量オッズ帯監査 仕様書 v0.1-draft

## 0. 目的

AI競馬予想マスターズ2026優勝者資料では、2025〜2026年4,365レースの三連単について、
確定オッズ600〜1,200倍で払戻率0.831、1,200〜2,500倍で0.820という広い山が報告された。
一方、主表は13倍未満を表示せず、券種ごとに同じ固定帯を使うため、低倍率帯の構造と
高倍率帯の標本精度を比較できない。

本監査の問いは次の2つに限定する。

1. 全標準券種に、控除率基準を安定して上回るオッズ帯構造が存在するか。
2. terminal価格で見える構造が、購入判断時価格で帯を決めても残るか。

これは黒字条件探索ではない。モデル、買い目、資金配分を変更しない。

## 1. 対象券種

中央競馬の単一レースで完結する8券種を別々に監査する。

1. 単勝
2. 複勝
3. 枠連
4. 馬連
5. ワイド
6. 馬単
7. 三連複
8. 三連単

WIN5は5レース積で推論単位が異なるため対象外。券種間で帯境界を共有しない。

## 2. 三種類の帯

### 2.1 Primary: equal expected-hit-mass bands

同じticket数でも、3倍帯と2,000倍帯では期待的中数が数百倍違う。比較精度を揃えるため、
各ticket `j` の市場implied mass `q_j` を足し上げ、累積 `sum(q_j)` が10等分になる境界を使う。

- 単勝・枠連・馬連・馬単・三連複・三連単: race内の `1 / odds` を券種ごとの総和で正規化。
- 複勝・ワイド: 全ticketで同一の事前価格定義を使用。Lo/Hiの片側だけ、的中後払戻、結果で
  選ぶ価格は禁止。採用する代表価格は往復・払戻整合監査を通過したものだけとする。
- 10帯をprimaryとし、20帯は境界安定性の感度分析だけに使う。
- 境界は結果列を読まず、価格だけで作る。

### 2.2 Secondary: equal ticket-count bands

券種ごとに全ticketを価格順に並べ、各帯のticket数が同じになる10分位を作る。
ユーザーの「1〜5倍帯と1,000〜3,000倍帯の票数を同程度にする」に対応する。

ただし同一raceの数千ticketは独立標本と見なさない。CIは暦日cluster bootstrapで計算する。

### 2.3 Descriptive: fixed readable bands

結果を見る前に次を固定する。

`[1.0,2.0], (2.0,3.0], (3.0,5.0], (5.0,10.0], (10.0,15.0],
(15.0,25.0], (25.0,50.0], (50.0,100.0], (100.0,300.0],
(300.0,600.0], (600.0,1200.0], (1200.0,2500.0],
(2500.0,5000.0], (5000.0,15000.0], (15000.0,inf)`

ワイド5.1〜15.0倍は事前注目帯だが、Gate判定を別扱いしない。

## 3. 推論単位とROI

- 1ticketへ100円を賭けたticket-weighted ROIを再現する。
- 同一race内ticketの相関を保ち、暦日単位paired cluster bootstrap 10,000回でCI95を出す。
- 表ごとにticket数、race数、暦日数、期待的中mass、実的中数、投資、払戻、ROIを記録する。
- 払戻上位1・3・10ticketを除く感度、上位1日・3日を除く感度を必須とする。
- 控除率基準との差とROI 1.0との差を別々に示す。
- 組合せ数が大きくてもrace数と暦日数が不足する帯は `insufficient` とする。

## 4. 価格時点を分離する

### D0 terminal diagnostic

terminal quoteで帯を決め、確定払戻で決済する。市場形状の診断に限り、実行可能な戦略とは
呼ばない。

### D1 actionable decision-time

T-10（なければ事前固定した最も近いpre snapshot）で帯を決め、terminal払戻で決済する。
購入時帯からterminal帯への遷移行列を券種別に出す。

D0とD1を同じROI表へ混ぜない。D1が存在しない券種はterminal診断で停止し、売買条件を
主張しない。

## 5. Stage 0 data gates

結果集計より先に次を券種別に判定する。

1. source path、sha256、期間、記録区分、価格単位、払戻単位をmanifest化。
2. ticket keyの一意性、対称/順序付き構造、self ticket=0、頭数別ticket数を検証。
3. 的中ticketと公式払戻をrace_id+ticket keyで突合。馬名joinは禁止。
4. 複勝・ワイドのLo/Hiは、結果と無関係な一つの価格定義を凍結できなければその券種を停止。
5. 取消・除外・同着・返還・不成立を券種別に分離し、0円払戻へ黙って変換しない。
6. terminal/preの区分が不明なファイルをD1に使用しない。

現時点の既知制約:

- 馬連は2013〜2025の9時/terminal基盤がある。
- 2023全券種ファイルは列配置と時点区分の再検証が必要。
- 2026の227列/T-10は券種ごとに被覆が異なる。
- 現パーサはワイド・馬単・三連系を完全には保証していない。

したがって「全8券種の表を必ず出す」のではなく、8券種すべてを監査し、契約を通過した券種だけ
表を出す。欠測を推測オッズで補わない。

## 6. 時系列規律

- 帯境界の作成期間と評価期間を分ける。
- 同一期間で境界を最適化して同じ期間のROIを採用しない。
- 2024/2025の既存封印を本監査のために解除しない。
- terminal診断の歴史資産しかない券種は、歴史をdescriptionに限定し、将来forwardを判定用にする。
- 2025〜2026を混ぜた優勝者表はprior artであり、採用判定のholdoutとして扱わない。

## 7. Gate

### G0 Data contract

券種別Stage 0の全項目がPASS。FAIL券種は以後計算しない。

### G1 Shape replication

Primary 10帯について、発見期間と評価期間で控除率基準からの差が同方向、かつ帯順位の
Spearman相関が0.70以上。固定帯の単一セルだけの黒字では通さない。

### G2 Actionability

D1がある券種のみ。事前注目帯を含む有望帯で、decision-time分類後のROI改善がterminal診断の
50%以上残り、CI95下限が控除率基準を上回ること。ROI 1.0超は別に報告し、混同しない。

G1/G2を通ってもproduction採用ではない。次番号でモデル非依存のforward shadowを事前登録する。

## 8. 多重比較と禁止事項

- 最良帯を選んでから境界を動かさない。
- 券種8 × 表3 × 帯多数の最小p値を採用しない。
- Primary形状が主検定。equal-countとfixed帯は説明・感度。
- 全券種のfamily-wise補正を報告する。
- 最良競馬場、月、クラス、頭数、人気構成との交差探索を本番号で行わない。
- AI確率、Harville順位、券種配分、Kelly、賭金を本番号へ追加しない。
- terminal帯を購入可能条件と表現しない。
- production、本番買い目、2024/2025、ROI方針を変更しない。

## 9. 完了時の表

券種ごとに次の三表と一図を作る。

1. equal expected-hit-mass 10帯
2. equal ticket-count 10帯
3. fixed readable bands
4. decision-time → terminal帯の遷移ヒートマップ

全券種横断表には、各券種の最良ROIではなく、G0/G1/G2、期間、race数、日数、価格時点、
primary形状の再現性だけを載せる。
