# EXP21 Stage 1 報告 — 単勝・複勝・馬連の等期待的中質量帯

**仕様**: v0.3-frozen（commit `e36ed2ca`、結果開封前に凍結）。判定は凍結した `evaluate_stage1.py` の規則だけで行った。
discovery 2013–2018 / evaluation 2019–2023、2024/2025 は封印。bootstrap は年層化・暦日 cluster、B = 10,000、seed 20260928。
全表は `STAGE1_TABLES.md`（primary 10 帯、4 期間 × 価格層）と `out/stage1_results.json`（副解析・集中除外・遷移行列を含む）。

## 0. 最終結論（Fable 最終レビュー承認、2026-09-27）

単勝・馬連の等期待的中質量10帯では、最大穴の1帯だけに較正null比−0.13〜−0.27の崖が再現し、残る9帯はおおむね±0.03前後で平坦だった（例外は馬連の帯1 +0.046〜+0.064 と、期間で位置が変わる単勝の帯8または帯9 +0.068〜+0.069。D0）。複勝は帯順位が再現したが、最大穴帯を除いたROIも0.784で、法定参考値0.80と損益分岐1.0の双方に届かなかった。全券種・期間・価格層でROI 1.0超の帯は存在しなかった。

射程外: 枠連・ワイド・馬単はD0記述のみ、三連複は標本不足、三連単は価格源なし、T−10・2024/2025は未検証。

## 1. 判定

同着・不整合で除外した race: 単勝 25 / 31、複勝 70 / 44、馬連 63 / 55（discovery / evaluation）。

## 2. 形状（evaluation D0、基準との差）

- **単勝**（基準 = 較正 null ≈ 0.797）: 帯 1〜9 は基準の ±0.03 前後で平坦。帯 3（2.5〜3.1 倍、+0.034）と帯 9（11.7〜21.3 倍、+0.069）が CI 下限 > 0。
  帯 10（21.3 倍〜）だけが **−0.159** と大きく沈む。discovery でも同じ「平坦 → 最終帯の崖」だが、基準を上回る帯の位置が違う（discovery は帯 8 = 8.3〜12.4 倍）。
  平坦部の順位はノイズで入れ替わるため、Spearman は 0.49 にとどまった。
- **馬連**（基準 ≈ 0.773）: 帯 1（〜5.0 倍）が **+0.046**（CI 下限 +0.015）、帯 2〜9 は平坦、帯 10（139 倍〜）が **−0.270**。discovery も同形（帯 1 +0.064、帯 10 −0.261）。
  ここでも平坦部の順位が入れ替わり、Spearman 0.35・符号一致 6/10 で FAIL。
- **複勝**（基準 = 全 ticket プール ROI ≈ 0.733）: 帯 1（〜1.3 倍）**+0.127** → 帯 2 +0.095 → 帯 3 +0.072 と本命側で段階的に下がり、帯 4〜9 は +0.03〜+0.05 の台、
  帯 10（7.3 倍〜）が **−0.081**。discovery もほぼ同じ並びで、Spearman 0.855。

## 3. G2（複勝のみ）

- discovery D0 で「uplift > 0 かつ CI95 下限 > 0」を満たした帯は **帯 1〜9 の 9 帯**（大穴の帯 10 以外のすべて）。
- evaluation D1（約 T−28 の価格で帯を決め、terminal で決済）の uplift は **+0.051**（discovery D0 の +0.061 の 84%）、CI95 下限 +0.042 > 0 → **PASS**。
- ただしこの uplift は**全 ticket プール ROI（大穴帯に引き下げられた平均）に対する差**である。選択帯の evaluation D1 ROI は **0.784** で、損益分岐 1.0 にも、
  法定控除率の参考値 0.80 にも届かない。G2 PASS が示すのは「約 T−28 の時点でも、最大穴の 1 帯を除くと全 ticket 平均より良い」ことだけで、利益の edge ではない。
- 9/10 帯が選ばれたのは、最大穴の帯 10 が全 ticket 平均（基準）を大きく引き下げたため、残る 9 帯がすべて機械的に基準を上回ったことによる。
  帯を選び分けた結果ではない。したがって G2 PASS は、G1 で確認した「最大穴帯の崖」が約 T−28 の価格でも再現したこと以上の情報をほぼ持たない。

## 4. 事前期待と結果

| 事前期待（v0.3 に固定） | 結果 |
|---|---|
| 単勝・馬連で FLB 形状（本命帯 ROI > 穴帯 ROI）が再現する | **部分的**。大穴 1 帯の崖（単勝 −0.13〜−0.16、馬連 −0.26〜−0.27）は両期間で再現。しかし帯 1〜9 は較正 null の周りで平坦で、段階的な勾配ではない。10 帯の順位相関は再現基準（0.70）に届かず **G1 FAIL** |
| 複勝は同方向だが低倍率帯で頭打ち | **方向は一致、頭打ちは見られない**。最低倍率帯（〜1.3 倍）が最も高く（+0.126〜+0.127）、段階的に下がって中位帯で台になる |
| 較正 null を上回るとしても本命側 1〜2 帯、損益分岐 1.0 には届かない | 馬連は本命帯 1 だけが上回り期待どおり。単勝は本命側ではなく 8〜21 倍の帯（期間で位置が違う）と 2.5〜3.1 倍が上回り、期待と違う。ROI が 1.0 を超えた帯は**どの券種・期間・価格層にも無い** |
| D1 では pre → terminal の移動で勾配が縮む | **観察されず**。大穴帯の沈みは D1 の方がやや深い（単勝 evaluation −0.159 → −0.179、複勝 −0.081 → −0.102）。中位帯の D1 − D0 は ±0.04 以内でまちまち |
| G1 PASS を利益 edge と解釈しない | 複勝の G1/G2 PASS も上記のとおり edge ではない |

## 5. 集中除外（evaluation D0 の例）

払戻上位 1/3/10 ticket と上位 1/3 暦日を除いても、各帯の ROI は大きく動かない（例: 単勝帯 9 は 0.866 → 0.857〜0.865、複勝帯 1 は 0.860 → 0.859、
馬連帯 10 は 0.504 → 0.476〜0.500）。結論は少数の高額払戻に依存していない。

## 6. D0 と D1

- evaluation 期の D1 帯と D0 帯が一致する ticket の比率は単勝 0.66、複勝 0.58、馬連 0.81。約 T−28 から締切までの価格移動で、帯の約 2〜4 割が入れ替わる。
- D1 − D0 の帯別 ROI 差は単勝 −0.04〜+0.04、複勝 −0.025〜+0.008、馬連 −0.06〜+0.015（`STAGE1_TABLES.md`）。

## 7. 解釈の範囲

- 閉じたのは、**単勝・馬連の等期待的中質量 10 帯で、較正 null からの差の形状が 2013–2018 と 2019–2023 で順位まで再現するか**という問い（FAIL）。
  大穴帯の崖は両期間で再現しているので、「FLB が無い」とは言わない。平坦部の順位が再現しないという意味である。
- 複勝の PASS は「帯の順位形状が期間を越えて再現し、最大穴の帯を除けば約 T−28 でも全 ticket 平均を上回る」ことの記述で、控除率超えでも利益でもない。
- 単勝の「8〜21 倍が較正 null を上回る」は期間ごとに帯の位置が違い、事前選択していないので主張しない（救済に使わない）。

## 8. 未検証の範囲

- 枠連・ワイド・馬単は D0 診断だけ（2023 terminal 1 年と 2026 terminal 5 日）、三連複は insufficient、三連単は G0 FAIL。
- T−10 の価格は取得 0 日。2026 OD の前夜・未明 36 日は時点未定義の価格層として保留。
- 2024/2025 は開けていない。
- 等 ticket-count 帯・固定可読帯・20 帯は副解析で、判定・救済に使っていない。
- 優勝者の三連単高倍率帯の主張は、EXP21 では再現も否定もできない先行主張のまま。
