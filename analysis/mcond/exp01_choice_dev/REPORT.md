# 第1実験 報告: 陣営選択の逸脱 (MCOND-EXP01-CHOICE-DEV)

実行: 2026-09-18 / 仕様固定コミット `a41e7e96` (spec.json 未変更で実行) / 本番への接続なし

---

## 平易な結論

1. **陣営の異例な選択に、追加情報はあったか。**
   あった。ただし非常に小さい。現行AIと発走約35分前の市場確率の両方を与えた後でも、逸脱の指標を足すと3着内の予測誤差（logloss）が 2023年で 0.00056 下がった（97.5%CI [−0.00090, −0.00023]）。2024年・2025年も同じ向き。基準の誤差 0.419 に対して 0.13% の改善。

2. **生の選択列だけで説明できたか。**
   **ほぼ説明できた。** 「間隔・距離変更・場所変更・芝ダ変更・クラス移動・騎手継続」などの生の選択を足したモデル（M2）に対して、逸脱の指標を上乗せしても（M4）、2023年の改善は CI が 0 をまたぎ、上位20調教師を除くと符号が逆になった。事前に決めた判定規則では **「選択情報は有効だが、逸脱モデル固有の価値はなし」**。

3. **現行AIと市場を考慮しても残ったか。**
   生の選択情報は残った（M2 vs M1 も事前条件4つを全て満たした）。つまり「騎手の継続・出走間隔・条件替わり」という公開された事実の中に、発走35分前の市場がまだ織り込み切っていない情報が、ごく少しある。「この厩舎にしては異例」という量に固有の上積みは確認できなかった。

4. **年度をまたいで再現したか。**
   向きは 2023・2024・2025 で揃った（M3・M4 vs M1）。9時の市場で条件付けても同じ向き。ただし1着（勝ち馬）の予測には全く効かない（CI が 0 を中心に対称）。効いているのは3着内の予測だけ。

5. **利益へ変換できる大きさだったか。**
   **できなかった。** 事前登録した2つの購入ルールで、逸脱入りモデルと現行AI＋市場の差は、割安判定ルール（R1）で −1.14pt（95%CI [−3.3, +1.0]）、各レース最上位1頭（R2）で +0.15pt（[−0.4, +0.7]）。どちらも控除率の内側（R1 75%前後、R2 85.5%）。

6. **次の研究へ進む価値があるか。**
   陣営選択の逸脱は、仕様 §17 に従いここで打ち切る（パラメータ調整はしない）。共通基盤はそのまま使えるので、次は計画書の順に **動的対戦能力と不確実性** を同じ物差しで検定する。
   副産物として「現行AIは、発走35分前の市場に対しても3着内の予測で情報を足している」（M1 vs M0 が全年・全人気帯で改善）ことが確認できたが、R2 の回収率は市場1番人気の複勝均等買い（85.2%）とほぼ同じで、これも利益には変換されていない。

## 不採用の理由

- **逸脱モデル固有の価値がない**: 生の選択を入れた対照 (M2) に対して、事前に決めた4条件のうち3つを満たさなかった (CI、調教師集中、人気帯)。改善は一部の調教師に集中していた可能性がある
- **利益に変換されない**: 3着内の予測誤差の改善は基準の 0.13%。購入ルール上の差は ±1pt 程度で CI が 0 をまたぐ
- パラメータ調整・特徴の追加・閾値の変更は行っていない (仕様 §17)

## 追記: 仕様固定後の探索分析 (2026-09-18, `supplement.py`)

仕様書との突き合わせで見つかった抜け3つを埋めた。仕様 §12 に従い**探索分析として主検定と分離**する。主判定「選択情報は有効だが、逸脱モデル固有の価値はなし」は変更しない。

### 1. 競馬場への集中 (§13.2) — 集中なし
2023-25 合算の Δlogloss:
- M3 vs M1: **10/10 場で改善** (範囲 −0.00085〜−0.00012)。最も寄与した阪神を除いても −0.00044
- M4 vs M1: **10/10 場で改善** (−0.00087〜−0.00008)。阪神を除いても −0.00040
- M4 vs M2: 7/10 場で改善 (−0.00039〜+0.00027)
→ 生の選択・逸脱が現行AI＋市場に足す情報は、特定の競馬場に偏っていない。

### 2. 順位 (§10 副次) — 逸脱に小さな上積みの兆候
レース内の順位相関 (Spearman) とペア正解率、開催日ブロック bootstrap 95%CI:

| M4 vs M1 | 2023 | +0.0065 [+0.0050, +0.0080] | +0.0026 [+0.0020, +0.0032] |

| **M4 vs M2** | 2023 | **+0.0018 [+0.0006, +0.0029]** | **+0.0005 [+0.0000, +0.0010]** |
| **M4 vs M2** | 2024-25 | **+0.0012 [+0.0005, +0.0019]** | **+0.0005 [+0.0001, +0.0008]** |

ただし: (a) 副次指標であり、仕様 §10 により主検定へ昇格させない (b) 大きさはペア正解率で +0.05pt と極小 (c) Gate 3 で経済的差は出ていない。
→ 「逸脱に固有の情報がまったく無い」とまでは言えない。「あっても順位を 0.05pt 動かす程度で、確率の精度にも利益にも表れない」が正確な表現。
