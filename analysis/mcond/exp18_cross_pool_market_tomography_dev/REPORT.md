## 0. 正式結論（Fable 最終判定: 文言修正後承認）

EXP18は、較正済みterminal馬連市場に対する単勝由来T1のoffset残差について、2019〜2023 pooled評価では改善を検出したが、その改善は2021・2022年に依存し、2023年は逆符号となった。事前固定したleave-one-year-out年安定性条件を満たさなかったため、Gate M1をFAILと判定した。効果量約0.0014 nats/raceは、仮に年安定性条件を満たしても、凍結した実務床0.0093の約1/6であり、長期的な正の資金成長を支持する経済的証拠にはならない。複勝Lo/Hi制約は固定式の往復再現に失敗したため未検証である。本結論を全券種・全時点・JRA全市場・他の共同分布モデルへ一般化しない。

**副次結果**

- 2023 年に OOS 利得が消えたことは市場効率化と整合するが、原因として断定しない

**終了状態**

- EXP18 = complete / Gate M1 FAIL

- 2024/2025 = 未開封のまま維持
- M2、ROI、候補生成、資金配分、T2 救済 = 開始しない

- 新しい実験を自動開始しない

## 1. 結論

**Gate M1 = FAIL**（理由: leave-one-year-out の CI95 上限 < 0 を満たさない年がある）。仕様の停止規律 6 により **EXP18 は終了する**。

> 較正済み terminal 馬連市場に対する単勝由来 T1 の offset 残差情報を、2019-2023 rolling 評価で検出できなかった。
> 全券種・全プール・JRA 全市場へ一般化しない。（`grade_m1` の凍結文言）

pooled の CI95 は 0 未満だったが、2021 年または 2022 年を除くと CI95 上限が 0 を超える。事前固定した SIGNAL 条件は
「全 LOO で CI95 上限 < 0」を要求するので、残差情報が頑健に検出されたとは言えない。仮に SIGNAL を満たしていても、
CI95 上限（−0.00053）は実務床の符号反転値（−0.00933）に遠く届かず、PASS-PRACTICAL にはならなかった。

## 5. 副次指標（報告のみ、Gate に使わない）

| 指標 | pooled | CI95 | 年方向 |
|---|---|---|---|
| UB1（T0 Harville を source）の Δ | −0.001419 | [−0.002340, −0.000490] | 4/5 |
| **UB2 − UB1**（λ 割引の上乗せ） | −0.0000257 | [−0.0000626, +0.0000115] | 3/5 |
| T1 − T0 頭対頭（LL(q_T1) − LL(q_T0)） | −0.00581 | [−0.00724, −0.00443] | 5/5 |

- UB2 と UB1 はほぼ同じで、λ 割引（Stern）は offset 残差の上ではほとんど何も足さない。頭対頭では T1 が T0 より明確に良い
  （既知の Harville 偏りの補正）が、較正済み馬連市場に対する残差としては差が消える。
- UB1 の β（0.23〜0.26）は keiba-masters-kit の Harville 係数 0（三連単市場に対する 46 race holdout）と対照的だが、
  別プール・別標本・別設計であり、どちらも本判定の根拠にしない（v0.5 の取り決めどおり）。
- 競馬場別の平均 Δ は 10 場中 8 場で負、小倉（+0.00047）と福島（+0.00287）が正。leave-one-venue-out の CI95 上限は全て < 0
  （−0.00024〜−0.00076）。競馬場への依存より年への依存が大きい。
- U0P（比例 de-vig）は、a・a0 がべき乗を吸収するので Gate モデルは構成上同一（別計算していない）。

## 6. 解釈（射程）

- 閉じるのは、**terminal 単勝市場から作った T0/T1 の順不同 top2 確率を、γ 較正した terminal 馬連市場へ入れ子の offset として
  足す**経路の、2019〜2023 rolling 評価である。
- fit 窓では β が一貫して正で、pooled 評価でも CI は 0 未満だった。しかし改善は 2021・2022 年に偏り（両年とも pooled の約 2.3〜2.5 倍）、
  2023 年は逆符号だった。どちらか 1 年を抜くと CI が 0 を跨ぐので、事前固定の頑健性条件を満たさない。
  「単勝と馬連は完全に整合している」とも「残差情報が存在する」とも主張しない。
- 仮に頑健だったとしても、効果量（点推定 0.0014、CI 上端 0.0024）は、実 terminal オッズで長期成長 1e-4 / race を得るのに必要な
  0.0093 の約 1/4 にとどまる。
- 一般化しない範囲: 複勝を使う T2（Stage 0 で往復 Gate FAIL・未実装）、他の対象券種（ワイド・馬単・三連系）、pre 時点（M2 は未実施）、
  2024/2025、他の de-vig・tomography 族。
- 救済探索（年・競馬場・人気帯・券種・de-vig の選び直し、T2 の復活、別の払戻式）は行わない。

## 7. 実施しなかったこと

2024/2025 の開封、M2、ROI、候補生成、資金配分、production 変更、economic checks（PASS-PRACTICAL でないため）。
