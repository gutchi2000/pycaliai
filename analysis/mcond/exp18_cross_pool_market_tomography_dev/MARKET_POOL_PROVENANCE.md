## 2. 列の意味

| プール | 列 | 意味 |
|---|---|---|
| TANPUK | `n単` | 馬番 n の単勝オッズ（n=1..18） |
| TANPUK | `n複Lo` / `n複Hi` | 馬番 n の複勝オッズの**範囲**（下限・上限） |
| TANPUK | `単勝票数` / `複勝票数` | **券種全体**の票数（馬別ではない） |
| UMAREN | `馬ii-jj` | 馬番 i-j（i<j）の馬連オッズ、全 153 組 |
| UMAREN | `馬連票数` | **券種全体**の票数（**組合せ別の実票数ではない**） |

票数は流動性の metadata としてだけ扱う。組合せ別実票数とは呼ばない。票数は pre → terminal で
**全 37,998 race で単調増加**（単勝・馬連とも）しており、累積の券種全体票数という解釈と整合する。

## 4. 組合せ格子と 0.0 / 欠損の区別

- 理論組数は starter 数 n に対し `n(n−1)/2`。UMAREN の 153 列のうち `i>頭数 または j>頭数` の列は
  **頭数外**（0.0）、starter でない馬（締切前取消）を含む列は **取消・返還可能性**（0.0）、
  starter 同士の列は**実格子**。
- 実測（terminal、2013–2023）: **starter 同士の組で 0.0・欠損は 0 件**、オッズ 1.0 ちょうども 0 件。
  0.0 はすべて頭数外か取消馬を含む組に分類された（年別の件数は `RACE_AND_TICKET_COVERAGE.json`）。
- starter = terminal 単勝オッズ > 1.0 の馬番（EXP16A と同定義）。締切後の取消・返還は市場表示に現れない
  （EXP16A の監査で締切後除外の痕跡 0 件）。

## 6. 結果条件付きの除外（DNF・1着2着同着）

DNF（terminal starter なのに finisher 行が無い馬がいる race）と 1着・2着の同着は**結果による条件付け**なので、
2019–2023 では Stage 0 で数えていない（Stage 1 で結果 loader により適用する）。≤2018 だけ結果 loader で数えた:

| 年 | eligible | DNF race | 1着・2着同着 race | 結果行なし |
|---|---|---|---|---|
| 2013 | 3,324 | 168 | 6 | 0 |
| 2014 | 3,326 | 150 | 12 | 0 |
| 2015 | 3,326 | 134 | 13 | 0 |
| 2016 | 3,326 | 132 | 15 | 0 |
| 2017 | 3,329 | 149 | 10 | 0 |
| 2018 | 3,328 | 138 | 15 | 0 |
| **2013–2018** | **19,959** | **871**（4.4%） | **71**（0.4%） | **0** |

- DNF の定義は「terminal starter（確定単勝 > 1.0）のうち master に finisher 行が無い馬がいる race」（`loaders.dnf_horses`、
  EXP16A と同定義）。master_v2 は DNF 馬の行を持たない（着順 NaN の行が無い）ので、着順 NaN を数える方法では
  DNF が常に 0 になる。Stage 0 の途中でこの誤りを見つけ、anchor と provenance を starter − finisher の定義で再計算した。
- 2019–2023 の DNF・同着は Stage 1 で結果 loader により同じ定義で除外し、年別に報告する。
