## 1. 目的

T2_SOFT_FUKUSHO_MAXENT は複勝市場の「各馬の top-k 入り確率」を soft 制約として使う。
表示されている複勝オッズは Lo/Hi の**範囲**であり、確率そのものではない。表示から
複勝プールの票シェアを逆算し、それを同じ式で表示へ戻したときに表示を再現できるかを確かめる。
再現できなければ、表示から作る制約は式の誤り・丸め・返還処理のいずれかで汚れているので、
**T2 は未実装として停止する**（別の関数形で救済しない）。

## 2. 使用する JRA 複勝払戻式（実行前に固定）

| 項目 | 固定した内容 |
|---|---|
| 純プール | `D = (1 − 0.20) · V`（V = 複勝プール総票数。控除率 20%） |
| 的中票控除 | 払戻対象 k 頭 W の元本 `Σ_{j∈W} V_j` を D から差し引く |
| `places(n)` による分配 | 残り `D − Σ_{j∈W} V_j` を k 頭で**等分**する。1 票あたり利益 = `(D − Σ_{j∈W} V_j) / (k · V_i)` |
| オッズ | `odds_i(W) = 1 + (D − Σ_{j∈W} V_j) / (k · V_i)` |
| 表示 Lo | 他の k−1 頭が**票数上位**（最も人気）の場合 = 最小値 |
| 表示 Hi | 他の k−1 頭が**票数下位**（最も不人気）の場合 = 最大値 |
| 10 円 breakage | 表示は **0.1 倍単位の切り捨て**（払戻の 10 円単位切り捨てと同値）。下限 1.0（元返し） |
| `places(n)` | 出走（starter）8 頭以上 → k=3、5〜7 頭 → k=2（4 頭以下は複勝発売なし） |
| starter | 確定単勝オッズ > 1.0 を持つ馬番（EXP16A と同定義）。締切前取消は pool に居ない |
| 取消・返還 | 締切前取消は starter から除外する。締切後の返還は表示に現れないので往復では扱わない |

シェア `v_i = V_i / V` で書けば式は票の尺度に依存しない（0 次同次）ので、総票数列は使わない。

## 3. 逆算の数値解法（式とは別。式を変えない）

人気順（表示 Lo、同値は Hi の昇順）を固定すると、各馬の「他の上位 k−1 頭」「他の下位 k−1 頭」が
決まり、丸め前オッズが切り捨て区間 `[表示, 表示+0.1)`（表示 1.0 は下側を課さない）に入る条件は
シェア v について**線形不等式**になる:

`v_i·(k(L−1)+1) ≤ (1−t) − Σ_{j∈C_i} v_j < v_i·(k(U−1)+1)`

Σv=1・v>0・人気順の単調性を加え、全不等式の最小余裕を最大化する LP（HiGHS）で内点を取る。
表示が完全に同じ馬（tie）の順序は表示から決まらないので、tie 群の中の順列（最大 64 通り）を試し、
再生成が一致したものを採る。

**合成検査**（式が正しい世界で表示を作り、逆算して戻す）: 1,000 race で馬行一致率 **100.0%**、
race 全馬一致 **100.0%**、1 race あたり 2.6 ms（`test_invariants.py` の
`place_formula_synthetic_roundtrip` にも組み込み）。したがって実データで不一致が出れば、
それは**解法ではなく式（または表示データ）の不一致**である。

## 5. τ と T2 の単一形（spec どおり。通過時だけ実装）

- **τ の定義（宣言）**: 逆算したシェアから `τ_i = places(n) · v_i`。Σ τ = places(n) を構成的に満たす。
  これは「複勝プールの票シェアを k 倍したもの」という宣言した写像であり、真の top-k 確率だとは主張しない。
- **T2**: 事前 = T1（λ 割引 Harville）の順序付き top-k 分布。単勝 marginal は**等式制約**
  （先頭馬ごとのブロック再規格化で厳密に満たす）、複勝は `w_fuku · Σ_i (P_q(i∈top-k) − τ_i)²` の
  単一ペナルティ形、`k = places(n)`、`w_fuku ∈ [0,1]`。KL(q‖q_T1) + ペナルティを最小化する。
  `w_fuku = 0` は T1 を同じ計算でそのまま返す（bit 一致、`T2_w0_equals_T1_bitwise`）。
- **Stage 0 の dry-run fit**（通過時だけ）: λ は T1 の ≤2018 fit 値に固定し、
  `w_fuku ∈ {0, 0.1, …, 1.0}` を 2016〜2018 の realized 順不同 top2 logloss（結果 loader、≤2018）で選ぶ。
  2019 年以降の結果は使わない。
