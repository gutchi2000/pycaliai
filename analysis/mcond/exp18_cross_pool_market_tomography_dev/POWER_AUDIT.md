## 1. 固定した生成構造（spec §S0-E、seed 20260925 を実行前に固定）

| 項目 | 内容 |
|---|---|
| 真の分布 | `p ∝ m_cal · exp(ε · s_true)`。`s_true` = race 内で中心化・標準化した `log q_T1 − log m_cal`（UB2 の source 方向） |
| 効果の大きさ Δ | `ε` を平均 `KL(p‖m_cal) = Δ`（真の期待 logloss 改善）に較正 |
| 推定 | `q_est ∝ m_cal · exp(ε · s_true + noise)`、noise ~ N(0, 2Δ) を組ごとに独立 |
| noise の大きさ | `SD(noise) = sqrt(2Δ)` は label-free の**宣言慣習であり、導出ではない** |
| 決済 | 馬連倍率 `o = 0.775 / m_cal`（控除率 22.5%） |
| 参加 | `max(q_est / m_cal) > 1/0.775` の race だけ、現金込み Kelly（排反事象の閉形式）で賭ける |
| 成長 | 真の p の下での期待対数成長の race 平均（賭けない race は 0）。noise は 3 draw 平均 |
| 実務床 | 期待対数成長 ≥ **1e-4 / race** となる最小の Δ（格子の線形補間） |
| 母集団 | 2019〜2023 の eligible 16,644 race（2,525,787 組のうち評価年分） |

EXP16A の 0.005 は流用していない。`-log(0.775) = 0.2549 nats` は全額比例投入の参考条件で、hard gate にしていない。

## 3. 補助診断（記述用。床・Gate の定義は変えない）

`power_diagnostics.py`（seed 20260926）。

**D1 noise-free 対照**（q_est = p）: 真の p で Kelly を張れば期待成長は負にならないはずで、実際に全点 ≥ 0 だった
（Δ = 0.001: +0.000000、0.005: +0.000036、0.02: +0.00169、0.05: +0.0105、0.1: +0.0341、0.2: +0.0978）。
したがって Kelly・決済・参加条件の実装は正しく、§2 の負の成長は noise の宣言慣習から来ている。
（参考: noise が無ければ成長 1e-4 に届く Δ は約 0.0056。Gate には使わない。）

**D3 推定の情報利得**: 宣言慣習の下で、推定 q_est の市場に対する期待 logloss 利得
`KL(p‖m) − KL(p‖q_est)` は Δ の約 7〜8% にとどまる。

| Δ | KL(p‖m) | KL(p‖q_est) | 利得 |
|---|---|---|---|
| 0.005 | 0.005 | 0.00468 | 0.00032 |
| 0.02 | 0.02 | 0.01856 | 0.00144 |
| 0.1 | 0.1 | 0.09247 | 0.00753 |
| 0.2 | 0.2 | 0.18336 | 0.01664 |

noise の分散 2Δ は、組ごとに独立だと `KL(p‖q_est) ≈ ½·2Δ·(1 − Σp²)` を生み、信号の `KL(p‖m) = Δ` をほぼ
打ち消す。推定が市場とほぼ同じだけ真の分布から離れているので、控除 22.5% を払って Kelly で張っても、
期待成長が正になるのは Δ が 0.9 nats 近くになってからになる。

## 4. 検出力（宣言効果 = 実務床）

合成 winner を p から引き、年 Y（2019〜2023）ごとに 2016..Y−1 の合成データで温度 null（a0）と cross 代替（a, β）を
rolling fit し、`Δ_r = LL(q_cross) − LL(q_temp)` を年層化・暦日 cluster bootstrap（1,000 回）で集計した。
SIGNAL = CI95 上限 < 0。「全統計条件」= SIGNAL かつ 4/5 年で負かつ全 leave-one-year-out の CI 上限 < 0。

| 宣言効果 | Δ | rep | **SIGNAL 検出力** | Wilson 95% | 全統計条件 | 推定 Δ の中央値（中央 CI95） | 減衰 |
|---|---|---|---|---|---|---|---|
| **実務床** | **0.8843** | 400 | **1.000**（400/400） | [0.990, 1.000] | 1.000 | −0.742（[−0.762, −0.723]） | 0.84 |
| 0.5 × 床 | 0.4422 | 200 | 1.000（200/200） | [0.981, 1.000] | 1.000 | −0.392（[−0.405, −0.378]） | 0.89 |
| 2 × 床 | 1.7686 | 200 | 1.000（200/200） | [0.981, 1.000] | 1.000 | −1.394（[−1.421, −1.369]） | 0.79 |

**検出力 Gate（宣言効果で SIGNAL 検出力 ≥ 80%）: PASS**（1.000、Wilson 下限 0.990）。所要 6,325 秒。

**減衰の注記**: 真の効果が床ちょうど（0.8843）でも、推定 Δ の中央値は 0.742 で床を下回る（減衰 0.84）。
これは生成側の方向（race 内で標準化した `log q_T1 − log m_cal`）と、fit 側の cross 代替
（標準化しない `a·log m_cal + β·log q_T1`）の関数形が一致しないためで、rolling fit が真の傾きの 8 割強しか
回収しない。SIGNAL 検出力には影響しないが、「pooled 点推定 ≥ 床」を要求する PASS-PRACTICAL は、真の効果が床に
あっても大半の rep で満たされない。

## 5. 解釈（Fable レビュー事項、本版では変更しない）

- 実務床 0.8843 nats は、全額比例投入の参考値 0.2549 の約 3.5 倍、≤2018 anchor における Harville（T0）と市場の
  差全体（0.0416）の約 21 倍である。馬連市場の race-level logloss は約 3.39 nats なので、PASS-PRACTICAL には
  非対象プールの情報で市場 logloss を 1/4 以上削ることが必要になる。
- この大きさは市場の性質ではなく、主に `SD(noise) = sqrt(2Δ)` の宣言慣習から来ている（§3 D1・D3）。
- さらに §4 の減衰（0.84）により、真の効果が床にあっても点推定は床を下回りやすい。
- 凍結仕様のままでは Stage 1 の PASS-PRACTICAL は実質的に到達不能であり、Stage 1 で得られる判定は事実上
  PASS-SIGNAL か FAIL に限られる。どちらも仕様上は M2 へ進まず停止する。
- 慣習を変える（例: noise を Δ と独立に置く、推定誤差を ≤2018 の実 fit 誤差から見積もる）なら、新しい版番号で
  結果開封前に固定し直す必要がある。本 Stage 0 では変更していない。

## 6. v0.5 の実務床（方式。数値は floor 固定 commit で追記）

- **宣言的な独立ノイズは加えない**。推定誤差は、凍結済みの実際の推定器 `q_cross`（`fit_cross`）を有限の合成標本から
  fit したときの誤差だけで表す（`floor_v05.py`）。
- **真値**（主方式 ρ=1）: `log p = log m_cal + ε·c`、`c` = race 内中心化した `log q_T1 − log m_cal`。これは `q_cross` 族の
  `a = 1−ε, β = ε` そのもの（正しく指定された世界）。**真の Δ** = 2019〜2023 評価 race 上で、期待 logloss 最良の温度 null
  `q_temp(a0*)` に対する `KL(p‖q_temp)` の平均。ε は真の Δ が格子値になるよう二分法で較正。
- **fit**: 各年 Y で `≤Y−1`（2013..Y−1）の合成 formal race から合成 winner を引き、`(a, β)` を実際に fit。
  件数 `n_fit(Y)` は実 formal race 数に合わせる（2019: 19,027 / 2020: 22,197 / 2021: 25,372 / 2022: 28,546 / 2023: 31,721）。
  ≤2018 は結果 loader（≤2018）で数えた実数、2019 以降は構造 eligible 件数 × ≤2018 保持率 0.9533 を seed 固定の一様抽出で選ぶ
  （件数合わせのみ。2019〜2023 の結果は読まない）。γ・λ は ≤2018 dry-run 値に固定（λ 推定誤差を含めない分、床は楽観側）。
- **決済**: 年 Y の合成評価 race を**実 terminal 馬連オッズ**で決済し、fit 済み `q_cross` による現金込み Kelly の期待対数成長を
  真の p の下で解析的に計算（参加は Kelly 自身の条件）。
- **床**: 24 rep 平均の期待成長が `1e-4 / race` 以上となる最小の真の Δ（格子 0〜0.5 の 18 点、初回交差点と直前点の線形補間）。
- **感度 ρ=0.5**（参考値、主 floor と混ぜない）: 真の log 傾き = `ε·(0.5·c + sqrt(0.75)·v)`、v は race 内で
  `[1, log m_cal, log q_T1]` に直交化し `‖v_r‖ = ‖c_r‖` に揃えた固定乱数方向。推定器は `0.5·c` 成分（振幅の 50%）しか回収できない。
- **seed**: 主 20260927 / 件数抽出 20260928 / v 方向 20260929。**rep**: 成長 24、検出力は床で 400・0.5 倍 / 2 倍 / Δ=0 で各 200。
- **検出力**: 床の真の効果で、Stage 1 と同じ rolling fit・年層化暦日 bootstrap（simulation は B=1000）・年方向・LOO を合成 outcome で
  回し、凍結済み `gate_grade.grade_m1` で等級を付ける。placebo 条件は計算量のため通過と仮定（宣言）。推定器は決定論的なので seed 条件は
  pooled の符号に従う。**Stage 1 の進行可否は床での SIGNAL 検出力 ≥ 0.80**。床ちょうどの効果に対する PASS-PRACTICAL 検出力は低いはずで、
  別に計算して報告する（`CI95 上限 < −floor` は実務床を 95% 信頼水準で上回ったと主張する厳格な等級であり、床ちょうどの効果を
  高確率で通す検出条件ではない）。
- **成長閾値 `1e-4 / race` は変えない**。年約 3,300 race なら対数成長 約 0.33、単純換算で約 **+39% / 年**に相当する高い基準である。
- **floor 探索前の合成 oracle / invariant テスト 20/20 PASS**（`test_floor_v05.py` → `out/floor_v05_tests.json`）: 真値が `q_cross`
  族に入ること、ε=0 で真値 = 市場・Δ=0、ε 較正、a0* の独立検算、ρ 方向の直交性、大標本で推定器が真値を回収（z = 1.43 / −1.00）、
  ρ=0.5 で回収率 0.49、真値 = 市場なら実オッズで正 EV の組が無く成長 ≤ 0、oracle Kelly 成長 ≥ 0、真の係数で `q_cross = p`、
  推定経路に独立ノイズが無いこと、seed 決定性、決済オッズ = 実 terminal 馬連オッズ（bit 一致）、n_fit 表、補間規則、Gate 境界。
