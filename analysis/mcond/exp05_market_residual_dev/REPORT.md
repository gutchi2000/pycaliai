# EXP05 市場条件付き第2段確率モデル — 結果

spec: `spec.json` (commit `876156d9`)。実装: `build_features.py` / `models.py` / `tie_diagnosis.py` / `run.py`。
2026年ロック不可の判定根拠: `LOCKED_PERIOD_AUDIT.md`。**Gate2以降は探索的評価であり、最終確証ではない。**

## 平易な回答 (spec §24)

1. **EXP04の通常モデル改善は未使用期間でも再現したか** — 再現した。EXP05独自の実装(offset構成が
  EXP04と異なる)でも、全候補プールモデル(M5)がv6+市場だけのモデル(M1)を2023・2024・2025年**全て**で
  有意に上回った(Δlogloss −0.0015〜−0.0015、95%CIいずれも0をまたがない)。
2. **改善はv6較正の情報圧縮を直しただけか** — 直しただけではない。calibrated_v6_probability+市場
  (M1) に生スコア・順位を足しても(M2)、レース内相対特徴を足しても(M3)、logloss はほぼ変化しない
  (2023: M1=0.41303→M2=0.41304→M3=0.41301、小数第4位レベルの差)。改善のほぼ全ては M3→M4/M5、
  つまり**表特徴を足した段階**で起きている。情報圧縮(p_win同値)は実在する(較正確率はレース内最大値
  タイ率3.85-5.00%、生スコアは0%)が、この同値の解消では説明できない。
3. **元の表特徴に市場条件付きの追加情報があったか** — あった。M4(offset(M3)+F-serve) vs M3の
  Δlogloss は2023 −0.00132 [−0.00184,−0.00078]・2024 −0.00138 [−0.00203,−0.00077]・
  2025 −0.00147 [−0.00205,−0.00088]、いずれも99%水準でも0をまたがない。競馬場別でも10場中10場、
  人気帯別でも4帯中4帯全てM4が有利という点でEXP04のI1選別失敗より遥かに頑健。
4. **本番で取得できる特徴だけでも成立したか** — 成立した。F-serve(117列, 本番serveで死んでいる28列
  を除外)によるM4は、F-full(145列)によるM5とほぼ同水準(M5 vs M4のΔは2023 −0.00021
  [−0.00038,−0.00004]で辛うじて有意だが、2024 [−0.00034,+0.00005]・2025 [−0.00023,+0.00013]は
  CIが0をまたぎ、フルセットの追加価値は一貫しない)。実用上の主結論はF-serveで足りるということ。
5. **割安と判断した領域で確率は正しく較正されたか** — おおむね良好。M4の較正ギャップは大半の領域で
  ±1.5pt以内(model_higher_than_market +0.03pt、edge上位10% −0.10pt、人気帯別も±2.2pt以内)。
  edgeの十分位でも単調性が保たれ、DeepValue/Benterで見つかったような「edgeが大きいほど較正が
  悪化する」optimizer's curseの強い再現は無い(edge最上位十分位: 予測36.53% vs 実測36.63%、
  むしろ実測がわずかに上回る)。唯一 edge上位5%(+0.80pt)と◎馬(v6 1位, +1.46pt)でわずかな
  過信が見られるが、同じ◎馬でM1は+2.94ptの過信でありM4の方が較正は良い。
6. **回収率は基準を上回ったか** — 明確な優位は確認できなかった。prob-first(レース最大確率1点、
  複勝100円均等)ではM4=86.35% [85.08,87.72] > M1=85.28% [83.98,86.54] ≈ M3=85.20% [83.92,86.49]と
  点推定はM4が最も高いが、信頼区間が広く重なり合っており統計的に明確な差ではない。logloss水準の
  改善が回収率にそのまま乗るとは言えない。
7. **ROI 100%を超えたか** — 超えなかった。どの構成(R1のEV閾値選抜・R2のprob-first1点、M1/M3/M4
  いずれの確率源でも)も73-86%の範囲で、控除率(約80%)の壁を破っていない。EV閾値選抜(R1)は
  prob-first(R2)より一貫して悪く([[project_ev_selection_harmful_probfirst]]と整合)、この構造は
  どの確率源を使っても変わらない。
8. **前向きシャドーへ進む価値があるか** — 条件付きで「あるが今すぐではない」。logloss面の改善は
  EXP04のI1選別失敗とは対照的に頑健(全競馬場・全人気帯・複数年で一貫)で、価値のあるモデルの兆候を
  示している。しかし(a) 2026年をロック評価できるだけのデータ基盤が無い(LOCKED_PERIOD_AUDIT.md)、
  (b) 現時点でROIへの転嫁が統計的に確認できていない、という2つの理由から、いきなり
  `wide_residual_shadow`型の前向きshadow(実オッズ取得・300 bet規律)に進むのは時期尚早。次の一手は
  LOCKED_PERIOD_AUDIT.md末尾に記載した2026年研究用データセット構築(週次CSV再パース)を先に行い、
  真のロック評価でGate2を再実行することを推奨する。

## Gate 2 (探索的、2026非ロックのため最終確証としない)

**主判定 M4 vs M3**: 2023 Δ=−0.00132 [−0.00184,−0.00078] / 2024 Δ=−0.00138 [−0.00203,−0.00077] /
2025 Δ=−0.00147 [−0.00205,−0.00088]。競馬場別10/10、人気帯別4/4がM4favor。上位100レース除外後も
Δ=−0.00123で符号維持(少数の極端なレースへの依存ではない)。

**M5 vs M4 (フル特徴の追加価値)**: 2023のみ有意 (−0.00021 [−0.00038,−0.00004])、2024/2025はCIが
0をまたぐ。フル特徴の追加価値は一貫しない → F-serveで実質的に十分という結論を支持。

**M4 vs M6 (Benter型対照)**: 全期間で大差 (Δ≈−0.0044、95%CI大きく0を下回る)。表特徴を持たない
Benter型αβ合成は市場+v6生スコアの単純な線形結合に留まり、この検定の中では最弱のモデル。

## 仕様からの逸脱・簡略化 (事前登録との差分、透明化)

- spec §3のB1/B2/B3診断は §11のM1/M2/M3と数式が同一のため重複fitせず流用した(spec.jsonに明記)。
- spec §8の「OOF stacking」は、v6base.py が既に提供する時点安全なOOF/OOS構成(2015-2023 expanding
  window, 2024-2025本番)をそのまま使い、EXP05独自のfold切り直しは行っていない。calibrated_v6_probability
  のみtrain-onlyで自前isotonic再fitした(較正器自体のリーク回避のため)。
- spec §9の2026年開封条件は「不可」と判定し、Gate2-4を探索的評価として実行した(LOCKED_PERIOD_AUDIT.md)。
- spec §19の前向きシャドーは実装しなかった(§21の理由、次の一手として記録)。
- spec §11のM6(Benter型対照)は win 尤度でα,βをMLE fitし、top3予測はpl_top3(Harville)で導出した
  (top3を直接尤度化する自然な定式化が無いため、v6base.py自身が採る手法と同じ設計)。

## 終了規則の適用

Gate1・Gate2(探索的)はいずれもM4/M5がM1/M3を明確に上回る方向で一貫しており、spec §23の
「M4がM3を改善しなければ終了」には該当しない。一方 §16 の意味でのロック評価は実施していないため、
「確証された」とも言えない。今回は**仮説を終了せず、次の一手(2026データ基盤構築)を明示した上で
一旦区切る**。GBDT化・特徴追加・閾値再探索・人気帯専用モデルには進んでいない(§23遵守)。
