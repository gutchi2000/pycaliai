**正本**: `spec.json`（v1.1）。数値は `out/gate_results.json`、表は `out/results_tables.md`。

## 正式文（spec.mde.fail_statement）

> 現在の特徴、事前固定したモデル容量、2023 development、および本実験の検出力では、

## 1. 何をしたか

- **比較の構成**: R1（DeepSets）と、文脈経路だけを外した双子の R1-noctx を比べた。
  共通の条件は次のとおり。
  - 入力は clean 契約の111列
  - φ・loss（pointwise MSE）・optimizer・batch・seed 5本（対）・ハイパラが同一
  - パラメータ数は R1 342,381 対 R1-noctx 325,267（−5.0%）
- **期間**: 2016-2021 で学習、2022 で early stopping・τ・選択、2023（3,456R / 288 開催日）を
  fixed-model で評価。
- **R0-clean**: v6 レシピの LightGBM。ID・as-of 違反の列を除き、2023 年は不使用。
- **R0-prodref**: v6 の120列。参考値。
- **経過（コミット順）**
  1. `spec.json` 凍結（`14c486a2`）
  2. 契約・学習前 MDE（`6d73014a`）

## 3. 記述的な観察（判定を覆すものではない）

1. **logloss 単独では、事前基準の一部を満たす改善があった。**
   - 5/5 seed で改善し、CI の上限がわずかに 0 を下回り、相対 0.35% で実務閾値 0.2% を超える。
   - ただし Brier・NDCG・◎top3・ECE（Δ +0.00008、CI [−0.0008, +0.0009]）はどれも動いていない。
   - 事前に2指標の同時改善を要求していたので FAIL である。**logloss だけで救済はしない**。
2. **容量では説明できない。**
   - R1-noctx-2x（684,826 パラメータ）− R1-noctx は ΔLL −0.00085（CI は 0 をまたぎ、改善した seed は 2/5）。
   - R1 − R1-noctx-2x は ΔLL −0.00641（CI [−0.0137, +0.0008]、4/5）。
   - 容量を倍にしても同じ改善は出ない（診断用、Gate 外）。
3. **基準にした NN 自体が弱い。**
   - R1-noctx は R0-clean より ΔLL +0.0675・ΔBrier +0.0115 悪く、0/5 seed。
   - 最低確率帯（R0 の p < 0.02）の A/E は R0 0.876 に対し、R1-noctx 0.386・R1 0.405。
     NN は穴馬の確率を大きく過大に予測している。
   - logloss の改善は、この弱い基準の上での小さな sharpening とも読め、
     強い馬ごとの行モデル（R0）に移る保証はない。
4. **Replacement Gate（参考）は明確に FAIL。**
   - R1 − R0-clean は ΔLL +0.0602 [+0.0476, +0.0733]、0/5 seed。
   - NDCG@3 −0.0051、ECE も有意に悪化。
   - 競馬場10場の全てで R1 が悪い。
5. **R0-prodref − R0-clean（参考）**
   - logloss は差なし（−0.00001）。
   - NDCG@3 は +0.0021（CI [+0.0002, +0.0040]、5/5 seed）、◎top3 は +0.46pt（5/5 seed、CI 下限 −0.0002）。
   - 除外した疑義列（`馬主(最新/仮想)` など）が、順位づけ系の指標に小さな寄与を持っている。
     これが as-of 違反による見かけの寄与かどうかは、本実験では分けていない。

## 6. 範囲と限界（結論の外延）

**否定されたこと**
- 「この DeepSets（平均・最大の自分除外プーリング）を、この pointwise 損失とこの容量で
  2016-2021 に学習したとき、2023 年に logloss と Brier の両方で文脈なしの双子を上回る」こと。
  事前基準では検出されなかった。

**否定されていないこと**
- attention による個体間相互作用（R3）
- race-level 損失（R2）
- より強い基準モデルの上での文脈効果
- 2016 年より前のデータを使った学習
- DNF を含む集合

これらは未検証である。ただし進行規則により、本 EXP15 の中では R2 以降へ進まない。

**入力の制約**: 人気系の入力（kako5_avg_ninki ほか）は master_v2 で被覆率 0% のため、
C1 が想定する「人気分布」は入力に含まれていなかった。

## 7. 次の扱い

- 進行規則「Context Gate FAIL → R2 を作らず終了」に従って EXP15 を閉じる。
- §3 の logloss 単独の信号を理由に同じ 2023 年で再検定することはしない。
  in-sample の蜃気楼を避けるため、統制を緩めて再検定することもしない。
- 再開する場合は、別の仮説として新しい事前登録と未使用期間が必要になる。
