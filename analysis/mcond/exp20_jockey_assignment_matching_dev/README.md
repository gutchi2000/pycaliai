# EXP20 — 騎手配置の制約付きマッチング残差

**版**: v0.1-review-draft
**状態**: 仕様レビュー待ち。実装・学習・結果評価は未開始
**主目的**: 同一レースに実際に集まった騎手と馬の組合せに、既知能力・継続騎乗・厩舎関係では説明できず、terminal close市場にも残る情報があるかを検証する。

本実験は「有力騎手だから強い」「乗り替わりだから買う」を再検証しない。EXP01が扱った馬単位の生の選択・陣営通常行動からの逸脱とも異なる。各レースの**観測済み騎手 roster と出走馬 roster の一対一対応**を、斤量実現可能性を持つ制約付き二部マッチングとして扱う。

観測できない依頼、辞退、エージェント契約、騎手の移動意思は復元しない。したがって結論は「騎手がどの馬を選んだか」ではなく、**観測済み roster 内の条件付き配置残差**に限定する。

進行順:

1. Fableによる仕様レビュー
2. Stage 0: データ契約、候補集合、時点安全性、EXP01等価性、被覆、検出力
3. Stage 0の全Gateを通過した場合だけ、別commitで仕様を凍結
4. Stage 1: terminal close市場に対する残差Gate
