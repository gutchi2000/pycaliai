## 2. E0-A 代数：Hodge 射影は pair 固有情報を捨てる操作である

過去対戦 log-odds を全馬にわたる反対称行列 L（L_hc = ell_hc）とし、Hodge 分解 L = grad(θ) + R（R は curl + harmonic）と書く。

- `d_ij^(c) = L_ic − L_jc = (θ_i − θ_j) + (R_ic − R_jc)`
- `d_ij = (θ_i − θ_j) + Σ_c ω_ijc (R_ic − R_jc) / Σ_c ω_ijc`

現在レースの Hodge 射影 `min_s Σ w_ij (s_i − s_j − d_ij)²` は d の **gradient 成分を s に、curl 成分を残差に**分ける最小二乗射影である。したがって

1. 履歴が推移的（R ≡ 0、BT が真）なら `s = θ`（centering を除く）。合成テスト `algebraic_reduction_when_transitive`: 最大誤差 2.3e-13。
2. d が純 curl（3 サイクル）なら `s ≡ 0`、残差 = d。合成テスト `pair_specific_info_survives_only_in_residual`: s の最大 |値| = 0.0。
3. 一般に s_i = θ_i + （共通対戦馬集合が pair 依存であることから生じる馬ごとの残差平均）。これは **θ の別推定量**であり、モデル族としては「馬ごと 1 スカラー → softmax」。EXP02 と同じ族。

結論: SPEC §2.3 が新規性の核とした「pair 行列として保持した後、Hodge 射影で整合する馬スコアへ変換する」は、**保持した pair 固有成分を射影の瞬間に捨てる**設計である。G2（race-level）は「EXP02 と異なる推定量で作ったスカラー rating」の比較にしかならず、EXP02 の終了記録「レーティング系は名前・条件区分・パラメータを変えて再探索しない」に該当する。

pair 固有成分を race-level 確率に運ぶ唯一の方法は PL の分配関数に pair 結合項を入れることで、それは統計力学 M1（脚質ベース）として既に検定済み。EXP17 の identity ベース版を作ることは「高度化して救済」に当たり、本 Stage 0 では提案しない。

## 3. E0-B 実測：2022 label-free snapshot

### 3.1 設定

- 母集団: 2022 正式 race set 3,206R（平地・勝馬一意・starter ≥5・DNF なし; `GRAPH_DATA_AUDIT.md`）。
- 対象: 直接対戦なし・共通対戦馬あり・EXP02 μ あり pair **138,717**、(i,j,c) 三つ組 **965,299**、(h,c) 辺 **1,197,881**、対戦 **1,439,200**。
- 使用した label: 対象日より前の履歴対戦（特徴そのもの）のみ。2022 の対象レース着順は使っていない。
- EXP02 能力 μ: `data/_research/mcond/exp02_features.parquet` の pre-race 値（対象レース行 = 対象日 as-of、対戦レース行 = 対戦時点 as-of）。
- pair スケール b: `P(h beats c) = σ(b(μ_h − μ_c))` を **2018 年以前の対戦 30 万件**で 1 パラメータ MLE。b = 0.1033、pair logloss 0.6434（coin flip 0.6931）。development 2019〜2023 の結果は使っていない。

### 3.2 事前固定した判定量

- **超過分散比** ρ = Var_real(d_ij − b·Δμ_ij) / E_null[Var(d_ij − b·Δμ_ij)]。null = 各過去対戦の勝敗を σ(b(μ_h(m) − μ_c(m))) から再抽選（200 draw、seed 20260925）、count 構造 (n_hc, ω) は実データ固定。
- **FAIL 条件（実行前に固定）**: ρ の CI95（meeting-day block bootstrap 1,000）上限 < 1.10。
- 補助: 共通対戦馬 c1, c2 を介した残差の一致相関 corr(r_c1, r_c2)、real vs null 97.5%ile。

### 3.3 結果

| 量 | 値 |
|---|---|
| Var(d_ij) real | 0.4068 |
| Var(b·Δμ_ij) | 0.6449 |
| d_ij の b·Δμ_ij への回帰: slope / R² / corr | 0.304 / 0.146 / 0.382 |
| Var(d_ij − b·Δμ_ij) real | **0.6600** |
| 同 null 平均（200 draw; draw 間 SD 0.0026） | **0.7858** |
| **ρ** | **0.840**、CI95 **[0.825, 0.856]** |
| FAIL 条件（上限 < 1.10） | **満たす → FAIL** |
| real d の再構成誤差（null 経路の検算） | 0.0 |
| 一致相関 corr(r_c1, r_c2)（≥2 共通対戦馬の 107,594 pair） | real 0.391 / null 平均 0.328 / null 97.5%ile 0.335 |
| 射影後 s と EXP02 μ のレース内回帰 R² / corr（37,331 馬行） | 0.236 / 0.486 |

### 3.4 読み方

1. **ρ < 1**: 実データの pair 状態は、EXP02 の単一能力から各対戦を独立に抽選した世界よりも**ばらつきが小さい**。pair 固有の追加状態が存在するなら ρ > 1 になるはずで、その兆候はない。ρ が 1 を下回るのは、実対戦が BT(b) 抽選より予測可能（μ の情報を BT ロジスティックが取り切っていない、または対戦時点 μ と対象日 μ の差）ためで、いずれも「pair 固有状態」ではなく「スカラー能力側の説明力」に属する。
2. **一致相関の超過（0.391 vs 0.335）**は小さく、null が μ を真値として扱っている（μ の推定誤差 e_i は c1 経路・c2 経路の残差に同符号で入り real の相関を押し上げる）ため、pair 固有状態の証拠にはならない。事前登録どおり補助指標であり、主判定 ρ を覆さない。
3. **s と μ の差は、事前固定した超過分散基準では null 抽選ノイズを上回らず、追加の pair 固有状態として Stage 1 へ進める根拠にならなかった**（s と μ のレース内 R² は 0.24）。§3.5 の対戦回数構造が示すとおり s は単発対戦の符号の集積で、E0-B の主判定はこの低い R² を新規性と読まないために ρ を置いた。低い R² を「新情報」とも「ノイズと確定した」とも読まない。
4. d_ij の分散 0.41 は、EXP02 能力からの再抽選 null の残差分散 0.79 を上回らず、b·Δμ の分散 0.64 より小さい（事前固定基準では pair 固有の追加分散は観測されなかった）。

### 3.5 対戦回数の構造（被覆監査と一致）

| 量 | 2022 等価性監査 | 2019〜2023 被覆監査 |
|---|---|---|
| 使用した (h,c) 辺のうち対戦 1 回 | **84.7%** | 78.8% |
| 同 ≤2 回 | 96.6% | 93.9% |
| 平均対戦回数 / 辺 | 1.20 | 1.31 |

対戦 1 回の辺の ell は `±logit((1+α)/(1+2α)) = ±0.405`（α=1）の 2 値、`d_ij^(c)` は事実上 {−0.81, 0, +0.81} の 3 値。**pair 固有状態を推定するための繰り返し観測がデータに存在しない。** これは仮説の数理ではなくデータ構造の限界で、パラメータ（α、減衰、条件重み）をどう凍結しても変わらない。

## 5. G1（機構 Gate）だけを残す選択肢について

G1 は d_ij を直接 pair 確率に使うので E0-A の還元は受けない。しかし

- §3 の実測で pair 固有成分は null と区別できず、期待される G1 効果は「EXP02 の pair 残差を共通対戦馬 1〜2 頭の単発結果で平均したもの」で、事前固定基準では null を上回る pair 固有状態は観測されなかった。
- G1 が通っても G2 へ運ぶ経路が構造的に存在しない（§2）。G2 に運ぶには統計力学 M1 型の結合項が必要で、それは「高度化して救済」に当たる。
- SPEC §1 は「機構が通っても市場価値を意味しない。terminal close 市場を通らなければ候補馬券や配分へ進まない」としており、G2 に到達できない G1 単独の実験は本プロジェクトの目的（実利益への接続）に対して価値を持たない。

したがって G1 単独での続行は提案しない。

## 6. EXP12 との関係（placebo の比較は `POWER_AUDIT.md` §5）

EXP12 O3 は相手 identity の**馬行への集約**を検定して placebo に負けた。EXP17 は集約を遅らせ pair 行列で保持するが、§2 の射影で結局同じ「馬ごとスカラー」に戻る。EXP12 が壊した identity 情報を EXP17 が救えるのは pair-level（G1）だけで、その pair-level 状態は §3 で観測不能規模と判明した。EXP17 は EXP12 の再実験ではないが、同じ壁（identity 固有情報の不在）に別経路で到達した。

## 8. 結論の射程（2026-09-25 修正、文言のみ）

Stage 0 停止判断そのもの（E0 FAIL・被覆床 FAIL）は変更しない。結論の射程を次のとおり限定する。

| 旧表現（使わない） | 正式表現 |
|---|---|
| 「identity 系は 1-hop・2-hop とも閉じた」 | **EXP12 で検証した 1-hop 表現と、EXP17 で検証した時点安全な共通対戦 2-hop 表現＋Hodge スカラー射影を閉じた** |
| 「s と μ の低い R² は新情報ではなくノイズ」 | **s と μ の差は、事前固定した超過分散基準では null 抽選ノイズを上回らず、追加の pair 固有状態として Stage 1 へ進める根拠にならなかった** |

- curl 成分または identity pair coupling を直接 race 確率へ運ぶ方式は**未実装・未検証**であり、失敗したとは主張しない（EXP17 の凍結ルールにより EXP17 内での救済実装はしない）。ただし使用した (h,c) 辺の **84.7%（2022 等価性監査。2019〜2023 被覆監査では 78.8%）が対戦 1 回**であり、pair 固有状態を推定する繰り返し観測が乏しいため、**現データで新実験を開始する根拠は不足している**。
- PageRank・3-hop 以上・embedding・GNN・地方海外履歴・他券種と同様に、上記方式も「失敗」ではなく「未検証」に分類する。
- 学習・成績評価・2024/2025 開封・ROI・救済実験は行っていない。
