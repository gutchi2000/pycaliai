# v6カテゴリ修正の予測変化・成績指標 (spec §1-2)

`category_fix_impact_eval.py`。**制約**: `data/weekly/`は2026年分の週次CSVしか保持していない
ため、2023-2025を含む完全な過去replayではない。2026年の完了済み12週(20260104〜20260815、
代表サンプル、375レース/5,852頭)によるcontrolled replay。市場データ等は使わず、
v6モデルの生スコア・PL順位のみを比較する。

## 予測変化

| 指標 | 値 |
|---|---|
| 対象頭数 / レース数 | 5,852頭 / 375レース |
| カテゴリ変更が起きた行 | 5,852 (100%、天気/馬場状態の"(暫定)"接尾辞が広範囲に影響) |
| ai_score変化量(絶対値平均、変更行) | 0.0302 |
| ◎(トップ1)変更レース数 | 22/375 (5.9%) |
| top3構成変更レース数 | 33/375 (8.8%) |
| 芝(内・外)の影響を受けた行 | 0 (下記「既知の限界」参照) |
| 暫定表記の影響を受けた行 | 5,002/5,852 (85.5%) |

ダート/芝別のスコア変化件数はほぼ半々(ダート2,983行、芝2,807行) — ダートは芝・ダ修正
(52.4%→0.9%)の直接効果、芝側は主に天気/馬場状態の暫定表記修正の効果。

## 成績指標 (◎=スコア最大馬)

| 指標 | 旧処理 | 新処理 | 差 |
|---|---|---|---|
| ◎勝率 | 26.67% | 26.40% | -0.27pt |
| ◎top3率 | 56.27% | 55.47% | -0.80pt |
| NDCG@3 | 0.5653 | 0.5651 | -0.0002 |

## 解釈

n=375レースというサンプルサイズでは、◎変更が起きたのは22レース(5.9%)のみであり、
成績指標の差(-0.27pt/-0.80pt)は統計的にほぼゼロと解釈すべき水準(ノイズ範囲内)。
改善も悪化も統計的に検出できていない、という意味で「中立」。

spec本文の採用条件そのものがこの結果を許容している: **「修正の採用条件は、カテゴリ値が
学習時語彙と意味的に一致することであり、短期成績の良し悪しだけでrevertしない」**。
本修正は`CATEGORY_PARITY.md`のとおり学習時語彙との意味的一致を直接検証済み
(`tests/test_category_normalize.py::test_normalized_values_are_in_v6_encoder_vocabulary`)
であり、この基準を満たしている。短期成績が中立という結果は採用を妨げない。

## 既知の限界

- このスクリプトは`predict_weekly.parse_csv`+`apply_encoders`の簡易版で、
  `export_weekly_marks.py`本番フロー全体(fill_history_features・着度数CSV結合等)は
  再現していない。特に`芝(内・外)`列は本番フローの別ステップ(未特定の結合処理)で
  populate されるため、この評価では touched=0 (測定対象外) になっている
  (`CATEGORY_PARITY.md`のとおり本番フローでは51件/287頭の実例を確認済み、
  過小評価ではあるが列自体の正規化ルールは`tests/test_category_normalize.py`で
  独立に検証済み)。
- 完全な過去replay(2023-2025)ではなく2026年のcontrolled replay。
