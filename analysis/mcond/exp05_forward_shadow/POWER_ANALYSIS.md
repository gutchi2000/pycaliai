# EXP05-F 必要サンプル数 (spec §7、単位を明確化)

`POWER_ANALYSIS.json`。以前の版(README.md/spec.json初版)は「6,600レース≈5-6ヶ月」と書いていたが、
5-6ヶ月は算出根拠のない誤記だった。正しく計算し直す。

## 観測単位

**主指標(spec §17)はレース単位で集約したtop3 log loss差**なので、検出力計算の独立単位は
**レース**(horse_rowでも、bet_candidateでも、ticketでもない)。

## 計算根拠

EXP05 (`exp05_market_residual_dev`) の2023-2025確認/OOS期間、M4 vs M3のΔlogloss (レース単位で
馬を平均した後の値) を使用:

| 項目 | 値 |
|---|---|
| レース単位SD (σ) | 0.017744 |
| 2023-2025プール平均効果 | -0.001498 |
| 年度別効果 (2023/2024/2025) | -0.001434 / -0.001449 / -0.001610 |
| 年度別最小絶対値 | 0.001434 |
| 効果量 (spec§7規則: 観測の50%とこの小さい方) | min(0.000749, 0.001434) = **0.000749** |
| 両側有意水準 | 1% (z=2.576) |
| 検出力 | 80% (z=0.842) |

```
n_races = (z_alpha/2 + z_power)^2 * sigma^2 / effect^2
        = (2.576 + 0.842)^2 * 0.017744^2 / 0.000749^2
        ≈ 6,557 レース
```

## 単位換算 (2023-2025開発期間の実測ペースから)

| 単位 | 値 |
|---|---|
| **必要レース数** | **6,557 → 切り上げ 6,600** |
| 開発期間の平均出走頭数/レース | 13.65 |
| 参考: 必要馬行数(horse_rows)換算 | 約89,537行 (主指標の単位ではない、参考値) |
| 開発期間のレース開催日(複数会場合算)数 | 322日 / 3年 |
| 開発期間の「レースが実施された暦週」数 | 156週 / 3年 (ほぼ毎週末開催) |
| 暦週あたり平均レース数 (開催週のみ) | 66.4レース |
| **必要暦週数 (開催週ベース)** | **約99週** |
| **必要暦年数の目安** | **約1.9年** |

## 旧版からの訂正

以前のREADME.md/spec.jsonに書いた「6,600レース≈5-6ヶ月」は誤り。1開催週あたりのレース数を
根拠なく250-300と仮定していたため。正しくは1開催週(土日合算、複数会場)あたり平均66.4レースで、
**必要観測期間は暦週ベースで約99週≈約1.9年**。旧記載はREADME.md/spec.jsonとも本セッションで
修正した。

## 最低条件 (spec §7、いずれか厳しい方を採用)

```
12開催週以上
500レース以上
計算された必要レース数(6,600)以上
```

→ **6,600レースが支配的**。前向き観測をこれだけ貯めるまで主評価(Gate1)を実行しない。
途中経過でのROI判断は禁止 (spec §16)。
