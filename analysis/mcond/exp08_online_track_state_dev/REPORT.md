# EXP08 — 当日馬場状態オンライン推定AI 最終報告

**作成日**: 2026-09-21　**状態**: Stage3本実行完了。**Gate2A FAIL・Gate2B FAIL。
EXP08を終了する**(§0凍結の終了条件に該当、スコープ変更による再救済は行わない)。

## 0. 結論(先出し)

時計・上がり・ペースのいずれの同日オンライン状態も、v6+市場の後に実務的に
意味のある追加情報を持たない。効果量は要求閾値(絶対改善0.0005)の**4〜5桁小さい**
(実測 約4×10⁻⁸)。permutation placebo(1,000回)は不合格、EWMA対照との有意差もない。
2026-09-20夜の事前指示通り、この結果を見た後にQ/R探索範囲・状態次元・clip範囲・
集約方法・利用可能時刻・interaction・EWMA減衰率・分割方法のいずれも変更していない。

## 1. 対象・条件

- 対象状態: 時計(speed_signal)・上がり(agari_signal)・ペース(pace_signal)の
  3独立Kalman状態(開催日×競馬場×芝ダートunit)
- 学習: 2023年development(n=44,169行、beta凍結)
- 評価: 2024年・2025年、genuinely OOS(再fitなし)
- 主比較: M1 vs M0(同日情報自体の価値)、M3 vs M1(状態空間化固有の価値)
- 利用可能時刻: primary=発走+20分、sensitivity=発走+30分(完全に別系列)
- 全コード・spec.json・テストは2024-2025の実評価を実行する前にコミット済み
  (commit `256b9cbb`)

## 2. Gate2A: M1 vs M0(同日情報自体の価値)

| 条件 | 判定 | 実測 |
|---|---|---|
| 2024・2025両方で改善方向 | ✅ PASS | 2024: -3.41×10⁻⁸、2025: -4.60×10⁻⁸(primary、両方とも負=改善) |
| meeting-day bootstrap 97.5%CI上限<0 | ✅ PASS | 全期間CI=[-6.26×10⁻⁸, -1.76×10⁻⁸](551 meeting-days) |
| logloss絶対改善>=0.0005 または相対改善>=0.1% | ❌ **FAIL** | 絶対改善=4.00×10⁻⁸(要求の**1/12,500**)、相対改善=0.0000098%(要求の**1/10,000**) |
| 競馬場1場・少数開催日への集中でない | 未評価(効果量が既に決定的にFAILのため実施せず) | — |
| +20分と+30分で改善方向一致 | ✅ PASS | primary=-4.00×10⁻⁸、sensitivity=-3.61×10⁻⁸(同符号) |
| permutation placebo通過(1,000回、97.5%) | ❌ **FAIL** | 実測Δ=-4.00×10⁻⁸ はplacebo分布[2.5%点-5.86×10⁻⁸, 97.5%点-2.97×10⁻⁸]の**内側**(通常のノイズ範囲内) |
| EWMAより有意に良い | ❌ **FAIL** | M1 logloss=0.410440、EWMA logloss=0.410440(小数第6位まで完全一致) |

**Gate2A: FAIL**(7条件中3条件未達、うち効果量・placebo・EWMA比較という
最も本質的な3条件で不合格)。

統計的有意性(CI・方向一致)は技術的に満たすが、これは**meeting-day単位n=551の
大標本ゆえに極小の効果量でも統計的検出力が出るという既知の落とし穴**であり、
事前固定した効果量閾値(0.0005)こそが実務的な無意味さを正しく検出している。

## 4. 事前指示(仕様書§14)の判定規則に照らして

> M1-M0だけ通りM3-M1が落ちた場合は「同日情報は有効だが状態空間モデル固有の
> 価値なし」と判定する

今回はM1-M0自体が(統計的有意性以外の)実務的効果量・placebo・EWMA比較の
3条件で不合格のため、この「部分合格」パターンには該当しない。**同日情報自体に
実務的価値がない**、より根本的な結論となる。

## 6. 仕様書§18相当の結論

1. **判断時点までに何レースの結果を利用できたか** — unit(開催日×競馬場×
   芝ダート)ごとに変動するが、Q/R選択時点で2023年development全体でn=3,206
   レース分の観測イベントを処理。中央値レベルの詳細breakdownは実施していない
   (効果が既にゼロに等しいため優先度低)。
2. **内外・脚質・時計の当日状態を推定できたか** — 時計・上がり・ペースの状態は
   Kalman機構としては正しく構築できた(日次リセット・欠損処理・時系列リーク
   境界を全てテストで確認済み)。内外・脚質はnegative control専用のまま
   (Stage0で既に却下済み)。
3. **単純な当日集計に情報があったか** — なかった(RAW/M1がM0と同一logloss)。
4. **状態空間モデル固有の価値があったか** — なかった(M3がEWMA・M1と同一logloss、
   Gate2B全条件不合格)。
5. **v6＋市場の後にも情報が残ったか** — 残らなかった。v6+市場は既にレース単位
   でΣp≈3.0(top3の理論値)へ極めて精密に較正されており、レース内一定値となる
   状態特徴量(RAW/Kalman平均)がそこに追加で説明できる余地がほぼ存在しない
   (2023 in-sampleサニティチェックの時点で既に示唆されていた)。
6. **2024・2025で再現したか** — 再現以前に、両年とも効果量自体が閾値の桁違いに
   小さい。M3-M1に至っては方向も不一致。
7. **10競馬場で一貫したか** — 未評価(効果量が既に決定的にFAILのため実施せず、
   多重比較によるfishingを避けた)。
8. **1着と3着内のどちらに効いたか** — 未評価(主判定のtop3で既に決定的にFAILの
   ため、副次のwin評価[Gate2C]は実施しなかった)。
9. **利益へ変換できたか** — 未評価(Gate2A/2B不通過のためGate4経済評価は実施せず、
   中止規律に従った)。
10. **前向きshadowへ進めるか** — 進めない。
11. **この仮説を終了するか** — **終了する**。時計・上がり・ペースの当日
    オンライン状態は、同一のv6+市場baselineに対して実務的に意味のある追加
    情報を持たないことが、2023development でfitし2024-2025でgenuinely OOS
    評価した結果、effect size・permutation placebo・EWMA比較の3系統の独立した
    基準全てで一致して示された。内外・脚質(Stage0で却下済み)と合わせ、
    EXP08が当初想定した4次元の当日オンライン状態仮説は**すべて閉じた**。

## 7. なぜこの結果になったと考えられるか(考察、Gate合否には影響しない)

- v6+市場のbaseline較正が既に極めて精密(レース単位Σp≈3.0、std=0.049)であり、
  レース内一定値の状態特徴量が説明できる「calibration上のずれ」の余地が構造的に
  小さい。
- horse_aptitude(closing_power)は既にv6の訓練特徴量に含まれるため、
  interaction項(M3)がaptitude×state経由で捉えようとした情報もv6が概ね
  吸収済みの可能性が高い。
- この結果は[[project_v6_pastform_dominance]]・[[project_marks_grade_blind_pastform]]
  等で繰り返し確認されている「v6+市場の後に残る新規情報はほぼ存在しない」という
  本プロジェクトの一貫したパターンと整合する。
