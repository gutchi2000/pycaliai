# EXP10 — 大敗・中止・能力未発揮リスク

## 目的

通常の着順精度向上ではなく、**v6が高く評価した馬が大きく崩れる下方リスク**を、
既存の勝率・entropy・市場人気の後にも検知できるかの検証。

**主仮説**: v6確率、raw score、entropy、市場確率、人気、頭数、出走回数、
休養日数を統制した後にも、専用の下方リスクモデルが大敗を識別できるか。

## 絶対条件

EXP01-09・v6・compute_bets.pyは変更しない。新規作業は
`analysis/mcond/exp10_downside_risk_dev/`へ限定する。
「負けた馬=陽性」という設計は禁止（v6の逆モデルになるため）。

## Stage 0 の要点

- **先行研究**: `diag_upset_decomposition.py`/`diag_flop_detector.py`が
  「AI◎が複勝圏外に飛ぶか」を既に検定済み（AUC天井0.65、市場priced）。
  他5候補（DNF・相対下振れ連続値・絶対着順・タイム残差・1番人気軸）は
  未踏査。
- **結果コード**: 生ソース`add_20130105-*.csv`の`着順`列に`止`(中止)/
  `外`(除外)/`消`(取消)が識別可能な形で存在(2013-2025合計 止2,946/外1,212/
  消1,007件)。ただし`master_v2`は`convert_finish()`+`dropna()`でこれらを
  完全除去しており、DNF型ターゲットは生ソースからの再構築が必要。失格の
  独立コードは未発見。
- **time-safety**: 着差・タイム残差・上がり3F・通過順位・馬体重変化の
  「今走」版はmaster_v2に存在せず(前走版のみ)。ラベル構築専用として
  生ソースから取得する必要があり、これは設計として正しい(予測特徴には
  混入させない)。
- **疾病・故障理由**: 構造化データなし。取消・除外の「なぜ」は取得不可能。
- **EXP02重複**: 出走回数・休養日数を統制変数に含める判断はEXP02の実測
  （動的能力効果の3/4がこの2変数由来）と整合。

詳細は`PRIOR_ART_AUDIT.md`/`DATA_AUDIT.md`参照。
