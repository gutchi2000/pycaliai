# 情報量と資産成長率の関係 — `-ln(1-takeout)` を普遍的な停止閾値に使わない理由

**作成日**: 2026-09-24　**位置づけ**: EXP16A Stage 0 の付属文書。
数値確認は `verify_growth.py`（純粋な合成シミュレーション、実データ不使用、ROI 評価ではない）。
結果は `out/derivation_checks.json`。

---

## 1. 恒等式そのもの

1レースの結果を $X \in \{1..N\}$、真の確率を $p$、市場の（控除前の）シェアを $\pi$ とする。
pari-mutuel の単勝配当（元返し込みの decimal odds）は

$$o_i = \frac{1-t}{\pi_i}, \qquad t = \text{控除率}$$

資金を毎回**全額**投じ、配分 $b$（$\sum_i b_i = 1$, 現金ポジションなし）で賭けるとき、
対数資産の1レースあたり期待増分（doubling rate）は

$$W(b) = \mathbb{E}_p\big[\log (b_X o_X)\big] = \sum_i p_i \log\!\big(b_i o_i\big)$$

$b$ で最大化すると $b^\* = p$（比例賭け）であり、

$$W^\* = \sum_i p_i \log\frac{p_i (1-t)}{\pi_i} = D_{\mathrm{KL}}(p \Vert \pi) + \log(1-t)$$

したがって $W^\* > 0 \iff D_{\mathrm{KL}}(p\Vert\pi) > -\log(1-t)$。
$t=0.20$ なら閾値は **0.2231 nats**。これが「情報が控除を超えないと増えない」という主張の出どころである。

**合成確認 C1**: 2,000 レースで $W^\*$ と $D_{\mathrm{KL}}(p\Vert\pi) + \log(1-t)$ の差は最大 **2.2e-16**。
恒等式としては正しい（`C1_full_investment_identity`）。

## 2. 我々が測れるのは $D_{\mathrm{KL}}(p\Vert\pi)$ ではない

実験で測るのは、市場に対する **race-level categorical logloss の改善**

$$\Delta = \mathbb{E}\big[-\log \pi_X\big] - \mathbb{E}\big[-\log q_X\big]$$

であり、モデル $q$ と真値 $p$ の関係は

$$\Delta = D_{\mathrm{KL}}(p\Vert\pi) - D_{\mathrm{KL}}(p\Vert q) \;\le\; D_{\mathrm{KL}}(p\Vert\pi)$$

- $\Delta$ は $D_{\mathrm{KL}}(p\Vert\pi)$ の**下界**であって等号は $q=p$ のときだけ。
- よって「$\Delta$ が 0.2231 に届かないから成長できない」とは**言えない**（下界と閾値の比較になっていない）。
- 逆に「$\Delta>0$ だから儲かる」とも言えない。$\Delta>0$ は**情報の存在**しか意味しない。

**EXP16A の Gate A/B が測るのは $\Delta$ であり、成長率ではない。** これは実験の設計上の限界であって、
控除率の壁を否定するものでも肯定するものでもない。

## 3. 閾値が成り立つために必要な仮定

| # | 仮定 | 破れると何が起きるか |
|---|---|---|
| A1 | **完備市場**: 全出走馬に同じプールで賭けられる | 単勝プールでは概ね成立。複数プール横断や部分的な組合せ券では成立しない |
| A2 | **全資金投入・現金ポジションなし** | 破れる（現金を持てる）。§4 参照。**この仮定が本件で最も重要** |
| A3 | **価格受容**: 自分の賭けがオッズを動かさない | pari-mutuel では自分の金がプールに入るので必ず破れる。§5 |
| A4 | **価格と払戻の対応**: 見たオッズでそのまま払い戻される | 破れる。判断時点のオッズと確定オッズは別物。§6 |
| A5 | **連続分割可能・端数なし** | 破れる。100 円単位、オッズ 0.1 刻み、配当は 10 円単位。§7 |
| A6 | **レースが独立で同分布、バンクロール連続** | 実際は開催日単位のクラスタ、資金制約、同日複数レースの同時性がある |

## 4. A2 を外すと閾値は停止規則にならない（最重要）

現金を許す Kelly は

$$\max_{b_0 + \sum_i b_i = 1,\; b \ge 0} \; \sum_i p_i \log\!\big(b_0 + b_i o_i\big)$$

であり、**最適値は常に 0 以上**（全額現金 $b_0=1$ が可能なので $W \ge 0$）。
このとき「賭ける価値があるか」の条件は平均 KL ではなく

$$\exists i:\; p_i o_i > 1 \iff \max_i \frac{p_i}{\pi_i} > \frac{1}{1-t}$$

という**レースごとの参加条件**になる。

**合成確認 C2**（市場を正確側に寄せた設定）:
- 平均 $D_{\mathrm{KL}}(p\Vert\pi) = 0.0270$ nats（閾値 0.2231 を**大きく下回る**）
- 全額投入・比例賭けの平均成長率 = **−0.1961**（負）
- 現金を許す最適の平均成長率 = **+0.0037**（正）
- 成長率が正になるレースの割合 = **94.7%**、$\max_i p_i/\pi_i > 1/(1-t)$ の割合も **94.7%**（一致）

つまり **「平均 KL < 0.2231 だから打ち切り」は誤り**。正しくは「その条件下で*全額投入*するなら負ける」であり、
選択的に賭けられるなら別の条件が支配する。

**ただしこの C2 は $p$ を真値として与えた理想条件**である。実際には $p$ を知らず $q$ しか持たないため、
$\max_i q_i/\pi_i > 1/(1-t)$ で選抜しても、$q$ の誤差の分だけ選抜が逆選択（overbet）になりうる。
この点が本プロジェクトで繰り返し実証されてきた「EV 選抜は有害」の数理的な居場所である。

## 5. A3（自己希釈）

自分の賭け金がプール比 $f$ を占めると、実効シェアは $\pi_i \to \pi_i + f b_i$ になり配当が下がる。

**合成確認 C3**（14頭、比例賭け）: 成長率は
$f=0$: −0.1275 → $f=0.001$: −0.1287 → $f=0.005$: −0.1334 → $f=0.02$: −0.1506 → $f=0.05$: −0.1843。
穴馬ほどプールが薄いので影響が大きい。

## 6. A4（判断時点と確定の差）

**「判断時点と確定が違う」こと自体は害ではない。**
- **合成確認 C4**（対称で情報を持たない drift）: drift の sd を 0 → 0.20 に上げても平均成長率は
  −0.0766 / −0.0775 / −0.0741 / −0.0610 と**系統的に下がらない**（Jensen の不等式でむしろ僅かに上がる）。
- **合成確認 C4b**（市場が締切までに真値へ寄る = 補正 drift）: 補正の強さ $\lambda$ を上げると
  成長率は −0.0798 → −0.1388 → −0.1834 → −0.2136 → **−0.2231**（= $\log(1-t)$）へ単調に落ち、
  $\max_i p_i/\pi^{\text{final}}_i$ は 3.32 → 1.00 へ縮む。

害になるのは **自分が張る側へ不利に動く drift**（市場が締切までに正しくなる、または自分の資金で動く）。
EXP16A が Q0（確定オッズ）を oracle 診断と呼び、Q3（判断時点）を実運用可能性の測定と呼んで分けるのは、
まさにこの $\lambda$ を経験的に測るためである。

## 7. A5（粒度・端数）

**合成確認 C5**（1万円を配分、オッズは 0.1 刻みに切り捨て）:
1円単位 −0.0902 / 100円単位 −0.0887 / 500円単位 −0.1051。
この合成条件では主たる劣化要因は**オッズの丸め**であって賭け金単位ではない。実運用では
配当 10 円未満切り捨て（breakage）と最低 100 円が加わる。

## 8. 本実験での取り扱い（結論）

1. `-ln(1-t) = 0.2231 nats` を **hard Gate に使わない**。A1-A6 のうち A2・A3・A4 が本プロジェクトの実運用条件で
   明確に破れているため。
2. Gate A/B は **$\Delta$（市場に対する logloss 改善）が 0 を超えるか**だけを判定する。
   これは情報の存在確認であり、成長率・利益・実運用可能性のいずれも意味しない。
3. 参考値として $\Delta$ と 0.2231 の比を報告してよいが、**「壁の何%」といった表現は使わない**
   （$\Delta$ は $D_{\mathrm{KL}}(p\Vert\pi)$ の下界にすぎないため）。
4. 経済的な確認（Gate A/B 通過時のみ）は、平均 KL ではなく
   **レースごとの $\max_i q_i/\pi_i$ 分布・shrinkage 後の正 edge 被覆・期待的中と実際の的中**で行う。
5. 本文書の主張は合成例で確認した範囲に限る。実データでの $\lambda$（補正 drift の強さ）は未測定であり、
   Stage 1 の Q0 対 Q3 の差として初めて観測される。
