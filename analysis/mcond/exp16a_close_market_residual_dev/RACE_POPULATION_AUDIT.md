# EXP16A — race 母集団の監査（正式 race set の確定）

**作成日**: 2026-09-24　**改訂**: 2026-09-24（改訂2: 障害除外、starter/finisher/scratch/DNF を別構築）
**測定**: `race_population.py` → `out/race_population.json`
**範囲**: 2016-01-01〜2023-12-31。2024/2025 は読み込み時に破棄。学習なし。**結果を使う指標は 2022 以前のみ**。

---

## 1. 馬の 4 集合（別々に構築する）

| 集合 | 定義 | 備考 |
|---|---|---|
| **starter** | 確定（区分4）の単勝オッズ **> 1.0** を持つ馬番 | 締切プールに居た馬。市場分母の正式定義 |
| **finisher** | master（着順が数値）に完走順位を持つ馬番 | Q1 がスコアできる馬 |
| **scratch** | pre スナップショットに居て確定に居ない馬番 | 締切前取消 |
| **DNF** | starter − finisher | 出走したが完走順位が無い（止・失格等） |
| finisher_without_market | finisher − starter | 着順があるのに確定オッズが無い異常 |

> **改訂2 の修正点**: 旧実装は starter を master 由来の finisher から作っていたため、
> starter 正規化と finisher 再正規化の差が**構造的に 0** になっていた（Fable 指摘）。
> 本改訂で 4 集合を別々に構築し、差が実際に出ることを確認した（§5）。

## 2. 障害の除外

- 定義: **`トラックコード(JV) ∈ 51..59`**。production の P0 hard gate（`race_eligibility.py:48-49`）と同一定義。
- 本データでの実測出現値: **52 / 54 / 55 / 56 / 57**（`トラックコード(JV)` の欠損は 2016-2023 で 0 件）。
- 2016-2023 の障害 **1,011 レース**を正式 race set から除外する。
- 障害レースは DNF が集中する（障害での DNF 馬 608 頭 / 平地 1,161 頭）。

## 5. DNF の扱いと感度分析

- **DNF を取消として扱わない**。DNF 馬は締切時点でプールに居り、市場確率の分母に含まれていた。
- **Q1（R0-clean）は DNF 馬をスコアできない**（master は dropna 後で DNF 行を持たない）。
  したがって正式 Gate の主 race set は **DNF が存在しない平地レース**に限定する。
- この除外は「完走したか」という**結果による条件付け**である。よって
  **「DNF-inclusive な Q1 を構築できるまでの暫定母集団」**と明記する。DNF ありレースの Q1/Q2/Q3 を正式判定へ混ぜない。

Q0（市場のみ）で 2 つの正規化を比較した実測（2016-2022）:

| 母集団 | レース数 | starter 全頭正規化 | finisher のみ再正規化 | 差 | 平均 DNF 頭数 |
|---|---|---|---|---|---|
| 正式 set | 22,310 | 1.952808 | 1.952808 | **0.000000** | 0.00 |
| 平地 DNF ありレース | 937 | 2.045111 | 1.983745 | **+0.061366** | 1.081 |
| 障害レース | 884（883 採点） | 1.891900 | 1.846601 | **+0.045299** | 0.594 |

- 正式 set の差が 0 なのは starter == finisher だからで、これは**定義の帰結であり検証済みの整合性**である（旧版のようにバグで 0 になっているのではない）。
- DNF ありレースでは starter 正規化の logloss が **+0.0614 nats 高い**。完走しなかった馬に確率を割り当てた分だけ勝馬の確率が薄まるため。
- EXP16A は**正規化を一度だけ**に固定する（mcond 経路の `market.py` → `v6base.py` 二重正規化はしない）。
