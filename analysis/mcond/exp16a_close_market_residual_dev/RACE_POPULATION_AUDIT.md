# EXP16A — race 母集団の監査（正式 race set の確定）

**作成日**: 2026-09-24　**測定**: `race_population.py` → `out/race_population.json`
**範囲**: 2016-01-01〜2023-12-31。2024/2025 は読み込み時に破棄。学習なし、2023 の指標は未計算。

---

## 1. 馬の分類（仮定せず実測で決めた）

master（着順が数値の行）と、締切プールの構成（確定オッズを持つ馬）を突き合わせ、
外部 kekka の異常コードを**オッズの有無から実証的に同定**した。

| 異常コード | 頭数 | 確定オッズを持つ割合 | 実測からの解釈 |
|---|---|---|---|
| 3 | 676 | **0.0%** | 締切前に市場から消えた＝**取消**（プールに残っていない） |
| 4 | 1,748 | **100%** | 締切プールに残ったまま着順が無い＝**出走したが完走しなかった（DNF 系）** |
| 7 | 20 | 100% | 同上（稀、失格・降着等の可能性） |
| 5 | 1 | 100% | 同上 |

**コードの意味は外部ファイルの符号であり、TARGET の標準割当とは限らない**。
ここでは「確定プールに残っているか」という観測事実だけで DNF 系と取消系を分けている。

## 2. 締切後の取消・返還の監査

- 締切プールに居て着順が無い馬（1,769 頭）は**すべて コード 4/5/7**、つまり出走側だった。
- 締切前に市場から消えた馬（コード 3、676 頭・656 レース）は pre スナップショットにだけ現れる。
- **「締切後に除外されて返還が発生した」痕跡は検出されなかった**。
  もし存在すれば「確定オッズを持ち、着順が無く、コードが取消系」という組合せで現れるはずだが 0 件。
- 返還が確定オッズに反映されるか否かは、この監査の範囲では判定できない（該当事例が無いため）。

## 3. 正式 race set の規則

1. 勝馬が一意（同着レースは除外）
2. 出走頭数 ≥ 5
3. 着順のある馬が全員 確定オッズを持つ
4. **確定プールに居て着順が無い馬（DNF / 締切後除外）が 0 頭**
5. pre と確定の両方で de-vig 可能

この規則により、主評価では **「全 starter 集合」と「モデルがスコア可能な集合」が一致する**。

## 5. DNF の扱い（方針）

- **DNF を取消として扱わない**。DNF 馬は締切時点でプールに居り、市場確率の分母に含まれていた。
- **DNF-inclusive な Q1 を新規構築できない限り、DNF ありレースを正式 Gate に混ぜない**。
  現行 master は dropna 後の母集団で DNF 行を持たないため、Q1（R0-clean）は DNF 馬をスコアできない。
- DNF ありレースは感度分析としてのみ報告する。

## 6. 感度分析（2022 selection、`out/race_population.json` の `sensitivity_2022`）

| 方式 | 内容 |
|---|---|
| **starter 正規化（正式）** | 確定オッズ > 1.0 の starter 全頭で市場を正規化。正式 set では starter = finisher なので定義上一致 |
| **finisher 再正規化（従来方式）** | 着順のある馬だけで再正規化。DNF ありレースでのみ starter 正規化と乖離する |

- 正式 race set（2022, 3,276R）では両方式の Q0 logloss は**定義上一致**する（差 0）。
- **差が生まれるのは DNF ありレースのみ**。その部分集合での Q0 logloss は
  `out/race_population.json` の `sensitivity_2022.dnf_races_only` に記録した
  （starter 正規化 と finisher 再正規化の両方、および差）。
- 従来の mcond 経路は `market.py` で正規化した後 `v6base.py` で再度 starter 正規化する**二重正規化**だったが、
  EXP16A は**正規化を一度だけ**に固定する。

## 7. 主評価に残る既知の除外

| 事象 | 扱い | 件数 |
|---|---|---|
| 1着同着 | 除外 | 44 レース（2016-2023 合計） |
| 出走頭数 < 5 | 除外 | 2 レース |
| DNF / 締切後除外あり | 除外（感度分析でのみ報告） | 1,517 レース |
| 締切前取消 | レースは残し、当該馬を分母から外す | 676 頭 |

除外件数は**アーム間で共通**であり、Q0 / Q1 / Q2a / Q2b / Q3a / Q3b / Q3-placebo / LEGACY-v6 は
すべて同一の race set 上で評価する（被覆差が静かな選抜になるのを防ぐ）。
