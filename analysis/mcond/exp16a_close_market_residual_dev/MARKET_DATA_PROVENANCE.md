## 1. 4 つのオッズ概念を分離する

| 概念 | 手元の実体 | 時刻の意味 | 用途 |
|---|---|---|---|
| **historical_pre_snapshot** | `TANPUK_*.csv` の **区分1**（途中＝前売り）のうち、レース当日かつ確定の 15 分以上前の最後の1本 | **実測: 発走の 25〜30 分前（中央値 27〜28 分）** | Q3a/Q3b（実運用可能性）の市場確率 |
| **close odds**（締切時点の板そのもの） | **手元に存在しない** | — | 使わない。§2 参照 |
| **terminal_close_market**（正式名称、旧 Q0） | `TANPUK_*.csv` の **区分4**（確定） | **情報時点は締切時。記録時刻は発走の 5〜13 分“後”**（中央値 7 分） | Gate A の基準。締切市場に対する残差情報を測る |
| **result-file odds** | `kekka` 系の `単勝配当` 括弧値、外部 `kekka_*_enhanced.csv` の `単勝オッズ` 等 | **時刻が無い**。確定相当かそれ以降か不明 | **Q0/Q3 のいずれにも使わない**。照合のみ |

**T-10 とは呼ばない**。historical_pre_snapshot は実測 26〜30 分前（中央値 28 分）であり、
T-10 は 2026 年以降の JV-Link 前向き取得にだけ使う別概念である。

## 2. 「close」と「final」を手元データで区別できない

JRA は pari-mutuel で、発走時刻に投票が締め切られ、そこでプールが確定する。
手元にあるのは①締切前の途中経過（区分1、最後が発走 28 分前）と②確定値（区分4、発走 7 分後に記録）だけで、
**「締切ちょうどの板」の断面は存在しない**。したがって本実験では

- **`terminal_close_market` は「確定オッズ（区分4）」であって「クロージングライン」ではない**、
- 区分4 は発走後に**記録**されるが、値の**情報時点は締切時**であり結果情報は含まない、

と明記して扱う。この区別を曖昧にすると枠組み自体が誤って解釈される。

**名称**: この価格を **`terminal_close_market`** と呼び、**oracle とは呼ばない**。
- 締切時点の公開市場情報である
- 結果情報を含まない（発走後に記録されているが、値は締切時のプールで決まっている）
- historical_pre_snapshot 時点では**執行不可能**な価格である
- Gate A では「締切市場に対して表特徴が残差情報を持つか」を測る基準として使う

**記録時刻と情報時点の差**: 区分4 は発走の 5〜13 分後に記録されるが、JRA は発走時に投票を締め切るため、
値の情報時点は締切時である。両者を必ず併記する。

**締切後取消・返還の監査**: 確定プールに居て着順が無い馬 1,769 頭は、外部 kekka の異常コードで
**すべて出走側**（コード 4/5/7、確定オッズ保有率 100%）だった。締切前に消えた 676 頭はコード 3 で
確定オッズを持たない。**締切後に除外されて返還が発生した痕跡は 0 件**である
（詳細は `RACE_POPULATION_AUDIT.md` §2）。

## 4. de-vig（控除の除去）と正規化

- 方式は **比例正規化のみ**: `pi_i = (1/o_i) / Σ_j (1/o_j)`。power/Shin/logit 法は使わない
  （既存 `analysis/mcond/market.py` と同一規約）。
- **正規化の母集団は「master に居る出走馬」に一度だけ固定する**。
  既存 mcond 経路は `market.py` で正規化し `v6base.py` で再度正規化する二段になっているが、
  本実験では**取消集合が pre と確定で異なる**ため、二重正規化はしない。
  Q0・Q3 は必ず同一の馬集合の上で定義する。
- overround は pre 中央値 1.259〜1.261、確定 1.261〜1.262。単勝の控除率 20% と整合
  （1/1.26 ≈ 0.794）。

## 5. 欠損・取消・返還の扱い（事前固定）

| 事象 | 規則 |
|---|---|
| オッズ `<= 1.0` | 欠損として扱い、その馬を de-vig の分母から外す（実測 0 レース） |
| オッズはあるが master に居ない馬番（取消・除外） | 分母から外す。件数を年別に記録 |
| master に居るがオッズが無い馬 | 実測 0 件。発生したらそのレースを**両アームとも**除外し件数を報告 |
| 1着同着 | 主評価から除外、件数を報告 |
| 返還（レース不成立等） | 手元の単勝時系列には該当レースが現れない。発生時はレース単位で除外 |

**共通の適格レース集合**を最初に1回だけ作り、Q0/Q1/Q2a/Q2b/Q3a/Q3b/Q3-placebo/LEGACY-v6 のすべてが
同じレース集合の上で評価されることを assert する（被覆差が静かな選抜になるのを防ぐ）。
正式 race set の規則と実測（**25,501 / 27,639 レース**、障害 1,011R と平地 DNF 1,072R を除外後）は `RACE_POPULATION_AUDIT.md` を参照。
**DNF を含むレースは主評価から除外**し、感度分析としてのみ報告する。

## 7. 既知の注意点

1. **区分4 は発走後の記録**（情報時点は締切時）。`terminal_close_market` を「クロージングライン」と呼ばない。
2. **result-file odds を混ぜない**。EXP10 の市場特徴がこれに該当し、素性不明として要再検証扱いになっている。
3. **京都競馬場は 2021〜2023 に改修で不在**。2022 で固定する競馬場サブセットは 9 場（中京/中山/函館/小倉/新潟/札幌/東京/福島/阪神）であり、
   2023 の評価でも京都は現れない。サブセット定義を年をまたいで使う際はこの欠落を明示する。
4. 単勝票数（`単勝票数` 列）は pre スナップショット時点の値であり、**market size のサブセット定義に使えるが、
   確定側の票数と混同しない**。
