## 6. 解釈の制限（spec v0.4 の規約）

1. Gate A の FAIL は **単勝 close 市場に対する R0-clean の残差情報を 2019-2023 crossfit で検出できなかった**という限定的な意味である。**全券種・JRA 全研究・馬券依存構造へ一般化しない**。
2. Q3 系（pre 市場基準）で観測された改善は、**Gate A の FAIL を打ち消さない**。pre 市場に対する改善は EXP05 で既に観測されている系統の再現であり、本実験の空白は Q0（締切市場）側にある。
3. `PASS-SIGNAL` を `PASS-PRACTICAL` と言い換えない。今回はいずれの等級も Gate A では成立していない。
4. 統計的な残差情報の存在は経済価値を意味しない。0.005 付近の効果は期待成長の規模がほぼゼロであり（spec の `c2c_economic_scale_fixed_interpretation`）、候補生成へ進む根拠にならない。
5. **2024/2025 は開封していない**。ROI 評価・候補生成・配分最適化・production 変更も行っていない。
6. 『市場に吸収された』と断定しない。Gate A の FAIL の原因は、表特徴の情報が締切市場に既に含まれている可能性に加え、結合モデルの形・τ・較正・OOF の学習量など複数が考えられる。

## 7. 結果を見る前に決めた実装上の判断

凍結 spec が一意に定めていなかった点について、**結果を開封する前に**次のとおり決めて記録した（`out/oof_manifest.json` / 本 REPORT）。

| 項目 | 決めたこと | 理由 |
|---|---|---|
| Q1 の学習母集団 | master_v2 の着順が数値の全行（EXP15 R0-clean と同一。障害を含む） | spec は Q1 の hyperparameter family を EXP15 と同一と定めており、EXP15 は全行で学習している。評価だけを正式 race set に限定する |
| τ の母集団 | Y−1 の正式 race set 行（Y=2016 のみ 2015 の全レース） | 評価と同じ母集団に合わせる。2015 は市場データ突合の対象外 |
| Gate A の placebo | log(Q1) を事前固定セル内で馬単位に置換（20 draw） | spec は Gate A の等級条件に placebo を含むが、Gate A の arm に残差特徴は無い。同じ construction を検定対象の信号（log Q1）へ適用した |
| placebo の seed | median seed のみ | 計算量。等級条件は median seed で判定するため |
