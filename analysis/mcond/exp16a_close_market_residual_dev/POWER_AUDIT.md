# EXP16A — 検出力監査（3 段）

**作成日**: 2026-09-24　**コード**: `power_audit.py`　**結果**: `out/power_audit.json`
**範囲**: 2016〜2022 の正式 race set のみ（22,310R / 312,489 頭）。**2023 は一切読まない**。
学習しない（LightGBM を使わない）。ROI 評価も候補生成もしない。

実務床 **0.005 nats/race** と recovery ratio 10% は**この監査より先に**固定した値であり、
監査結果によって変更しない（`spec.json` の `thresholds_fixed_before_power_audit`）。

---

## 1. 3 段に分ける理由

`SD(Δ_r) ≈ \sqrt{2\bar\Delta}` と `MDE ≈ 2·2.8²/R` は、**局所指数傾斜・最適な方向・正しいモデル仕様・
独立レース**という条件下の近似である。本実験に対する厳密式・保証値ではないため、
次の 3 段に分けて扱う。

| 段 | 名称 | 役割 |
|---|---|---|
| 1 | `ideal_local_approximation` | 理論的な**楽観側の基準**。仮定を明記して参照するだけ |
| 2 | `empirical_cluster_power` | **正式な検出力判定**。合成注入して判定規則を最後まで通す |
| 3 | `secondary_reference_check` | 2022 pre→close 差で理論 SD と実測 cluster SE を照合（普遍式の証明としては使わない） |

## 2. tier 1 — `ideal_local_approximation`（楽観側の基準）

仮定: ①局所指数傾斜（δ→0）②方向が最適 ③モデル仕様が正しい（係数推定の誤差を無視）
④レースが独立（meeting-day クラスタなし）⑤点推定を床と比べる条件・seed 判定・年ごとの方向一致条件を課さない。

- $\bar\Delta = 0.005$ における理論 SD = $\sqrt{2\times 0.005}$ = **0.1 nats**
- 床 0.005 を検出するのに必要なレース数 = $15.68/0.005$ = **3,136R**

| R の取り方 | レース数 | 理論 MDE (nats) |
|---|---|---|
| 2018 単年 | 3,184 | 0.004925 |
| 2019 単年 | 3,185 | 0.004923 |
| 2020 単年 | 3,169 | 0.004948 |
| 2021 単年 | 3,200 | 0.004900 |
| 2022 単年 | 3,206 | 0.004891 |
| 5 年 pooled（2018-2022） | 15,944 | **0.000983** |

理論式だけを見れば「単年でぎりぎり、5 年 pooled なら十分」に見える。**この結論は採用しない**（tier 2 参照）。

## 3. tier 2 — `empirical_cluster_power`（正式判定）

### 3.1 手順

1. 2016〜2022 の正式 race set（年・頭数・市場 entropy・meeting-day の実構造をそのまま保持）を読む。
2. 方向 $s$ をレース内標準化し、**真の確率**を $p_\delta(i) \propto \pi(i)\,e^{\delta s_i}$ とする。
   $\delta$ は**真の期待 logloss 改善が指定値になるよう二分探索で較正**する（0.005 で δ = 0.1251）。
3. 合成 winner を $p_\delta$ から引く（Gumbel-max）。
4. **実際と同じ手順**を最後まで通す:
   評価年 Y（2018〜2022）ごとに **Y−1 以前の合成データだけ**で係数 β を条件付きロジット（offset log π）で fit →
   Y を予測 → per-race $\Delta_r = LL(q) - LL(\pi)$ → 年層化 meeting-day bootstrap → seed 判定 →
   最大効果年を除いた leave-one-year-out。
5. これを 150 反復し、**事前登録した判定規則全体の pass 確率**を測る。

5 seed は、方向に per-horse ノイズ（`seed_jitter` ∈ {0, 0.1, 0.25}、事前固定）を載せて再標準化することで模す。
実際の seed 間ばらつきは Stage 1 で Q1 の 5 seed から実測し、その値で再実行する。

判定規則（`spec.json` の `five_year_judgement`）:
①pooled median ≤ −0.005　②年層化 meeting-day bootstrap CI95 上限 < 0　③5 年中 4 年以上で改善方向
④5 seed 中 4 以上で改善方向　⑤最大効果年を除いた leave-one-year-out でも ① と ② を満たす。

### 3.2 真の効果 = 床 0.005 を注入したときの pass 確率

| 基準市場 | 方向 | seed_jitter | **規則全体** | ①点推定≦床 | ②CI上限<0 | ③年方向 | ④seed方向 | ⑤LOO最大年 |
|---|---|---|---|---|---|---|---|---|
| close | 残差特徴線形 | 0.0 | **0.187** | 0.473 | **1.000** | 1.000 | 1.000 | 0.187 |
| close | 残差特徴線形 | 0.1 | **0.213** | 0.433 | **1.000** | 1.000 | 1.000 | 0.213 |
| close | 残差特徴線形 | 0.25 | **0.100** | 0.220 | **1.000** | 1.000 | 1.000 | 0.100 |
| close | 標準化乱数（対照） | 0.1 | **0.187** | 0.373 | **1.000** | 1.000 | 1.000 | 0.187 |
| pre | 残差特徴線形 | 0.1 | **0.173** | 0.393 | **1.000** | 1.000 | 1.000 | 0.173 |

- **CI95 上限 < 0 という「効果があること」の検出は 100%**。落ちているのは「点推定が床 0.005 を**超える**」条件と、
  それを最大効果年を除いてもう一度課す leave-one-year-out 条件である。
- 推定の減衰はわずか（median 推定 / 注入量 = 0.90〜0.98）。つまり推定器が偏っているのではなく、
  **「真の効果 = 床」の点推定比較は原理的に 50% 前後にしかならない**（LOO で選抜バイアスが入ると更に下がる）。
- 方向を残差特徴線形から標準化乱数へ替えても 0.187 対 0.187 でほぼ同じ。
  **per-race 分散の形は結論を変えない**。close 基準と pre 基準の差も小さい（0.213 対 0.173）。

### 3.3 真の効果を動かした power curve（close / 残差特徴線形 / jitter 0.1）

| 真の効果 (nats/race) | 0.005 | 0.0075 | 0.010 | 0.015 | 0.020 | 0.030 |
|---|---|---|---|---|---|---|
| 規則全体の pass 確率 | 0.213 | **0.967** | 1.000 | 1.000 | 1.000 | 1.000 |

**規則全体が 80% で通る最小の真の効果 = 0.006947 nats/race**（線形補間）。

### 3.4 判定

> 真の効果 0.005 nats/race を注入したときの pass 確率は **10〜21%**（全設定の最小 0.100）で、
> 事前固定した 80% に届かない。したがって事前登録の規則により **`do_not_open_2019_2023`**。
> 2019〜2023 の結果を開けず、期間・設計の見直しをレビューへ回す。

**構造的な注意**: 判定規則が「点推定 ≤ −0.005」を含む限り、真の効果がちょうど 0.005 のときの pass 確率は
レース数をいくら増やしても 50% を超えない。レース数が決めるのは「**何 nats なら 80% で通るか**」であり、
それが 0.006947 である。**実務床 0.005 自体は変更しない**。
（規則から leave-one-year-out の hard 条件を外した場合でも、床での pass 確率は 0.220〜0.473 であり
80% には届かない。すなわち結論は LOO 条件の有無に依存しない。）

### 3.5 この tier の既知の楽観点

- 方向 $s$ は正しく与えられている（Q1 の推定誤差は `seed_jitter` でしか近似していない）。
- 真のモデルが厳密に局所指数傾斜である。
- 評価年が 2018〜2022 で、実判定の 2019〜2023 と 1 年ずれる（2018 の fit 年は 2016-2017 の 2 年しかない）。
- **`q1_log_ratio` = log(Q1/π) 方向は Stage 0 では測れない**（rolling OOF が無い）。
  Stage 1 で OOF を作った直後、**結果を開封する前に**この方向で tier 2 を再実行する。

## 4. tier 3 — `secondary_reference_check`（2022 pre→close 差）

| 量 | 実測 | 理論（局所近似） |
|---|---|---|
| 平均 gap | 0.047458 nats | — |
| per-race SD | **0.270610** | $\sqrt{2\bar\Delta}$ = 0.308085 |
| SD 比（実測/理論） | **0.878** | — |
| iid SE | 0.004779 | 0.005441 |
| meeting-day cluster SE | **0.004683** | — |
| cluster / iid SE | **0.980** | — |

- 理論 SD は実測より **14% 大きい**（理論が保守的側に外れている）。
- この量に関しては **meeting-day クラスタはほぼ効いていない**（cluster SE / iid SE = 0.98）。
- ただし pre→close 差は局所傾斜ではなく大きな差（平均 0.047 nats）なので、理論式と一致する保証は無い。
  **一致・不一致のいずれも普遍式の証明として扱わない。**

## 5. 進行条件（再掲）

- 実務床は **0.005 のまま変更しない**。
- **`empirical_cluster_power` が 80% 以上なら進行**。
- **80% 未満なら 2023（および 2019〜2022 の結果）を開けず、期間・設計を見直す** ← 現在ここ。
- **理論 MDE（tier 1）だけで進行可否を決めない。**
