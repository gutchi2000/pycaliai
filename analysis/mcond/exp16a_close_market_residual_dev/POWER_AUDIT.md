# EXP16A — 検出力監査（3 段・等級別）

**作成日**: 2026-09-24　**改訂**: 2026-09-24（改訂3: Gate を 3 等級に分け、等級別に power を測る）
**コード**: `power_audit.py`（判定は `gate_grade.py`）　**結果**: `out/power_audit.json`
**範囲**: 2016〜2022 の正式 race set のみ（22,310R / 312,489 頭）。**2023 は一切読まない**。
学習しない（LightGBM を使わない）。ROI 評価も候補生成もしない。

実務床 **0.005 nats/race** と recovery ratio 10% は**この監査より先に**固定した値であり、
監査結果によって変更しない（`spec.json` の `thresholds_fixed_before_power_audit`）。

## 1. 3 段に分ける理由

`SD(Δ_r) ≈ \sqrt{2\bar\Delta}` と `MDE ≈ 2·2.8²/R` は、**局所指数傾斜・最適な方向・正しいモデル仕様・
独立レース**という条件下の近似である。本実験に対する厳密式・保証値ではないため、次の 3 段に分けて扱う。

| 段 | 名称 | 役割 |
|---|---|---|
| 1 | `ideal_local_approximation` | 理論的な**楽観側の基準**。仮定を明記して参照するだけ |
| 2 | `empirical_cluster_power` | **正式な検出力判定**。合成注入して等級判定を最後まで通す |
| 3 | `secondary_reference_check` | 2022 pre→close 差で理論 SD と実測 cluster SE を照合（普遍式の証明としては使わない） |

## 2. tier 1 — `ideal_local_approximation`（楽観側の基準）

仮定: 局所指数傾斜 (δ→0)／方向が最適 (正しい 1 次元スコア)／モデル仕様が正しい (係数推定の誤差を無視)／レースが独立 (meeting-day クラスタなし)／等級条件 (CI と床の比較・seed 判定・年方向・LOO・placebo) を課さない。

- 床 0.005 における理論 SD = √(2×0.005) = **0.100 nats**
- 床 0.005 を検出するのに必要なレース数 = 15.68/0.005 = **3136R**

| R の取り方 | レース数 | 理論 MDE (nats) |
|---|---|---|
| 2018 単年 | 3,184 | 0.004925 |
| 2019 単年 | 3,185 | 0.004923 |
| 2020 単年 | 3,169 | 0.004948 |
| 2021 単年 | 3,200 | 0.004900 |
| 2022 単年 | 3,206 | 0.004891 |
| 5 年 pooled（2018-2022） | 15,944 | **0.000983** |

理論式だけを見れば「単年でぎりぎり、5 年 pooled なら十分」に見える。**この結論は採用しない**（tier 2 参照）。

## 3. tier 2 — `empirical_cluster_power`（正式判定）

### 3.1 手順

1. 2016〜2022 の正式 race set（年・頭数・市場 entropy・meeting-day の実構造をそのまま保持）を読む。
2. 方向 $s$ をレース内標準化し、**真の確率**を $p_\delta(i) \propto \pi(i)\,e^{\delta s_i}$ とする。
   $\delta$ は**真の期待 logloss 改善が指定値になるよう二分探索で較正**する（0.005 で δ = 0.1251）。
3. 合成 winner を $p_\delta$ から引く（Gumbel-max）。
4. **実際と同じ手順**を最後まで通す: 評価年 Y（2018〜2022）ごとに **Y−1 以前の合成データだけ**で
   係数 β を条件付きロジット（offset log π）で fit → Y を予測 → per-race
   $\Delta_r = LL(q) - LL(\pi)$ → 年層化 meeting-day bootstrap（CI95）→ seed 判定 →
   **leave-one-year-out の全 5 通り** → `gate_grade.grade_gate` で等級を付ける。
5. 判定水準は **400 反復**（power curve の補助水準は 200 反復）、random seed = 20260924。

5 seed は、方向に per-horse ノイズ（`seed_jitter` ∈ {0, 0.1, 0.25}、事前固定）を載せて再標準化することで模す。
実際の seed 間ばらつきは Stage 1 で Q1 の 5 seed から実測し、その値で再実行する。

**等級**（`gate_grade.py` が唯一の実装。spec.json の `gates` と同一規則）:

| 等級 | 条件 |
|---|---|
| **PASS-PRACTICAL** | CI95 上限 **< −0.005** ＋ 安定性条件 |
| **PASS-SIGNAL** | CI95 上限 < 0 だが **< −0.005 ではない** ＋ 安定性条件 |
| **FAIL** | CI95 上限 ≥ 0、または安定性条件のいずれか不成立 |

安定性条件: 5 年中 4 年以上で改善方向／5 seed 中 4 以上で改善方向／**leave-one-year-out の全結果**で
CI95 上限 < 0／（Gate A）placebo 97.5 パーセンタイル超え。**点推定は等級条件に使わない**。

### 3.2 真の効果 = 床 0.005 を注入したときの等級別 power

| 設定 | seed_jitter | 反復 | P / S / F | **検出 (P∪S)** | Wilson 95% | PASS-PRACTICAL | Wilson 95% |
|---|---|---|---|---|---|---|---|
| close / 残差特徴線形 | 0.0 | 400 | 8 / 392 / 0 | **100.0%** | [0.990, 1.000] | 2.0% | [0.010, 0.039] |
| close / 残差特徴線形 | 0.1 | 400 | 6 / 394 / 0 | **100.0%** | [0.990, 1.000] | 1.5% | [0.007, 0.032] |
| close / 残差特徴線形 | 0.25 | 400 | 3 / 397 / 0 | **100.0%** | [0.990, 1.000] | 0.8% | [0.003, 0.022] |
| close / 標準化乱数（対照） | 0.1 | 400 | 7 / 393 / 0 | **100.0%** | [0.990, 1.000] | 1.8% | [0.009, 0.036] |
| pre / 残差特徴線形（Gate B） | 0.1 | 400 | 6 / 394 / 0 | **100.0%** | [0.990, 1.000] | 1.5% | [0.007, 0.032] |

- **検出（PASS-PRACTICAL ∪ PASS-SIGNAL）の確率は全設定で最小 100.0%**（Wilson 95% 下限の最小 0.990）。
- **PASS-PRACTICAL 単独**の確率は 2.0%, 1.5%, 0.8%（jitter 0 / 0.1 / 0.25）。真の効果が床と等しいとき、CI 全体で床を超える証明力が低いのは統計的に自然である。
- 床での点推定の中央値は -0.004880、CI95 の中央値は [-0.006393, -0.003315]。
- 点推定が床を超える割合は 45.2% で、**点推定だけで実務床超えを主張すると過大主張になる**ことがそのまま現れている。
- 方向を残差特徴線形から標準化乱数に替えても検出確率は変わらない。**per-race 分散の形は結論を変えない**。

### 3.3 真の効果 0.0069 での PASS-PRACTICAL 確率

| 設定 | seed_jitter | 反復 | P / S / F | PASS-PRACTICAL | Wilson 95% | 検出 (P∪S) |
|---|---|---|---|---|---|---|
| close / 残差特徴線形 | 0.0 | 400 | 230 / 170 / 0 | **57.5%** | [0.526, 0.623] | 100.0% |
| close / 残差特徴線形 | 0.1 | 400 | 186 / 214 / 0 | **46.5%** | [0.417, 0.514] | 100.0% |
| close / 残差特徴線形 | 0.25 | 400 | 134 / 266 / 0 | **33.5%** | [0.291, 0.383] | 100.0% |
| pre / 残差特徴線形（Gate B） | 0.1 | 400 | 183 / 217 / 0 | **45.8%** | [0.409, 0.506] | 100.0% |

**0.0069 は実務床の変更ではない**（実務床 0.005 は据え置き）。この値は
**改訂2 の旧判定規則（点推定 ≤ 床 ＋ 最大効果年 LOO）での 80% 点**として得られたものであり、
レビュー指示に従って「実務床超えを 80% 程度の確率で証明できる真の効果量」の記録値として残す。
ただし**改訂3 の等級規則（CI95 上限 < −0.005）での実測は 46.5%（jitter 0.1）で 80% に届かない**。
等級規則での 80% 点は **0.008160 nats/race**（§3.4）である。両者はいずれも実務床の変更ではない。

### 3.4 power curve（close / 残差特徴線形 / jitter 0.1）

| 真の効果 (nats/race) | 0.005 | 0.0069 | 0.0075 | 0.01 | 0.015 | 0.02 | 0.03 |
|---|---|---|---|---|---|---|---|
| 検出 (P∪S) | 100.0% | 100.0% | 100.0% | 100.0% | 100.0% | 100.0% | 100.0% |
| PASS-PRACTICAL | 1.5% | 46.5% | 73.0% | 99.5% | 100.0% | 100.0% | 100.0% |

- 検出（P∪S）が 80% に達する最小の真の効果 = **0.005 nats/race 以下**（最小の試験水準 0.005 で既に 100%。0.005 より小さい水準は測っていない）
- **PASS-PRACTICAL が 80% に達する最小の真の効果 = 0.008160 nats/race**（0.0069 は改訂2 の旧規則での 80% 点であり、改訂3 の等級規則では 46.5% にとどまる）

### 3.5 判定（進行条件）

> 進行条件は **「真の効果 0.005 で PASS-PRACTICAL ∪ PASS-SIGNAL の検出確率 ≥ 80%」**。
> PASS-PRACTICAL 単独の 80% は要求しない。

実測は最小 100.0%（Wilson 95% 下限の最小 0.990）であり、判定は **`proceed_to_stage1_pending_review`** である。

### 3.6 この tier の既知の楽観点

- 方向 s は正しく与えられている (Q1 の推定誤差は seed_jitter でのみ近似)
- 真のモデルが厳密に局所指数傾斜である
- Gate A の placebo 条件は満たされたものとして扱っている
- 評価年は 2018-2022 で、実判定の 2019-2023 と 1 年ずれる

`q1_log_ratio` = log(Q1/π) 方向は Stage 0 では測れない（rolling OOF が無い）。
Stage 1 で OOF を作った直後、**結果を開封する前に**この方向で tier 2 を再実行する。

## 4. tier 3 — `secondary_reference_check`（2022 pre→close 差）

| 量 | 実測 | 理論（局所近似） |
|---|---|---|
| 平均 gap | 0.047458 nats | — |
| per-race SD | **0.270610** | √(2Δ̄) = 0.308085 |
| SD 比（実測/理論） | **0.878** | — |
| iid SE | 0.004779 | 0.005441 |
| meeting-day cluster SE | **0.004638** | — |
| cluster / iid SE | **0.970** | — |

- 理論 SD は実測より 14% 大きい（理論が保守側に外れている）。
- この量に関しては **meeting-day クラスタはほぼ効いていない**（cluster SE / iid SE = 0.97）。
- ただし pre→close 差は局所傾斜ではなく大きな差なので、理論式と一致する保証は無い。
  **一致・不一致のいずれも普遍式の証明として扱わない。**

## 5. 進行規則（再掲）

- 実務床は **0.005 のまま変更しない**。
- **真の効果 0.005 で PASS-PRACTICAL ∪ PASS-SIGNAL の検出確率 ≥ 80% なら Stage 1 へ進める**。
- **PASS-PRACTICAL 単独の 80% は要求しない**。
- 推定 power だけでなく **Wilson 95% CI 下限**が大きく 80% を割っていないことを確認する。
  反復数が少なく 100% になっている場合は反復数を増やして確認する。
- **理論 MDE（tier 1）だけで進行可否を決めない。**
- 経済的な意味づけは別問題である。0.005 付近の等級は期待成長の規模がほぼゼロであり、
  候補生成へ進む根拠にはならない（`spec.json` の `c2c_economic_scale_fixed_interpretation`）。
