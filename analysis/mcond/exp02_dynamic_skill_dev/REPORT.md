## 平易な結論

1. **強い相手に善戦した価値を、従来より測れたか。**
   少しだけ測れた。多頭数の着順から相手の強さを込みで推定した能力（平均系）は、現行AIと発走35分前の市場を与えた後にも、3着内の予測を改善した。さらに、過去のELO・Glickoと出走回数・休養日数まで与えた後でも、小さいが有意な上積みが残った（探索分析）。ただし大きさは確率の誤差で 0.03〜0.04% 程度。

2. **v6と市場の後にも情報が残ったか。**
   残った。事前登録の主判定 M3 vs M1 は5条件すべて満たした（2023 Δlogloss −0.00074、97.5%CI [−0.00116, −0.00032]、2024・2025 同符号、4人気帯すべて、上位100頭を除いても、履歴2走以下を除いても）。EXP01（陣営選択）と違い、**1着の予測にも効く**。

3. **過去のELO・Glickoより固有の価値があったか。**
   事前登録の判定では **あった**（M4 vs M2 PASS）。ただし探索分析で分解すると、その上積みの**約4分の3は「出走回数」と「前回からの日数」**という生の事実によるもので、過去のELO/Glickoがたまたまそれを含んでいなかったことが大きい。それらを与えた後に動的能力そのものが足す分は、全体の約4分の1。

4. **能力平均と不確実性のどちらが効いたか。**
   同じくらい効いたが、**「不確実性」の効き目はほぼ全部が出走回数と休養日数**だった。モデルが推定した不確実性（σ）だけを足しても上積みはゼロ（CI が 0 をまたぐ）。実質的に効いているのは「能力平均」と「経験・休養の事実」。

5. **年度をまたいで再現したか。**
   した。2023・2024・2025 すべて同じ向き。人気帯・履歴数・昇級・同級でもおおむね同じ向き（M4 vs M2 の履歴3〜5走・昇級・降級は CI が 0 をまたぐ）。

6. **利益に変換できたか。**
   **できなかった。** 事前登録の2ルールで、M4 と M1 の回収率の差は R1 **+2.31pt**（95%CI [−0.03, +4.73]）、R2 **+0.24pt**（[−0.44, +0.97]）。どちらも有意ではなく、回収率そのものも R1 75.4%、R2 85.4% と控除率の内側。R2 は市場1番人気の複勝均等（85.1%）と同水準。

7. **この仮説を終了するか。**
   **終了する。** 仕様 §16 に従い、Gate 2 は通過したが Gate 3 で利益差がないので「予測情報として記録するだけで本番接続しない」。別のレーティング名・条件区分・パラメータでの再探索もしない。次は「恒常的能力と短期状態の分離」。

## 探索分析（仕様固定後に追加、主判定を変えない）`supplement.py`
問い4「平均と不確実性のどちらが効いたか」に答えるための分解。M1 に対する Δlogloss（95%CI）:

| 不確実性系のみ（σ・出走回数・休養日数・フィールド平均σ） | −0.000352 [−0.000583, −0.000108] | −0.000331 [−0.000458, −0.000205] |

| 平均系＋不確実性系 | −0.000742 | −0.000584 |

固有価値の分解（既存 ELO/Glicko ＋ 出走回数・休養日数 に対して）:
| 比較 | 2023 | 2024-25 |
|---|---|---|
| ＋動的能力の平均系 | **−0.000160 [−0.000282, −0.000035]** | **−0.000108 [−0.000199, −0.000014]** |

→ 過去のELO・Glicko・出走回数・休養日数を全部与えた後でも、動的能力の平均系は小さいが有意に上積みする。ただし主判定の上積みの約4分の1。

**EXP01 との共通点**: EXP01 でも効いていたのは出走間隔などの生の選択だった。2つの実験で、**出走回数・休養日数・間隔という生の事実に、発走35分前の市場が織り込み切っていない情報がある**ことが繰り返し出ている。ただし大きさは小さく、どちらの実験でも利益には変換されていない。

## 未解決事項
1. ハイパーパラメータが格子の端（β・τ² とも最小）で選ばれた。格子外の方が良い可能性があるが、事前登録どおり広げていない
2. 更新式の γ を評価前に OpenSkill 既定値から 1 に変えた（2013 ウォームアップの記述統計だけを見た判断、spec.json に記載）
3. 既存 ELO/Glicko は同日の先行レース結果を後続レースに使う逐次更新。発走35分前の判断時点では既知なのでリークではないが、M2 側がわずかに情報で有利（M4 vs M2 は保守的な比較）
4. OOF スコアは本番 C1 の学習重みを含まない近似
5. 「出走回数・休養日数に市場未反映の情報がある」という共通所見は、どちらの実験でも主仮説ではなく、事前登録された検定で確かめたものではない
