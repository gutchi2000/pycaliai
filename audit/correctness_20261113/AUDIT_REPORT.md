- **変換の順序:** スコア → PL `exp(s)` → p_win・2着内 (p_plc)・3着内 (p_sho) → p_win と p_sho だけを別々に isotonic 較正。p_plc は一度も較正されない。印は生スコアの順。

  - レース内の p_win 合計: 5〜95 パーセンタイルで 0.88〜1.08、全範囲は 0.79〜1.29。
  - p_win = 0 の馬: 1.5%。
  - ◎の p_win が他馬と同値のレース: 15.6%。
  - p_plc > p_sho の馬: 488 頭。p_plc が較正されていないために起きる。
- **オフライン test (本番の欠損を再現した条件):**
  - p_win の Brier: 較正前 0.06076 → v6 較正器 0.06073 → serve 較正器 0.06069。
  - p_sho の Brier: 較正前 0.13791 → serve 較正器 0.13798。
  - 較正でほとんど改善せず、0 や同値を作る原因になっている。

  - fit 時の baseline は 0905・0906 の週。
  - 今は欠損している 4 特徴 (closing_power、prev_pos_rel、前1角、前2角) をマスクしていない。
